# Listen Later presentation

[中文](../../../zh-cn/板块/界面/待听交互.md)

Order and persistence belong to the [host queue](../library/history-and-downloads.md). This page records layout, grouping, selection and reorder.

Listen Later reuses the catalog's track cards, display density, mobile column preference, background region, and restrained radii. The heading uses the same font size and 44px title row as catalog-page__context, shares horizontal padding with the grid, and shows actual queue order. An inset gray surface contains the heading and tracks, sharing the Discover track page's outer width and horizontal track padding without another width limit; the surface fills the available page height by default and grows with longer content, surrounded by the existing page background and bottom padding. Desktop totals use a theme-colored badge and bold number. Phones omit the content intro and show the full queue count at the top right. Platform and account context appears only in Discover. “All tracks / By platform” stays left as a direct collection grouping control. Display mode has one entry immediately before Filter in the lower toolbar at every width; narrow containers may use an icon with the same accessible name and target. Entries match Search/Import at 12px text and at least 44px height. Catalog state buttons and track-page header buttons share the 650 font weight of the Listen Later display entry. The toolbar sticks after scrolling past its original position, keeping arrangement on the left. Display settings reuse the catalog's density and phone column preferences. Density changes share grid movement animations; arrangement changes slide only the list content in both directions, keeping the intro, toolbar, and background surface in place, with movement disabled for reduced motion. Playback mode remains available in the player. Platform entries reuse CollectionCard and CollectionGrid with an ideal column width of 320 CSS pixels, independent of host-page root font sizes, and a 16px gap. Columns follow the actual content width; narrower regions use one column. Long names and count summaries truncate on one line with full text hints. Cards use 10px radii, theme icons, counts, type labels, and playback badges; selection controls remain separate from the view button. The platform overview omits breadcrumbs. Listen Later containers up to 600px wide use compact horizontal platform cards, placing the type before the count on a shared summary line. Actual text measurements remove the Source / Local composition prefix first when it does not fit; remaining count overflow is clipped on one line with a full text hint, wrapping playback badges as space allows, and keeping an independent 44px selection target on the right. The view button retains horizontal padding and room for its full arrow animation, reducing vertical footer spacing and card gaps. Opening a platform slides the whole page, including its intro, toolbar, and content, in both directions. Platform track details reuse the catalog sticky return header, title and summary font sizes, 44px context title row and horizontal text padding, collapsible context, with Display mode in the lower toolbar, showing platform name, queue counts, and playback status without repeating the overview intro or arrangement controls. Back to platforms restores the overview scroll position and entry focus. Leaving views become inert immediately, and reduced motion disables movement. The platform overview, All tracks, and platform track details retain the Operator entry, panel, and selected count. Each platform checkbox selects its currently matching tracks and displays a mixed state for partial selection; activating a fully selected checkbox clears that platform's matching selection. Selection is shared with track views, and bulk download and removal keep the existing track counts and confirmation rules. Selection, select all, download, removal, and counts in detail apply only to matching tracks from that platform. Empty filtered details retain navigation; removing the final platform track returns to the overview. Platform entries support two-dimensional drag and arrow-key reordering, while tracks stay within their platform. CollectionCard, CollectionGrid, CollectionBreadcrumbs, and useCollectionNavigation provide the same entry and navigation foundation for playlists. Switching to platform arrangement preserves each platform's track order and persists contiguous platform blocks. Cards share Play, Favorite, Download, and Actions with search results. The shared actions dialog preserves custom names, tags and source links, groups Play, Listen later, Favorite, and Download into four compact columns matching catalog track actions. Listen later is selected for queued tracks; toggling it off retains the removal confirmation, with no separate Remove from Listen later button. The ordering row contains Move later, Move earlier, and Pin, with name, tag and source options in a final group. Spacing and dividers separate groups; catalog track actions use the same four-column layout and separation. Enabled actions and options change background on hover or keyboard focus and give icons a small translation or scale when motion is allowed. Moves remain disabled at the appropriate boundary. Track cards in both All tracks and platform details omit dedicated drag buttons. A short artwork press selects only while the operator is open; holding for 500ms activates dragging with a raised outline and a top teal info notice with a reorder icon: “Drag sorting is ready. Move to reorder; release to finish.” It appears once per successful activation, dismisses after 3 seconds, and does not take focus or intercept dragging. Once the hold activates dragging, tracks, platform cards, child controls, and content gaps share the four-way move cursor; release or cancellation restores their usual cursors. Movement over 8px or scrolling before activation cancels the hold; touch dragging takes over only after activation. The synthetic click after release does not change selection. Artwork supports arrow-key movement and Escape cancellation; Actions retains Move earlier, Move later, and Pin. The top-right selection control appears only in operator mode and stays independent of reordering. Platform overview cards omit dedicated reorder handles. In selection mode, a short checkbox press selects tracks; holding the platform card or its selection area for 500ms activates whole-group dragging with the same top info notification and cancellation rules. The synthetic click after release neither changes selection nor opens platform details. The grid adds no extra padding, keeping heading controls aligned with the tracks; the container bounds horizontal reorder overflow. Tracks reorder within their platform, and complete platform blocks can move. Mobile retains these controls without an additional side drawer.
