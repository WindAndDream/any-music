# Tauri desktop and mobile runtime

[中文](../../../zh-cn/板块/桌面与移动端/文档索引.md)

`apps/tauri` binds the workbench to renderer IPC and Rust services. Rust owns native credentials, data, HTTP, account pages, media, installation and grants. Runtime capabilities select the desktop or mobile composition.
