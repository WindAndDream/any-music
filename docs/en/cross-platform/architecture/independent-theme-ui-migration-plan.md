## T13 completion and closeout

Perform browser/application/device inspection only when explicitly requested in the current task. Record each runtime/theme/build/device, input method, case, result and limitation. Cover applicable layout/appearance/reduced-motion, playback/download/editor continuity, protected surfaces, focus and scroll. Installed GM and native acceptance require their own evidence; component tests and development GM are insufficient. Close only executed cases, update this remaining matrix and remove redundant completed material under the [documentation lifecycle](documentation-lifecycle.md).
