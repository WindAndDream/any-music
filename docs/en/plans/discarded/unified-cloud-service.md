# One core account and cloud service

[中文](../../../zh-cn/计划/废弃/统一核心云服务.md)

**Discarded.** An earlier design assigned registration, password/email, synchronization and sharing to one core identity service. The selected plan keeps local identity, verified bindings and canonical writes in the host and lets independent services handle their own account and cloud lifecycles. This makes offline and private deployments possible with fewer dependencies. [Local users](../future/local-users.md), [optional services](../future/optional-services.md).

Revisit a unified deployment option if users need one installed service and service identity, grants, data, offline use and independent disablement can still be preserved.
