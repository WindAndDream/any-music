# Temporary acceptance

[中文](../../../zh-cn/变更/临时验收/文档索引.md)

There are no recorded temporary approvals. Pending and failed cases are listed under [change acceptance](../acceptance/README.md).

When the user explicitly approves proceeding with a known gap, move the change record here with `status: temporary-accepted`. Write the approved scope, decision and date, missing or failed cases and the next recheck. Link here from the affected module when the approved behavior is visible. Return to [acceptance](../acceptance/README.md) for retesting or [in progress](../in-progress/README.md) for repair. See the [change workflow](../../guides/documentation-workflow.md#accept-and-close).
