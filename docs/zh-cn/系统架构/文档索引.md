# Any Music 系统架构

[English](../../en/architecture/README.md)

Any Music 通过稳定的来源身份按需解析音乐。普通歌曲和片段配方共用资料库、播放器和下载流程。两个应用分别注入运行端服务，并提供经典界面。

| 层级         | 职责                                                                                                                  |
| ------------ | --------------------------------------------------------------------------------------------------------------------- |
| 应用         | `apps/userscript` 注入 GM 传输、存储和宿主页集成。`apps/tauri` 注入 IPC、原生存储、账号／代理上下文、媒体和系统能力。 |
| 共享工作台   | `packages/music-workbench` 持有播放器、资料库、下载、贡献生命周期和运行端组合端口。切换主题时这些控制器继续运行。     |
| 表现层       | `packages/ui` 提供受控 Vue 界面与交互原语。`theme-default` 组装完整的经典界面。                                       |
| 领域与来源   | `packages/core` 定义稳定模型、错误和端口。来源插件转换上游响应，`audio-composition` 编译和调度自定义片段配方。        |
| 原生插件权威 | Tauri 的 Rust 层持有经过验证的安装状态、授权、凭证和受限交付。插件 SDK、VM 和适配器提供有版本的有限契约。             |

应用依赖共享包。可信适配器给共享业务注入传输、数据访问和权限，界面向工作台发出操作意图。产品数据持久化稳定身份和配方，凭证、临时媒体和缓存归各自的运行端管理。
