# 篡改猴开发规范

英文对应页：[Userscript Development](../../en/userscript/development.md)。适用于 `apps/userscript`。这里的“后端”指 GM 请求和宿主页能力适配，不表示桌面 Rust 后端。

## 数据获取与调用链

`music-workbench / plugin-source-* → 注入的 HttpClient → apps/userscript/src/platform/http/gm-http-client.ts → GM_xmlhttpRequest`。

- 内置 API 显式 `credentials: 'include'`，由 GM 使用目标域登录态；S10 后不装配或执行外置声明式源。不按当前宿主页域名切换为页面 `fetch`。
- GM 请求的 `fetch: true` 是 Tampermonkey 内部传输选项；小文本与受头部/进度限制的字节请求使用不同策略，应用层统一管理超时和取消。该选项不适用于 Rust。
- Cookie、设备快照、BDMS/Web SecSDK 签名、`document-start` 页面桥和受保护列表回退留在 `src/platform`，通过端口注入共享来源。页面签名不发出第二条业务请求；捕获回退单独处理网页自己的响应。
- `@grant`、精确 `@connect`、`@noframes` 与脚本元数据归 Userscript 构建配置。桌面的 IPC capability 不替代这些权限。
- 当前是宿主单账号和单代理。代理只在 GM HTTP 边界转换；GM proxy 有浏览器兼容限制，保存不表示连通。账号池、Rust CookieStore、原生媒体 grant 不接入本端。

## 存储、媒体与挂载

图片及合规 GM 二进制响应使用独立的管理器缓存命名空间，具有容量、LRU 限制与确认清理。浏览器直接播放保持原生流优先的启动契约。释放产品写入标签之前会先等待缓存退出；缓存值不进入产品备份。详见[资源缓存](../跨平台/功能/资源缓存.md)。

S06 在挂载前登记标签页写入者会话并创建产品代次，启动入口等待初始化完成。命名仓库端口映射到数据归属分区，暂存、清单和日志校验先于提交指针发布。适配器先通过 `GM.saveTab` 声明唯一所有者，再查询 `GM.getTabs`，在产品 IO 前拒绝第二个展开的工作台。隐藏保留会话，实际卸载或退出页面时先冻结写入，等待保存确认后再移除自身登记；挂起标签页不按时间租约过期。产品读取、写入和删除采用异步 GM API 和串行队列，同步 GM 缓存不能作为跨标签页锁或初始权威快照。启动只创建当前格式，`GM.deleteValue` 回收旧代次分块；代理配置保存在独立运行时键中。可移植数据预检、导入后完整重载与恢复见[数据归属](../跨平台/架构/插件数据归属.md)。

- 正式键使用 `any-music:userscript:*`；GM 存储不与桌面 `product.json` 或原生凭证文件混用。代理秘密仅留本端专属配置，不进入产品快照、错误或日志。异步持久化失败后停止后续保存，并持续显示存储错误及重载提示；工作台作用域结束时移除事件监听。
- 工作台与媒体算法使用共享包；受控媒体字节通过 GM HTTP，原生流式播放按共享回退顺序执行。GM Range/MSE 的验证证据不能证明 Rust grant 播放通过。
- 原生启动器与 `document-start` 桥保持轻量，首次展开才加载产品树；T11 将宿主样式注入外层 Shadow Root，并在稳定的完整主题曲面激活共享／SFC／所选主题资源；元数据独立，可选工作室入口仅在选择后执行。隐藏保留播放/下载，真正卸载清理。详见[边界情况](架构/边界情况.md)。

## 在篡改猴中连接本地开发服务

任务明确要求浏览器检查时，在仓库根目录准备并复用真实篡改猴环境：

```powershell
pnpm setup:userscript
# 可选：选择 Edge，或只准备浏览器和扩展而不启动 Vite。
pnpm setup:userscript --browser edge
pnpm setup:userscript --browser-only
```

`scripts/setup-userscript-browser.mjs` 寻找已安装的正式版 Chrome/Edge，记住所选浏览器，使用 `.local/userscript-browser/<browser>` 中的专用持久配置启动／复用可见窗口，不使用临时自动化配置或禁用扩展的参数。请保留这个已被 Git 忽略的目录，其中包含扩展、用户脚本、管理器存储及网站登录态。命令不使用或修改日常浏览器配置。若没有浏览器，需先安装；企业策略仍可能禁止安装扩展或远程调试。

命令读取实时扩展管理状态：缺少正式版篡改猴时打开对应官方商店，等待确认安装；已安装但禁用时打开设置，不重复安装。同时检查用户脚本执行权限，请在扩展详情开启**允许用户脚本**，旧版浏览器可开启**开发者模式**，见[篡改猴官方说明](https://www.tampermonkey.net/faq.php?locale=en&q=Q209)。商店安装和权限确认只需首次手动操作，脚本不会绕过浏览器确认。`--timeout 600` 为每个准备阶段默认等待的秒数；超时以失败退出并保留配置，下次继续。Chrome 商店不可达时可改选 Edge 使用其官方商店，两种浏览器各自保留配置。

默认启动 `http://127.0.0.1:18765` 的 Vite，或复用属于当前仓库、由本命令启动的服务。端口被其他服务占用时明确失败，不静默更换地址；单独启动且没有环境标识接口的 Vite 也不复用，应停止占用服务后重试。命令打开 `gm-dev.html`，检查开发入口、`server:Any Music` 身份、真实 Tampermonkey GM 函数和悬浮入口；重试宿主页后仍未通过时才打开连接脚本安装页，首次点击**安装**即可。在同一浏览器配置中启用开发脚本、停用正式 `Any Music`，避免两个启动器竞争。只有正式脚本或预览替身的入口不会通过环境检查。

Vite 提供源码模块并随修改热更新／刷新，需要完整重启时刷新宿主页。只有服务地址／端口或生成的元数据变化时才重新安装小型连接脚本，不要每次修改都构建并粘贴正式包。Ctrl+C 停止本次命令启动的 Vite，保留浏览器与已安装配置；复用的服务仍归原进程管理。`.local/userscript-browser/endpoint.json` 记录当前本机调试地址，支持连接已有浏览器的工具应连接它，避免重新创建自动化窗口。关闭／重开浏览器后重新执行准备命令以更新地址。

`gm-dev.html` 不导入产品入口或 `platform/dev` 替身；普通 `/` 预览页仍使用开发 GM 替身。开发与正式脚本使用各自独立的管理器存储，二者内部键名都保留 `any-music:userscript:*`。开发脚本只展开一个工作台：隐藏保留写入者会话，换宿主页检查前应关闭原所有者标签页。在真实来源宿主页上检查时，继续使用同一个开发脚本。

证据应记录为**已安装开发脚本＋真实 GM 传输**，与普通预览替身、最终生产产物验收分别说明。开发插件申请的 grant 比生产元数据更广，开发 GM 通过不代表最终生产权限、打包启动和时序通过。最后统一执行一次生产构建门槛，需要验收最终产物时再单独安装该产物。

## 技能与验证

- 平台适配使用 `$any-music-userscript-runtime`，可移植来源协议使用 `$music-source-adapter`，产品 UI 使用 `$any-music-ui-delivery`。
- 先运行 `pnpm --filter @any-music/userscript test` 和 `pnpm --filter @any-music/userscript typecheck`，再完成根检查。
- 用户明确要求实站查看时才进行浏览器捕获或安装脚本回归。网页契约捕获、Vite GM 替身、实际 GM 请求分别说明；它们不验证桌面原生账号与凭证链路。

## GM 传输与代理细节

Chrome 中的小型文本 API 请求由 GM HTTP 适配器显式启用 Tampermonkey fetch 传输，避免鉴权 XHR 通道在每次请求前引入固定等待；媒体字节和依赖响应头/进度提前限流的请求继续使用 XHR。Tampermonkey 的 fetch 模式不会执行 `details.timeout`，因此适配器为两种传输统一维护可中止的应用层计时器，调用方仍只依赖 `HttpRequest.timeoutMs`。

### 单代理设置

请求代理是运行端设置，不进入 `HttpRequest`、`MusicSourcePlugin` 或平台 DTO。Userscript 将经过校验和持久化的 HTTP/HTTPS/SOCKS 配置注入统一 GM HTTP 适配器，因此平台 API、媒体完整读取和 Range 分段请求共享同一代理；关闭时不向 GM 请求传递代理字段，继续直连。凭证只保存在当前脚本的 GM 存储中，不得记录到日志或向 core、组件 props 之外的领域模型扩散。

当前实现使用 Tampermonkey 的 `GM_xmlhttpRequest.proxy`，该能力从 Firefox 版 Tampermonkey 5.5 起提供；不支持此字段的脚本管理器或浏览器会保持直连。设置界面必须明确显示该兼容性边界，不能把“已保存”表述为“代理已连通”。

## 内置限定运行策略

篡改猴在来源构造前以及激活、启用、命令、媒体和预取入口固定 `externalPlugins: none`，只装配构建目录中的功能/来源模块。产品备份和自报身份不能注册外部插件，不提供来源 JSON 安装器或归档管理页。参见[运行策略](../跨平台/架构/插件运行策略.md)。

规范曲目、歌单、标签命名空间和已发布配方独立于可选来源模块；停用或不可用的叶子明确失败，有效内置叶子仍可播放。生产依赖图排除外部安装器、Worker/WASM 执行器和公网代理，@connect 只保留内置 API/媒体域名。

页面桥只交换最小白名单 DTO，校验来源/origin、请求/目标、时效与取消。随机值只关联消息，不能认证同页代码；Shadow DOM 和 DOM 事件不授予 GM/插件权限。

运行端直接消费 plugin-source-bilibili/plugin-source-douyin 元数据及惰性 /runtime，每次 GM 操作接收取消信号；抖音捕获等待和回退页面在取消时清理。保留宿主账号、单代理、document-start 桥接及隐藏保留会话的行为。

验收检查各入口的 none 策略及真实生产依赖图；自动化与已安装 GM 证据分别报告，桌面沙盒或网页捕获不能证明本端传输验收。
