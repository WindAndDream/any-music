# 临时验收

[English](../../../en/changes/temporary-acceptance/README.md)

目前没有已记录的临时放行。待测或失败的场景见[修改内容验收](../验收/文档索引.md)。

用户明确允许带已知缺口先推进时，将变更移到这里，状态设为 `temporary-accepted`。写明允许范围、决定与日期、未测或失败场景和下一次复验。放行行为对用户可见时，在所属板块链接此记录。复验移回[修改内容验收](../验收/文档索引.md)，要修复则移回[内容修改中](../修改中/文档索引.md)。详见[变更流程](../../开发指南/文档变更流程.md#验收与收尾)。
