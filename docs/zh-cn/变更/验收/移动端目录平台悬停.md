# 对齐移动端目录平台悬停背景

[English](../../../en/changes/acceptance/catalog-platform-hover.md)

经典主题发现歌曲页的平台悬停底色随文字宽度变化。根据截图反馈，底色上下各留 4px，左右各留 8px。平台文字保持原有对齐，详情按钮保留 44px 的最小高度。

- [x] `pnpm --filter @any-music/theme-default test` 通过 573 项测试，包含悬停留白样式回归。
- [x] `pnpm --filter @any-music/theme-default typecheck` 和 `node scripts/check-package-boundaries.mjs` 通过。
- [x] `pnpm build:userscript` 和 `pnpm --filter @any-music/tauri build:frontend` 通过。
- [ ] 在移动布局核对 `抖音` 和更长平台名称的新版悬停底色，再打开列表详情。
