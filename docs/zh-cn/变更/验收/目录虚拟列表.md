# 目录虚拟列表验收

[English](../../../en/changes/acceptance/virtual-catalog-lists.md)

**待验收。** C08／C20 已接入经典的请求卡和非抖音歌曲结果。C08／C09 也接入桌面抖音的应用内结果与 Windows 子 WebView。调用方见[虚拟列表](../../板块/界面/虚拟列表.md#当前使用情况)。

- 经典请求目录检查完整筛选顺序、分组重排、操作和返回位置。非抖音歌曲结果检查按需续页、筛选、重试、短／空页及无重复请求。
- 桌面抖音结果页检查未过滤首视口在现有页数／时间预算内填充，主／子窗口滚动位置交接、焦点、弹窗、已加载和过滤计数、末页及返回应用和原控件。单独测有过滤条件的分页。
- 保留实际滚动根、样式、键盘／触摸语义及[来源网页会话](../../板块/桌面与移动端/来源网页会话.md)的操作边界。记录引擎、实际构建和结果。
