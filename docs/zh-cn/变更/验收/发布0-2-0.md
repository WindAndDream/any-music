# 发布 0.2.0

[English](../../../en/changes/acceptance/release-0-2-0.md)

将 `origin/develop` 在 `066852a` 的集成内容经 `main` 发布。此次次版本包含内嵌抖音账号和发现页流程、合集筛选历史、列表虚拟化和自动跳过不可播放的曲目。

macOS 应用从此版本起要求 macOS 14 或更新版本。

- [x] 同步用户脚本和 Tauri 产品版本，并将 Android `versionCode` 升至 `4`。已通过 `pnpm check:release` 校验发布清单。
- [x] 在 Windows x64 上使用 Node 24.22.1、pnpm 10.23.0 和 Rust 1.91.1 完成本地验证。`pnpm privacy:setup`、`pnpm check:privacy`、`pnpm check:privacy:history`、`pnpm test`、`pnpm lint`、`pnpm format:check`、`pnpm build`（包含 `pnpm typecheck`）、`pnpm check:native`、`pnpm check:rust:msrv` 和 `pnpm check:rust:deny` 均已通过。
- [ ] [Android 编译修复](Android发布编译.md)进入发布分支后，验证[发布 PR #34](https://github.com/WindAndDream/any-music/pull/34)并记录候选构建结果及验收。
- [ ] 合入 `main`，发布对应的注释标签 `v0.2.0`，核验 GitHub Release，并将 `main` 回合并到 `develop`。

下一步通过发布 PR 验证候选构建矩阵，并记录维护者和测试者对对应提交的验收。已安装运行时和设备实测待完成。
