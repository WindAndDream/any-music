# 移除工作室界面和残留实现

[English](../../../en/changes/acceptance/retire-studio-ui.md)

旧 Studio 界面、两端应用注册和 Windows 目录结果子窗口分支已移除。用户启动[工作室重新设计](../../板块/界面/独立主题开发.md)前，日常交付覆盖经典主题和共享契约。已保存的 Studio 选择在启动时回退为经典主题，各主题的设置映射继续保留。

已删除被完整根替换的旧目录、资料库和下载面板，以及登录试验的旧界面与 IPC。[独立 Rust 试验](../../板块/桌面与移动端/账号与代理.md#windows-开发版后台登录试验)依然可用。两端撤下已禁用的创作工作区，保留素材、草稿和配方逻辑。已有资料库引用中的已发布作品继续通过宿主播放和下载。两端的列表展示偏好通过当前宿主存储键保存。

## 验证

- `pnpm test` 已通过。共享 Node 测试覆盖经典主题重新挂载、主题回退、偏好存储、筛选、分页、播放和下载连续性。创作测试覆盖草稿持久化及已发布配方。Tauri 的 Rust 工作区测试和 TS／Rust 协议对照检查已通过。
- `pnpm build` 已通过，包含工作区类型检查、用户脚本生产包和 Windows Tauri 生产可执行文件。检查两端前端构建图和 Windows 结果子窗口脚本，均使用经典资源并移除了旧界面。
- `pnpm lint`、`pnpm format:check`、`pnpm check:native`、`pnpm check:rust:msrv` 与 `pnpm check:rust:deny` 均通过。锁定的 pnpm 工作区可离线解析。

用户要求实测时，在[已安装篡改猴](用户脚本主题.md)和 [Windows](Windows主题.md) 中验证已有 Studio 偏好时的经典主题启动。[Windows 结果视口交接](目录虚拟列表.md)和 [Android](Android主题.md) 场景按各自验收记录执行。
