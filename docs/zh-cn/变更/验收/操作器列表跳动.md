# 修复切换操作器时列表跳动

[English](../../../en/changes/acceptance/operator-list-jump.md)

在待听打开、关闭或反复切换操作器时保持列表位置稳定。检查用户脚本和 Tauri 经典主题中共用操作器的其他板块。

- [x] 追踪公共底栏高度和操作器的使用范围。
- [x] 在播放器区域提前预留操作器所需的最小空间，切换操作器时保持内容视口高度。
- [x] 运行经典主题布局回归并构建两个运行端的前端。
- [x] 在 Tauri 开发版实际滚动并复现剩余跳动。
- [x] 切换操作器时保留虚拟列表测量结果，验证受影响板块并实测复验。

Windows Tauri 开发版滚动后打开操作器时，可见歌曲向上跳动约 147 CSS 像素，列表视口和底栏高度保持稳定。选择模式变化导致虚拟列表丢弃已测高度。待听、我的喜欢、歌单详情、平台概览、播放历史、下载和发现的两级列表现在均在切换时保留测量值。

待听、我的喜欢、我的歌单概览与详情、播放历史、下载、发现的音乐列表与歌曲结果、标签管理和插件中心均使用这套底栏。

在 Windows Tauri 开发版使用 174 首歌曲的待听列表验证，覆盖 1280 和 510 CSS 像素宽度下的列表顶部、中部和底部，并在滚动后快速切换 12 次。逐帧采样中，切换期间的滚动偏移和采样卡片位置变化均为 0。Escape 关闭后焦点回到入口。我的喜欢、播放历史、发现的音乐列表和插件中心通过滚动后切换检查。下载、我的歌单概览和标签管理使用现有数据通过基本切换检查。

新增的待听回归用例在修复前测得 176 像素的滚动偏移变化。修复后 `pnpm --filter @any-music/theme-default test` 的 576 项测试及该包类型检查通过。`pnpm build:userscript:dev` 和 `pnpm build:userscript` 构建通过。

`pnpm build:tauri` 生成了 Windows 发布版可执行文件。在该产物的桌面和窄窗口布局共切换 12 次，滚动偏移和采样卡片位置保持稳定。根目录 Lint 和格式检查通过。

已安装的用户脚本、长下载和歌单列表、按平台分组仍待实测。
