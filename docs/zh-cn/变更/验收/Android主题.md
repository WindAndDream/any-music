# Android 主题验收

[English](../../../en/changes/acceptance/theme-android.md)

**待验收。** 先前[调试真机](../../../baselines/theme-ui-migration/T13-android-followup.json)与[签名优化版](../../../baselines/theme-ui-migration/T13-runtime-followup.json)覆盖主题切换、保存和部分原生操作。各项结果以记录中的构建和输入为准。
