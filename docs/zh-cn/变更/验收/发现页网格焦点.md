# 正式版发现页网格焦点

[English](../../../en/changes/acceptance/catalog-grid-focus.md)

修复 Windows v0.2.0 哔哩哔哩结果首次进入卡顿、打开歌曲操作卡住，以及返回发现页目录空白的问题。提供本地正式模式的构建和启动命令。

- [x] 使用正式版 Vue 模板引用，复现行快照更新引起的重复注册。
- [x] 检查经典主题其他板块，仅在实际输入改变时更新网格单元格和表格行注册。
- [x] 运行共享 UI 和经典主题测试及类型检查，再构建两个运行端的生产产物。

网格单元格和表格行组的注册监听均比较模板引用的值。相同行快照更新时，网格测试在修复前注册两次交互，修复后只注册一次。表格测试在修复前撤掉五个监听，修复后保持原有监听。交互代际变化时仍会重新注册。

Windows 和用户脚本正式版的发现页使用共享网格，Windows 抖音结果子 WebView 也使用它。待听、我的喜欢、我的歌单、下载及播放历史在开发配置下使用共享虚拟网格，正式版使用全量列表。当前产品尚未接入共享虚拟表格。源码检查未在其他经典板块发现同类注册循环。

- `pnpm --filter @any-music/ui test --maxWorkers=2` 通过 1106 项测试。`pnpm --filter @any-music/theme-default test --maxWorkers=2` 通过 576 项测试。
- `pnpm --filter @any-music/ui --filter @any-music/theme-default typecheck`、`pnpm build:tauri` 和 `pnpm build:userscript` 均通过。
- Tauri 目录 WebView 和页面遮罩测试通过 9 项。用户脚本启动和内置主题测试通过 7 项。已在 Windows 主界面、目录子窗口脚本和用户脚本的生产产物中确认修正后的监听。

下一步是在生产构建后运行 `pnpm start:tauri`，搜索哔哩哔哩，进入歌曲结果，打开和关闭歌曲操作，然后返回发现页目录。新构建的可执行文件及已安装用户脚本的运行态检查待完成。
