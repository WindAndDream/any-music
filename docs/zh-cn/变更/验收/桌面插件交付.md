# 桌面插件目标与安装器验收

[English](../../../en/changes/acceptance/desktop-plugin-delivery.md)

**待验收。** 旧 Windows 准入只适用于记录中的系统、WebView2、Profile、资源及原生宿主标识。Profile 的预算验证修改后不能沿用。当前能力由原生检查和[交付矩阵](../../板块/插件/工具与桌面交付.md)决定。

| 工作                   | 证据和要求                                                                                                                                                                                                                                                                                                                                                          |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 重新验收执行／安装目标 | 重跑精确目标的隔离、访客交付前的原生资源过滤、relay 和权限拒绝、安装／升级／回退／撤权／恢复、命令与目录取消，以及隔离 DEV。保留原范围的[目标准入](../../../baselines/plugin-system-s15/target-admission.json)、[桌面实测](../../../baselines/plugin-system-s15/desktop-acceptance.json)和[对话框证据](../../../baselines/plugin-system-s15/desktop-dialogs.json)。 |
| 验收实际系统安装       | 有选定安装产物后检查文件关联、深链接、选择／打开／保存和原生同意。已配置关联与直接启动的证据还未覆盖系统注册。                                                                                                                                                                                                                                                      |
| 发布前复验工具         | SDK／CLI／testkit 可本地打包。[独立工具证据](../../../baselines/plugin-system-s15/tools.json)与 [SBOM](../../../baselines/plugin-system-s15/toolchain-sbom.json)用于依赖及打包对照。注册表发布属于[未来计划](../../计划/未来/外置插件扩展.md)。                                                                                                                     |

下一步确认当前候选的精确标识，在收到实测请求后重跑该目标场景。[网关检查](桌面来源认证.md)单独覆盖账号和传输。
