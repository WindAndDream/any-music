# 插件匿名联网

英文对应页：[Anonymous Plugin Networking](../../../en/cross-platform/architecture/plugin-networking.md)。本页维护原生匿名传输及出口约束，实际能力准入见[桌面交付](插件系统重构S15工具与桌面交付.md)。

## 原生授权与数据组合

`am-plugin-runtime` 在身份、epoch、上下文及来源账本中保存 network_grants、exits 和 outbound_audit。应用直接初始化 plugins.sqlite3 schema 3；原生 NativeGate 绑定真实通道、对象上下文、出口类型及不可反序列化的 ExitPermit，插件不能自报身份、敏感等级或确认。

先验收 L0，再验收 L1 与联网的独立组合批准，最后验收 L2 声明和最高风险的独立批准。检查同时考虑读取授权上限、当前选中字段、历史交付、保留命名空间与发布者/插件 lineage。收窄域名、撤销读取或把私密备注编码成宿主标题都不能降低风险。离线历史不明按 L2；秘密拒绝。连续 90 天未用、过期或时钟回退的网络授权拒绝，不因一次检查刷新使用时间，实际消耗请求或字节才刷新。

每个会话最多累计 64 次派发和 128 MiB，已结束请求仍计入累计量；每安装最多 4 个、全局最多 16 个活动出口。每次重定向、资源读取、Range、重试和字节交付重新检查身份、epoch、期限和组合授权。撤权先提交原生新 epoch，再取消该安装的 token，最后确认；最终宿主 sink 交付与撤权共用应用 authority 串行屏障。已发出的字节无法收回。

## 匿名传输与 SSRF

`am-plugin-net` 是独立 IO crate，不依赖 Tauri、runtime、账号、vault、CDP 或 SQLite。Gate 由原生应用注入。所有请求都使用新建的无 Cookie 客户端，关闭环境代理、自动重试、自动重定向、连接复用、HTTP/2 合并和自动解压。没有共享或账号 Cookie jar，不保存 Set-Cookie，不暴露 HttpOnly。当前 SDK 未声明的 cookieJar、来源 Authorization、用户 API 密钥能力均不开放；不为它们新增临时授权。

Profile 1 只允许 HTTPS 443、GET/HEAD/POST，URL ≤ 8 KiB、头总量 ≤ 16 KiB、POST ≤ 1 MiB，最多 3 跳重定向。普通 API 响应 ≤ 4 MiB，资源单次读取 ≤ 64 MiB，30 秒总期限与 10 秒连接期限均含在同一次请求中；资源还受会话累计预算约束。媒体/下载只允许 GET/HEAD 与有界单段 Range，POST 不自动重试。

URL 与声明主机统一用 Rust url 解析，规范化 IDNA、大小写、尾点和默认端口，主机精确匹配，不支持通配符或自动包含子域。

版本化地址策略 `public-targets-1/2026-10-18` 拒绝凭证 URL、控制字符、非常规 IPv4、环回、私网、链路本地、共享地址、文档/测试/保留地址、映射 IPv6、标准 NAT64、6to4 等转换地址。IPv6 仅保守接受普通全球单播范围；已知特殊段继续排除。全部 DNS A/AAAA 候选必须通过检查，再绑定已验证地址连接；TLS 始终验证原主机名，响应实际 peer 再检查。每跳重新解析与校验，CNAME 最终地址同样受限。

首版 HTTP/SOCKS/系统代理路径全部返回 Unsupported，没有代理端 DNS 或弱模式回退；不能证明的地址转换或代理拓扑不属于已验收路径。没有用不传凭证代替公网目标校验。reqwest 的配置依据见[锁定版本文档](https://docs.rs/reqwest/0.12.28/reqwest/struct.ClientBuilder.html)，实现与测试使用 Cargo.lock 的版本。

地址分类核对 [IANA IPv4](https://www.iana.org/assignments/iana-ipv4-special-registry) 与 [IANA IPv6](https://www.iana.org/assignments/iana-ipv6-special-registry) 特殊用途注册表；本实现的保守拒绝范围比注册表中的非全球可达项更宽，不把“全球可达”视为当前网络上的连通性证明。

## 媒体、图片与其他出口

沙盒请求、声明式请求、图片、媒体和下载共用 Gate。Resources 只持有内存中的随机 ResourceRef、URL 和原生 lease；引用不提供序列化或持久化接口，不进入 Track、命名空间、下载历史或磁盘路径。Range、备用读取和再次读取共用同一个 lease；释放、撤权和注册表清理取消读取。图片只接受受限栅格 MIME，不能把外置 URL 交给 RemoteImage、audio 或通用下载器直接联网。

外链与任意宿主写入出口拒绝；受控文本结果／诊断导出通过原生保存对话框并重检 epoch。受限标题注解仍通过原生版本化提交并保留数据来源标记，联网后的私密组合在读取/提交点也要重检。没有新增通用业务写或 OS 打开接口。

通用 http_request 的 omit 只接受当前原生媒体端口的本机随机 grant 地址，匿名 register_media 被拒绝。 外部插件使用原生验证身份和 Gate；内置来源保持账号绑定，具体准入由桌面交付矩阵决定。

出站记录只保存安装、时间、SHA-256 主机标记、出口类别、状态码类别、累计字节与拒绝标志；没有路径、查询、头、正文或原始错误。记录在本机独立 DB 中保留最多 30 天/1024 条。不向插件开放日志读取或自动遥测；受控诊断导出和验证安装通过原生交付端口，不增加通用客体出口。

## 验证边界

测试伪造主体、L0／L1／L2 次序、历史来源、epoch／过期、闲置挂起、累积预算、持久撤权、混合／重绑定 DNS、TLS 固定身份、代理拒绝、重定向、不重放 Cookie、Range 及流中取消。测试 CA／连接替换仅限 `cfg(test)`。本地 TLS 替身不建立公网或精确 WebView／设备验收。
