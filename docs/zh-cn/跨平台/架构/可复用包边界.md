# 可复用包边界

`music-workbench` 是正式 Userscript 与 Tauri 的公共产品组合层，依赖 core/ui/audio-composition/plugin-center；可信契约适配另消费 plugin-sdk，以端口注入 HTTP、存储、登录、媒体和文件保存。禁止导入应用、GM、Node、Tauri 或 Electron；浏览器媒体由渲染端按需加载。账号调度组合现归 `apps/tauri`，篡改猴继续单账号/单代理。详见 [Tauri 运行端](../../桌面端/运行端架构.md)。

英文对应页：[Reusable Package Boundaries](../../../en/cross-platform/architecture/reusable-package-boundaries.md)。

项目使用 pnpm workspace、catalog 和递归脚本。共享职责分为音频、插件、来源、账号与网络调度。业务包是消费端构建的私有 TypeScript 源码包；SDK/CLI/testkit 0.1.0 可本地打包，尚未发布到注册表。

## 动态呈现边界

工作台新增依赖 `plugin-ui-vue`；该包只依赖 ui、plugin-sdk 与 Vue。根入口渲染受限 DTO，`/trusted` 装配随应用构建的主题和页面出口，`/directory` 保持无 Vue/样式。ui 仅定义受控呈现与贡献注入契约，不反向依赖 SDK 或插件框架。注册表仍只保存描述，不持有组件或业务实例。

## 包与入口

`VirtualTrackCardGrid` 可通过 `interaction` 组合已挂载单元的焦点／输入法保留，通过 `anchor`／`anchorResetKey` 组合稳定键补偿，两者默认关闭。组件向消费方暴露相同的保留／锚定端口供排序和主动导航使用，在既有上限内合并保留索引，并接受 `animate` 在落地交接期间暂停键控位移；可选集合布局独立保留集合卡片列宽／间距，不混用歌曲布局。`useQueueReorder` 转发可选虚拟几何、显式视口、保留及可取消焦点端口，默认仍使用 DOM 适配器。实时测量几何按空间代次刷新同身份行高，并重基指针／松手位置；不兼容的布局／根／身份变化仍取消。经典主题“我的喜欢”的歌曲和平台概览候选通过主题私有且默认关闭的门禁使用这些端口，生产准入仍开放。

轻量 `ui/theme` 连续性契约注册临时的出现项／偏移／控件适配器，不导入 Vue 或虚拟器。`ui/library` 持有渲染器辅助逻辑，消费注入的完整虚拟几何或原生项盒子；各主题提供自己的稳定出现项／控件映射。`plugin-ui-vue` 的可信展示事务取消旧任务并等待恢复，包括先挂载保留的离屏目标、再恢复焦点。恢复期间以租约暂停普通锚定，独占滚动写入，在完成／取消时释放；测量对齐有上限，无法收敛时明确失败。经典主题的同步桥等待惰性候选就绪，不把一轮渲染视为加载完成；概览返回复用相同的临时语义契约，中性返回元数据由既有编辑会话所有者保留，贯穿展示替换。快照、测量缓存与恢复任务不进入产品持久化，也不提交业务命令。C00 的自动集成不建立原生焦点／布局验收，也不为其他入口准入。

`ui/virtual-scroll` 持有仅供渲染器使用的共用滚动上下文、纯出现项／逻辑行几何、固定／测量列表、响应式测量网格、原生表格几何、可选语义锚定及有界交互保留。调用方注入已有滚动根、列表和有界前置标题，不向该入口传入业务／存储／运行端权威。列表／网格快照提供完整数量／长度及不可变稳定键几何，普通滚动不重建源索引。自然边框盒高度使用展示内缓存（默认 512 项），受当前宽度／布局／内容代次约束；仅同行项的带类型集合变化使对应拉伸高度失效，行内换位及无关已测量行保留有效高度，避免排序时滚动范围短暂坍缩。`VirtualTrackCardGrid` 通过公共组件子路径使用，CSS 仍决定密度／手机布局／列数，单元保留扁平稳定键父层，挂载行采用自然 auto 轨道，未挂载区间压缩为轨道；受控网格将隐式列固定为 `0px`，CSS 读取器仅在该契约下排除尾部零宽轨道，避免旧定位在缩列后维持过时列数；仅在虚拟测量表面停用内容可见性占位。`useVirtualScrollAnchor` 按稳定键／项内偏移补偿，输入、原生滚动、重置代次和展示替换取消旧任务，原生锚定禁用以租约共用并恢复。`useVirtualItemRetention` 默认保留 8 个不同活动项，可配置至 32，原始保留索引端口同样上限 32；调用方持有编辑／菜单会话，仅注册挂载目标，按键聚焦校验实际当前焦点并清理迟到任务。滚动根／就绪状态交接使旧注册失效，仍保留的稳定键网格单元在交接后重新注册。网格出现项保留对应逻辑行。这些 API 均为可选组合，分页消费完整几何而不增加测量，生产接入及原生焦点／布局等价性仍见[虚拟列表方案](虚拟列表与布局性能实施方案.md)。选定虚拟器仅归 UI，不进入元数据或 `ui/theme`。

`useMeasuredVirtualTable` 复用测量列表的唯一高度权威，推导包括调用方声明的表头／表尾数量在内的完整物理行位置。`VirtualTable` 使用合法原生表格分区、固定列布局、零间距、表题／表头下方的稳定起点、稀疏占位区间和包含主行／详情行的稳定键自然 `tbody` 单元；普通主题单元格规则不能给结构占位增加内边距／边框。调用方通过列插槽提供列宽，并提供准确物理行数、内容代次和原生行 ARIA 索引；`rows` 插槽保留既有 `tr` 组件。跨行合并须在一个逻辑测量单元内。行数变化自动使整体高度失效。原生列宽／吸顶／辅助技术树验收及消费入口语义宿主恢复仍开放。

`card-styles -> ui/core` 持有可复用的受控音乐／歌单卡牌。根入口提供无框架风格元数据和纯进度归一化，`/vue` 导出卡牌与只读展示注入。主题通过该包复用卡牌，不互相导入。卡牌只发出意图，不持有弹窗、播放、下载状态或保存逻辑；UI 持有可扩展的展示分类弹窗，工作台独立保存各板块／风格位。共享 SFC 资源收集器为两个正式运行端收集这些作用域样式。

正式组合使用公开 ui/theme 只读功能契约与应用持有的完整主题注册。theme-default／theme-studio 分别拥有独立根组件、页面与样式；正式工作台不导入任一实现。plugin-ui-vue/trusted 持有唯一通用事务和隔离的展示／受保护曲面。应用预加载经典回退并动态加载工作室，元数据根不执行 Vue／样式。构建持有的 SFC 资源收集器匹配模板作用域 ID，向曲面提供惰性 CSS 字符串。UI 和专业插件保留中性控件／编辑，宿主控制器保留业务／媒体／下载／存储权威。已移除局部映射／加载器／分派，仅在 theme.root 准入完整定义；经典页面／歌曲行样式与创作时间线控件样式分别归所属包，UI 保留中性控件和固定宿主曲面。T13 负责实机验收。见 [主题开发](独立主题开发指南.md)。

`account-pool` 拥有公开账号身份、操作策略与租约，`network-routing` 拥有有界请求竞争与被动代理健康。`account-pool -> network-routing`，后者无内部依赖；两者无 DOM、Node、GM、凭证或音乐模型，运行端注入时钟与传输。Tauri 已接入账号竞争和独立代理，代理组尚未开放，详见 [桌面账号与代理](../../桌面端/运行端架构.md#账号与验证)。

## 音频拼接复用

```ts
import { compileSegmentRecipe } from '@any-music/audio-composition'

const segments = compileSegmentRecipe([{ sourceTrackId: 'voice', startMs: 0, endMs: 2000 }], {
  resolveTrack: () => ({ durationMs: 3000 }),
  resolveCustomTrack: () => undefined,
})

// 仅在需要导出时加载浏览器编码器；voice 也可以是语音、音效或本地资产 ID。
const { exportAudioSegments } = await import('@any-music/audio-composition/browser')
const file = await exportAudioSegments({
  title: 'Composition',
  format: 'wav',
  segments,
  loadSource: async (id, { signal }) => readApplicationAsset(id, signal),
})
```

示例中的 `readApplicationAsset` 由消费端实现，返回 `{ bytes: Uint8Array }` 并处理取消。编码管线适用于显式导出和播放的最终兼容兜底，完整输出保留在内存中，不应用于普通首播。流式播放继续使用有界时间线、并发预取和应用持有的音频时钟，共享媒体会话与 Range 算法由 music-workbench 持有，实际 GM 读取或 Rust 媒体 grant/取消由运行端注入。

`core` 持有公开音乐适配器 `compileSegmentRecipe`：它校验叶子必须是普通曲目，并把独立引擎错误转换为 `AppError`。时间线算法只有 audio-composition 一份实现。UI 的导出格式类型也来自音频包纯入口。

## 插件中心复用

通用 `PluginCatalog` 不执行第三方代码、不授予域名权限、不读取存储。它可以管理文档导出等非音乐插件。音乐适配层额外接受 `builtInPlugins` 及经过原生验证的运行时投影；Vue composable 只同步快照，并在作用域销毁时退订。最新可用性检测拥有状态发布权，过期请求不能覆盖新检测、删除或重新安装后的状态。

当前产品快照保存宿主资料和插件命名空间；外置 `.amplugin` 清单与安装状态归原生包存储，可移植产品数据不携带这些内容。两端都不装配旧来源 JSON 解释器、安装器或归档界面。桌面外置目录走原生包事务与具名端口；Userscript 仅包含内置插件。见[数据归属](插件数据归属.md)与[运行端策略](插件运行策略.md)。

## SDK、执行与工具包边界

plugin-sdk 的根与 /music 无框架、core 或运行端依赖；/schema 使用生成校验器，/node 只供 Node 包校验，/guest 与 /host 只适配 DTO 连续执行。music-workbench/src/plugin-adapters 转换 core/wire 并通过具名原生端口接入 S15 目录，不授予权威。版本与支持能力见[S15 记录](插件系统重构S15工具与桌面交付.md)。

下表列出现有包的职责；真实依赖白名单以包清单与 scripts/check-package-boundaries.mjs 为准。完整目标设计见[插件系统重构计划](插件扩展与安全契约.md)，未提供能力不能从包已存在推导为可用。

| 模块                   | 采纳的职责与依赖约束                                                                                    |
| ---------------------- | ------------------------------------------------------------------------------------------------------- |
| plugin-sdk             | 无框架 Manifest、贡献、线协议、执行器端口；/music 只放可序列化 DTO；不导入 core、Vue 或运行端           |
| plugin-center          | 通用身份、生命周期、贡献和授权显示缓存；只依赖抽象端口，不导入具体 Worker/WASM，也不充当 Tauri 授权权威 |
| plugin-vm              | SDK 与固定 QuickJS；共用预算、桥和序列化，/profile 与 /control 无引擎                                   |
| plugin-sandbox-browser | 可信 Worker 适配，依赖 SDK/VM；Tauri 按 S15 精确目标准入；Userscript 不包含                             |
| plugin-ui-vue          | 声明式贡献渲染，依赖 SDK 与 ui 公共出口；ui 不反向依赖它或具体插件                                      |
| 功能/来源插件          | 根入口保持轻量；专属状态、规则、页面归所属插件，可信 Vue 页面走 /vue；外置包只获得公开 SDK              |
| am-plugin-protocol     | SDK Schema 生成的原生 DTO、版本和有界校验；无传输或业务权威                                             |
| am-plugin-policy       | 无 IO 的主体、操作、范围、风险和预算决策；时间与可信快照由调用方注入                                    |
| am-plugin-runtime      | 通过 Store/Clock/Ids/InstallFiles 排序安装、授权、上下文、来源追踪及提交/撤权；无具体 IO                |
| am-plugin-net          | 匿名 HTTP、公开目标与有界传输校验；原生 Gate 提供权威；无账号凭证或代理                                 |
| am-plugin-package      | 有界包/资源校验、完整性与签名；无安装/授权权威、联网或执行                                              |
| Tauri 原生适配器       | 通过公开 crate 契约组合具体 SQLite、文件系统、HTTP、账号隔离、调用方校验、同意和 Gate                   |
| plugin-testkit / CLI   | testkit 复用 SDK/VM，仅 Node 测试宿主；正式运行端不能依赖。S15 已验收 CLI/离仓产物，尚未发布到注册表    |

当前 core 音乐模型与 SDK DTO 在可信宿主适配层转换，不让 SDK → core → SDK 或 core → plugin-center → core 成环。MusicSourcePlugin 是宿主当前来源契约；不复制时间线、错误目录、下载调度或存储实现，不新增旧架构读取器或转发包。内置来源的账号/页面能力仍由应用单独注入，不因为与外置来源共用贡献点而公开。

包边界脚本、公共 exports、轻量入口测试与两端消费构建随每个迁移批次一起更新。SDK 的成立依据是此次明确的外部协议需求，不能据此顺带把所有 core 模型、工具和媒体实现再拆一遍。

## 音乐源与运行端

运行端使用 `new BilibiliApi(httpClient)` 或 `new DouyinApi(httpClient, getRequestState, getPageSignature?, getTargetCookieState?)`。抖音页面回退作为 `DouyinMusicSourcePlugin` 的可选能力注入。Userscript 的工厂继续注入 GM HTTP、浏览器快照、页面签名和目标 Cookie；`document-start` 桥接、`GM_*` 权限和持久化键都留在应用。

Tauri 向内置来源注入账号 Rust HTTP、本地签名和原生 CDP catalog 端口；抖音会话/搜索、已支持的个人列表和作品详情由账号系统浏览器捕获，媒体字节仍由 Rust HTTP/grant 读取。此桌面抖音路径不复用 Userscript 页面桥，也不证明移动登录受支持。外置包只通过原生 Gate 匿名联网。媒体解析与导出从解析阶段起透传取消。

## 继续拆分的判断

- **后续用户／Web／服务：** 本地用户作用域、绑定验证和核心写入权威留在宿主；提供方登录、同步、分享、报告归可选集成与独立服务。为 Web 提取无 Tauri 的宿主用例／API 适配，不让 core 或 workbench 依赖提供方实现；`account-pool` 仍是来源账号抽象。不据此新增包或能力，见[规划提案](多用户与本地云端部署规划.md)。
- **媒体运行时**：Userscript 与 Tauri 渲染端已共用 music-workbench 的 Range、解码和时钟调度；HTTP、取消、媒体授权由各端注入。只有出现非音乐消费端时，再独立为通用媒体包。
- **下载调度**：当前重试、并发和取消已经在 core；没有非音乐消费者前不额外拆一个只转发函数的包。
- **设计系统**：基础组件与产品面板仍在 ui；出现独立发布或明确多产品消费者后再拆，当前用子入口和异步加载维护打包边界。
- **契约包**：外置线协议已由独立 SDK DTO 与宿主可信适配持有；若以后下沉 Track、HTTP 或错误模型，须整体迁移全部消费者、避免循环依赖，并有独立的实际复用需求。

## 验证与性能

`pnpm lint` 先运行包依赖和入口图检查，禁止共享包导入应用别名、越界相对路径、未声明内部依赖和非公开出口，并验证纯音频入口、通用插件入口与来源描述符不静态加载 Vue/编码器/浏览器提供器。单元测试随实现迁入各包的 `test/`，应用保留组合与运行端回归。

新增回归覆盖独立资产拼接、真实 PCM 编码、混合采样率、重复素材只读取一次、取消、MP3 初始化失败重试、重复检测竞态以及大规模嵌套配方。窗口选取移除线性 `indexOf` 回扫；大配方展开避免展开运算符的参数数量上限；预取失败后停止领取后续任务；无效输入和时间线溢出在编码前被拒绝。

本页描述模块契约；各阶段自动化与运行态证据分别见专项记录。整理文档不新增实站、宿主页或设备验收，不更新平台 captureDate。
