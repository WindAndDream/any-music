## 剩余交付工作

桌面声明式来源网关已实现带版本的二维码、凭证、短信认证、明确的免登录策略、原生 Token 归属及账号绑定分页。内置账号需登录后加入列表，Profile 删除改为后台回收。实现有离线测试；真实网关与更新后的精确目标准入仍需独立验收。参见[音乐源认证](../../桌面端/音乐源认证.md)。

### 独立主题验收

两个生产运行端均在稳定业务、媒体、下载及编辑归属之上使用完整 Classic／Studio 主题。[开发指南](独立主题开发指南.md)维护实现契约，[T13 验收](独立主题UI迁移计划.md#当前验收状态与后续安排--2026-11-01)维护逐构建证据及剩余 GM、人工输入、原生对话框和移动用例。历史通过不接受当前工作树。

### 其他交付工作

外部目录目前不解析媒体。注册表发布、系统安装关联和渠道验收属于后续工作。Android 已接通 B 站账号/代理/前台媒体，参考设备签名优化版已有原生代理、保存及部分[播放／音频中断验收](../../桌面端/Android音频中断与播放验收.md)；更广媒体/代理/设备与真实通话/耳机/压低音量验收、最低设备/执行/渠道退出及 iOS 账号/媒体验收仍待完成。Android 要求 API 26、WebView 111+；已有模拟器和参考设备证据不授予手机外部执行准入。

[设计](插件扩展与安全契约.md)描述完整目标边界，包含尚未支持的扩展；产品实际行为以精确能力/目标矩阵为准。实施剩余功能时保留当前数据/权限事务及运行端传输隔离。

### 本地用户、独立服务与 Web 提案

[本地／云端规划](多用户与本地云端部署规划.md)维护 A01–J04，均未开始。它将宿主本地用户／隔离／绑定验证与可选账号提供方、同步、分享、报告插件及服务分开，同时保留后端／Web 拆分。当前 profile 显示名设置不是本地多用户切换。这些是后续契约，不计作 S15／S16 已交付，也不授予当前秘密／私网／跨插件权限。

## 验证

执行目标测试及根五项检查；原生修改另跑 native/MSRV/deny。当前代次写入、插件安装/更新/回滚和撤销执行故障注入；来源/播放变更覆盖请求数、顺序、并发、取消与重试。真实应用、浏览器和设备检查须明确授权。测试、产物和实机证据分别报告，不使用历史测试数量证明当前验收。
