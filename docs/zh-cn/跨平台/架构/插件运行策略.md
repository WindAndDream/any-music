# 插件运行策略

英文对应：[Plugin Runtime Policy](../../../en/cross-platform/architecture/plugin-runtime-policy.md)。

内置身份只能来自应用构建目录，名称、签名和自报字段均不能产生内置身份。可选标签、创作、来源模块共用生命周期及贡献管理；必需宿主模块不能停用或删除。

油猴端固定 `externalPlugins: none`，只构造随产品发布的插件。生产依赖图不包含外部安装器、解释器、VM/执行器资源或匿名公网代理。GM 请求、单宿主账号/代理、document-start 桥接和隐藏保留会话仍由运行端负责。

Tauri 在组合前通过 `runtime_capabilities` 获取形态、传输和外部插件策略。精确准入的桌面目标返回 `sandboxed`，其他桌面目标返回 `declarative`，移动端返回 `none`；原生安装仍拒绝未经准入的目标。策略字符串和渲染端来源投影不能创建安装或授权权力。

外部插件只使用 `.amplugin`、原生字节校验及显式原生同意。已支持的声明式包包含当前静态目录；代码目录通过固定 VM/Profile 和命名原生端口执行，目前均不提供媒体解析。当前包预览仅接受有界插件包字节，不提供来源 JSON 安装或归档管理。

来源注册表只接收内置实例和原生验证后的运行时投影，不能安装原始清单。注册前以及激活、启用、可用性检测、媒体解析和预取入口都执行策略。替换原生代次先释放旧游标和媒体生命周期，外部目录不能进入后台媒体预取。

内置 HTTP 通过所属 GM/Rust 传输并显式包含凭证。通用访客联网保持匿名，由原生 Gate 执行目标、预算及撤销检查。独立准入的[声明式来源网关](../../桌面端/音乐源认证.md)使用来源专属原生凭据及明确的来源／联网同意，不建立产品用户／账号系统绑定。原生内置来源适配器拥有绑定账号的媒体授权；渲染端不再以匿名方式重新注册任意地址。

实际能力参见[S15 能力与准入证据](插件系统重构S15工具与桌面交付.md)和[S16 手机工程](插件系统重构S16手机交付.md)。单元测试和构建不代表真实 GM、WebView 或设备验收。

[后续本地用户／服务提案](多用户与本地云端部署规划.md)将独立账号、云同步、分享与报告交给可选插件／服务，不授予当前能力。秘密注入、私有服务连接、私密数据出站及跨插件服务需分别设计版本化能力并完成运行端验收。本地用户切换和绑定验证权威仍归宿主；现有匿名联网及 Userscript／手机限制保持有效。
