# 插件无权限执行

英文对应页：[Permissionless Plugin Execution](../../../en/cross-platform/architecture/plugin-execution.md)。本页维护当前 VM／Profile 契约和资源上限；原生授权、联网与安装均在 VM 之外。

## 实现与入口

| 包                       | 当前职责与公共入口                                                                                                                                                |
| ------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `plugin-vm`              | 共用 QuickJS 内核、Promise/job 桥、VM 内序列化与句柄回收；`/profile` 提供无引擎元数据和 Profile hash，`/control` 提供纯准入/错误，`/engine.wasm` 交付固定引擎字节 |
| `plugin-sandbox-browser` | 根入口管理单次会话、准入、独立于 Worker 的 watchdog 与清理；`/browser` 只从固定应用资源创建 Worker，`/worker` 处理有界协议。离线构建产出内嵌 WASM 的可信 Worker   |
| `plugin-testkit`         | Node 中的测试宿主，复用相同 VM、WASM、Profile、桥与标准工具契约；客体测试作为文本进入 VM，Node 不 import 插件/项目测试入口                                        |

生产适配默认接收单文件 ESM，客体的 default 函数在 VM 内接收 JSON 副本并返回可序列化结果；外部模块加载器关闭，顶层 await 和异步结果都走同一 job 预算。`body` 格式只为同 VM 测试/契约片段提供入口。任意客体函数都只作为 QuickJS handle 留在 VM，不作为宿主函数执行。当前 source 字段也受 65,536 码点及整条消息 256 KiB 限制，大入口明确拒绝；包字节经原生校验与交付进入，VM 本身不授予安装权威。

每次调用结束释放 Runtime/Context、deferred Promise、句柄和 Worker；未启动的会话在 5 分钟后回收。持久状态通过 VM 外的具名原生能力访问，Userscript 不装配外部执行器。

## 固定引擎与 Profile

使用 MIT 许可的 [quickjs-emscripten 0.31.0 固定源码](https://github.com/justjake/quickjs-emscripten/tree/235f6da2fd4f7354fa4765fde4aea880d2a4aef5)，绑定和 FFI 精确锁定 0.31.0。`plugin-vm/scripts/build-engine.py` 用 Emscripten **3.1.65** 构建 `0.31.0-am1`：

- 在引擎的 `JS_EvalObject` 拒绝客体动态求值，覆盖直接/间接 eval 与普通、异步、生成器、异步生成器构造链；保留可信宿主 C API 编译入口。
- 引擎拒绝 dynamic import，不安装外部模块加载器，不接收客体字节码。Emscripten 使用 `DYNAMIC_EXECUTION=0`，不会为兼容开放宿主 eval/Function。
- 显式 imported memory，编译最大值与实例最大值均为 **128 MiB**。QuickJS 堆 **32 MiB**，栈 **256 KiB**。保留两份 MIT LICENSE、原始/补丁源码摘要、编译参数及产物哈希。
- WASM SHA-256：`5dadb9901b620bf9cbb6e314058e25d8cd2b2a343727f0ed0a2175bd6ade5b10`。初始化时检查实际字节，未知 ID/hash 在创建执行域前拒绝。生成记录见 [engine/build.json](../../../../packages/plugin-vm/engine/build.json) 与 [Profile 清单](../../../../packages/plugin-vm/engine/profile.json)。

`pnpm lint` 检查固定引擎和 Profile/桥/工具源码摘要；修改必须审查后显式执行 `node scripts/check-plugin-vm.mjs --write`。`/profile`、`/control` 和 adapter 根入口由依赖图检查保证不提前加载引擎；VM/browser 包不能导入 Node/Tauri 或业务包，正式应用不能导入 testkit。生成加载器单独排除格式/lint，原始字节由哈希检查；手写代码照常检查。

Profile 仅提供纯工具：URL/查询、UTF-8、base64、JSON 子集 structuredClone、注入时钟的 Date、Promise 定时器、受限随机数和 SHA-256/HMAC-SHA-256。浏览器/Node 对象都不跨执行域。URL 当前提供只读解析快照；查询参数是可独立编辑的副本。文本仅 UTF-8、无 streaming decoder；encodeInto 要求目的缓冲区容纳全部结果；clone 只接受同一线协议的 JSON 子集。随机数仅 Uint8Array，单次至多 4096 字节；HMAC key 是插件自供的 1–4096 字符文本，不含宿主密钥。MD5、HTML、文件、网络、存储、事件订阅及业务能力均未提供，console 正文直接丢弃。缺失或超出本 Profile 的能力明确失败。

## 预算、消息与回收

- 累计 VM 执行 **1 秒**，异步等待不计入；总等待 **30 秒**；每批最多 **64 jobs** 后让出，累计至多 **10,000 jobs**。额外 **10,000 次中断检查**防止假时钟停滞；检查次数不代表等价指令数或设备 CPU 时间。
- 所有输入/输出按 SDK 有界 JSON 规则校验：编码后 **256 KiB**、深度 32、节点 10,000、拒绝重复/危险键及不安全整数。Getter、toJSON、Proxy 和异常值留在有预算的 VM 内，宿主不 dump 客体对象或错误；序列化拒绝访问器、自定义原型、函数、稀疏数组和循环。
- 最多 **32** 个未完成纯工具/定时器；清除计时器不重置其已占预算。一次运行仅一个根任务，没有隐式排队或订阅；并发调用返回 busy。
- 全局最多 8 实例、384 MiB 预留；每实例按 128 MiB 预留，因此实际同时至多 **3** 个。全局任务上限 16；安装主体上限 32，限流每主体 **60 次/分钟**、全局 **240 次/分钟**。更换 requestId 或成功返回不重置限流。
- 10 分钟内 3 次崩溃/预算失败挂起同一主体；退避 1/4/16 秒。准入保留记录，未自动删除用户数据。成功、异常、坏输入、取消、超时、创建期间取消、关闭、空闲和迟到回复均回收句柄、订阅、计时器及内存预留。

这些是版本化保守上限，未做最低设备/手机校准，也不声称限制整个浏览器进程内存。只能收紧已有预算；提高上限需新版本与目标证据。

## 验证边界

`pnpm check:plugin:vm` 检查 Profile／引擎哈希以及真实引擎、恶意输入、准入和 Worker 测试。Node Worker 只证明构建后的启动器在该宿主可运行，不建立 WebView CSP 或原生权威。精确目标准入见[桌面交付](插件系统重构S15工具与桌面交付.md#退出证据与限制)。引擎、桥、Profile 或预算变化必须审查哈希并进行匹配验收。
