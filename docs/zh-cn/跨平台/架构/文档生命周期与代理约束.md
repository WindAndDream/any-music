# 文档生命周期与代理约束

英文对应页：[Documentation Lifecycle and Agent Instructions](../../../en/cross-platform/architecture/documentation-lifecycle.md)。明确的用户指令与适用仓库指南优先。

## 找到权威归属

从[文档索引](../../文档索引.md)选择运行端／任务，只读相关章节、最近的 `AGENTS.md` 和必需 skill。索引只负责路由；当前指南维护已实现契约，交付矩阵维护能力／目标准入，活动计划维护剩余任务与验收。源码／测试证明实现，实测证据只适用于记录的构建／设备／场景。区分网站、已安装 GM 和 Rust 证据，只有真实重抓才能更新 `captureDate`。

## 维护当前内容

- 先修改已有归属文档。新页必须有独立长期职责或可执行的未完成工作；不新增重复计划、时间流水账或假设性兼容指令。
- 声明 `documentType`、`runtimeScope`，保留平台契约元数据；同步双语、对应页、索引、入链与变化的锚点。标识符及实际 UI／源文本保持原样。
- 直接写当前契约和未关闭限制。计划注明目标、归属／运行端、剩余行动与验收；已完成步骤重复后即移除。过时事实就地修正。
- 命令结果直接在任务交接中说明；除非用户明确要求，不把日常输出或中间尝试另存为本地日志。持久证据只记录必要的方法、构建／产物身份、结果与限制，测试／构建不证明未执行的实测验收。

## 删除完成与被替代的材料

有效决策和不变量已进入当前归属后，删除已完成清单、旧设计、迁移盘点、重复交接和无用文件。默认不建立归档或永久完工记录。旧设计仅在仍规定必要的未实现契约时保留，并明确该范围。

只有仍支撑当前准入／安全／恢复声明、未解决问题、开放验收对比或复现需求的证据需要保留。指南中删除重复通过数、旧命令摘要及已完成实现叙述。保留未关闭门槛；整理文档不能接受新构建或关闭未执行用例。

删除前检查入链及独有内容，迁移仍需的契约／待办，并同步双语及索引。不因文件较旧而丢弃已修改／未跟踪工作；清理原始基线前检查消费者，Git 历史不能保存未提交产物。

## 代理流程与验证

识别运行端及归属 → 检查相关实现／约束 → 更新当前事实 → 保留未关闭门槛及必要证据 → 删除失效内容 → 检查受影响路径、链接、锚点与格式。运行与改动匹配的仓库检查；浏览器／应用／模拟器检查必须由当前任务明确请求。报告实际删除、验证和剩余限制，不将历史证据当作当前工作树通过结果。
