# 插件工具与桌面交付

英文对应页：[S15 Tools and Desktop Delivery](../../../en/cross-platform/architecture/plugin-system-s15-tools-and-desktop-delivery.md)。进度事实源：[实施步骤](插件系统重构实施步骤.md)。

本页维护当前工具／交付契约与精确目标准入。实现能力不覆盖下文的准入限制。

## 工具与公开边界

- am-plugin / @any-music/plugin-cli 0.1.0 提供 create、doctor、check、test、dev、inspect、permissions diff、pack、sign、verify、migrate check。Node 24.11+、ESM、JSON stdout、脱敏诊断；退出码 0 成功、1 校验失败、2 参数错误、3 环境失败、4 目标不兼容、130 取消。--yes 不产生原生授权。
- 封存选定目录的源码与资源，再使用固定的 Vite 库构建流程编译。拒绝链接逃逸、目录身份替换、Node/DOM/宿主网络全局、外部模块；仅支持本地纯 TS、擦除的 SDK 类型和公开 /guest 辅助函数。不执行项目配置、.env、钩子、Node 测试或安装脚本。作者明确运行无脚本安装更新初始锁文件，CI 使用解析后的冻结锁文件。
- SDK 根和 /music 保持轻量；/schema 使用生成校验器；/node 仅供 Node 包校验。/guest 返回具名请求 DTO，/host 校验并调度公开端口。GuestInvocation/GuestStep 来自同一 Schema；原生在 VM 外验权，再以结果/checkpoint 创建新执行域，最多 16 步。宿主函数、Promise 或活动对象不进入客体。commandId 由原生绑定到已声明命令，输入中的同名字段不能替换它；命令名称（包括 music.*）不能改变操作类型或把所选 L2 数据降为 L1。
- testkit 发布产物嵌入相同 VM/loader/WASM/Profile 和引擎许可证，不要求发布私有 plugin-vm。测试入口也编译到客体；正式应用禁止依赖 CLI/testkit。内核／Profile 与宿主适配代码／资源分别具有验收摘要。
- pack 生成规范顺序、固定 DOS 时间、STORE ZIP、完整性、插件许可证及 SBOM。sign 写入新包，共用 SDK Node Ed25519 校验。自签名仍标识未验证发布者。migrate check 仅验证 data schema 1 的宿主复制及无副作用 VM 冒烟，不开放外部 JS 迁移；权限差异报告不能生成 grant。
- SDK/CLI/testkit 采用用户选定的 **MIT**，保留 QuickJS/绑定许可证；不改变整个应用的许可证。三个工具本机可打包，尚未发布到注册表。

## 模板与当前能力

| 项目               | 实际行为                                                                                                                                                          |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| source-code        | music.sources 目录贡献进入工作台平台选择器；默认搜索合成曲目。可选匿名读取用户指定的公共 HTTPS JSON 目录（64 KiB），具名 request/read/release，每页 20 项按需消费 |
| source-declarative | schemaVersion 1 静态目录，最多 100 项，无客体代码，原生解释并进入相同选择器                                                                                       |
| tag-suggestion     | 只接收明确勾选的标题，返回标签建议并写自己的命名空间，不直接修改宿主标签插件私有数据                                                                              |
| export             | 生成所选标题文本；宿主持有结果 token，原生保存对话框选择位置，写入时重检 epoch                                                                                    |
| 能力               | state.read、state.write、crypto.sha256、network.publicHttps v1；其他必需能力拒绝，可选能力不可用                                                                  |
| 贡献               | 音乐目录进入平台选择器，命令/建议/文本在插件中心受控展示；其他必需扩展点拒绝，可选扩展点不装配                                                                    |

目录查询/分页参数是显式 L1 输入；带所选标题的通用命令至少 L2，不能伪装目录查询。匿名联网仍要求原生 grant 和用户关联数据确认，不借用账号 Cookie、代理或渲染端 fetch。目录一次消费一页；取消关闭原生上下文并中止 VM/网络，保留授权以便重试，迟到页面不展示。撤权或替换代次撤下投影并回收旧任务。退出前释放资源过滤处理器、关闭 WebView2 controller 并强制销毁执行器；有界重试回收仍被系统短暂占用的 Profile。无媒体能力时明确 unavailable，不用历史 URL 或通用下载器兜底。

CLI/SDK/testkit 0.1.0，wire/Profile/package/data/budget 1，内存类别 minimum。当前无上一线协议 major；继任稳定版后上一 major 迁移窗口至少 **180 天**，安全撤销可例外。见 [compatibility.json](../../../baselines/plugin-system-s15/compatibility.json)。这不是任意来源、扩展点、移动代码或 npm 客体依赖的支持承诺。

## 桌面与 DEV

文件选择、原生拖入、.amplugin 初次启动参数、公共 HTTPS URL 和 anymusic://plugins/install?url=... 回到同一不可变预览和[包事务](插件包与恢复.md)。深链只接受一个无凭证公共 HTTPS 地址，不隐式安装。独立匿名下载执行 [联网策略](插件联网.md)的 DNS pinning、逐跳重定向、环境代理约束、16 MiB 和累计预算。已配置文件关联/scheme，但未安装分发包或更改系统默认关联；配置/解析/原生入口证据不等于 OS 安装器注册验收。

手动回退先校验保留的代码/数据配对，生成绑定当前安装身份、epoch、撤销版本和截止时间的原生专用预览。原生对话框确认具体目标版本，取消时安装状态保持不变。提交消费该预览，并在串行事务中重检目标准入、绑定和文件完整性；过期、失效、取消或未准入请求均不修改状态。成功回退仍停用插件、清除授权并提高 generation/epoch；崩溃恢复独立于手动确认。

主视图选择 DEV 项目后，Windows 使用当前 token 用户 SID 的受保护 DACL、拒绝远程的 named pipe、120 秒单次配对文件及有界帧。秘密不进参数、URL、事件或日志。每会话独立 plugin-dev/<uuid>/authority DB/code/data；执行器使用独立临时 WebView Profile，匿名网络无 Cookie jar，相同插件 ID 不继承正式数据/grant。

快照绑定 plugin/session/hash/旧传输 epoch；每次重载都由宿主重新审批，再经正式事务日志安装，更新 hash/permissionEpoch 并取消旧任务。ACK 等待安装事务明确终态，不能把预览被取走当作成功。结束/断连/退出阻止迟到安装、撤权并取消网络。CLI 默认不启动产品或浏览器。

`src/ipc.rs` 维护唯一应用命令注册表。执行器只有专属 relay，原生另绑定真实 window/WebView/document/session/context/deadline/序号。跨执行域原生预算：每安装 60 次/分钟、全局 240 次/分钟、三个 128 MiB VM 槽位，重复失败退避/隔离。诊断最多 64 条，包含 callId、插件/hash、操作及脱敏结果，不包含输入、正文、Cookie、配对秘密或路径；经原生对话框导出。

## 退出证据与限制

- [tools.json](../../../baselines/plugin-system-s15/tools.json)：真实 tarball 离仓安装、禁用脚本并 frozen 再安装；四模板 check → 同 VM test → 相同字节 repack → verify → copy migration。独立宿主仅消费公开 SDK/host 和 testkit。同一离仓 CLI 经真实 ACL DEV 完成安装/重载，原生更新、成对回退及重新授权。
- [toolchain-sbom.json](../../../baselines/plugin-system-s15/toolchain-sbom.json)：记录的工具／引擎哈希、生产依赖闭包及许可证；发布前重新检查当前依赖。
- [desktop-dialogs.json](../../../baselines/plugin-system-s15/desktop-dialogs.json)：真实原生文本保存、诊断导出和文件选择。Windows 自动化焦点失败后，用户操作三个对话框；脚本核验内容/身份并清理导出。
- [desktop-acceptance.json](../../../baselines/plugin-system-s15/desktop-acceptance.json)、[target-admission.json](../../../baselines/plugin-system-s15/target-admission.json)：真实 UI/来源搜索、同 VM 桥、更新/回退/撤权、DEV hash/epoch、全部命令拒绝、同源独立 Profile 的 storage/Cookie/cache/BroadcastChannel、客体全局、CPU、上下文替换、文档/Worker CSP、导航、重放、取消及临时目录回收。
- [checks.json](../../../baselines/plugin-system-s15/checks.json)：根五项、native、MSRV、安全审计、共享包测试样本集和协议差分。普通 test/build 不启动应用；真实验收需要显式 --run。

已记录的准入精确到 Windows x86_64 / OS build 10.0.26200 / WebView2 155.0.4283.62 / Profile 和固定资源/原生宿主摘要。2026-10-21 的 B13-P01 预算校验修复将 Profile 摘要改为 `ccec9d23283bd9fcf31572499461d81371e3e42d669015c08e196c71041497b3`；现有验收记录保留旧摘要，不能准入本次构建。完成新的精确目标实机验收前，外置安装/执行保持关闭；离线回归通过不会续期准入。未知或变更组合关闭安装/执行。实测发现仅导航回调不能保证请求发送前拒绝，因此增加 WebView2 全来源原生资源过滤：只放行三个固定资源和精确 relay 传输；过滤器安装成功前不交付客体字节。Worker 独立 CSP 继续提供第二层约束。

不宣称任意系统、完整媒体 provider、系统安装器注册或手机设备已通过。无公网音乐账号、GM/Rust 实站播放或手机复测，captureDate 不变。市场/发布服务、可信分发根、自动更新、SecretRef 与 S16 设备/渠道继续保留原门槛。
