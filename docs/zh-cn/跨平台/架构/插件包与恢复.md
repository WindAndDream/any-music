# 插件包与恢复

英文对应页：[Plugin Packages and Recovery](../../../en/cross-platform/architecture/plugin-packages.md)。本页维护包校验与安装／恢复次序，[桌面交付](插件系统重构S15工具与桌面交付.md)维护原生审批和目标准入。

## 包与签名

- [am-plugin-package](../../../../crates/am-plugin-package/src/lib.rs)接收有界 reader 所得的自有字节，只做容器、资源、Manifest、完整性与签名校验，不联网、解压到用户目录、授权或执行插件。runtime 不依赖 package/ZIP/HTTP；应用负责组合。
- SDK Schema 定义完整性条目/目录、签名和撤销清单 DTO，由原生成链同时生成 TS 校验器与 Rust 类型。原始字节仍先经过重复键、Unicode、安全整数、深度和节点数边界。
- v1 ZIP profile 仅 STORE/DEFLATE，拒绝加密、分卷、ZIP64、目录项、extra/comment、data descriptor、前后缀及局部/中央目录不一致；先限制目录项数，再逐块计量实际解压输出。16 MiB 包、64 MiB 总输出、8 MiB 单文件、1,024 项、深度 8、240 字节路径与 100:1 压缩比不能由包扩大。JSON 沿用 256 KiB 协议上限。
- 路径拒绝穿越、UNC/盘符/ADS、设备名、链接、执行权限及大小写/NFKC 碰撞，输入须为 NFC。允许固定 Manifest/入口/本地 map、惰性静态 PNG/JPEG/WebP、JSON、许可证文本与 SBOM；资源不变成宿主 URL，不加载第三方 WASM/native/HTML/SVG/字体。远程 sourcemap/sourceRoot 被拒绝。
- 完整性目录精确覆盖 payload，含清单，不含目录自身/签名。Ed25519 覆盖 `AnyMusic.amplugin.integrity.v1\0` 加目录**原始字节**；撤销域为 `AnyMusic.amplugin.revocations.v1\0`。指纹为 32 字节公钥的 SHA-256。Rust 使用 dalek `verify_strict`，Node 使用标准 crypto 并拒绝弱点编码；自签只证明持钥，首次见到仍显示发布者未验证。
- [共享 corpus](../../../../packages/plugin-sdk/test/fixtures/packages/corpus.json)包含明确的正例与损坏包；Node/Rust 检查相同拒绝类别。Node→Rust 固定公开向量与 Rust→Node 临时签名互验；生成器只在内存持有私钥，夹具和日志不保存私钥。离线包检查入口为 `pnpm check:plugin:package`。

## 安装权威与恢复

[runtime 安装编排](../../../../crates/am-plugin-runtime/src/install.rs)通过 Store/Clock/Ids/InstallFiles 端口工作；[应用目录适配](../../../../apps/tauri/src-tauri/src/plugins/package_files.rs)持有私有内容寻址文件、跨进程锁和合作取消。插件提供的路径不成为磁盘目的地。暂存及文件总配额为 256 MiB；不足时中止，不删除活动数据腾空间。

1. 全部输入先形成有界不可变快照，再校验和预览。预览固定候选哈希、原身份/epoch、撤销序号、历史数据等级和期限；不反序列化渲染端的授权结论。
2. SQLite 直接初始化 schema 3，包含 packages、install_journal 和强制存在的 revocations 权威行；拒绝以前的数据库版本，未发布产品不保留旧版本读取器。缺失撤销行、未知 schema 或损坏授权拒绝并保留原库。
3. prepare 事务记录完整旧组合与自身命名空间副本，暂停旧实例、增加 epoch 并使会话/上下文/出口失效；数据只能复制或执行宿主具名的 Rename 操作。首版 data schema 1 不接受未知升级，不为迁移临时执行外部 JS、联网或写宿主业务。
4. 持久化旧数据快照、候选 code/data，再单事务切 committed 指针、命名空间、有效权限与 epoch。文件使用 create-new、sync 和不可覆盖的内容地址发布；Windows 使用 write-through move，其他系统同步父目录。未提交失败恢复完整旧组合；提交后只能读取 committed 记录。
5. 每次包会话创建都重新校验 code/data 与身份/epoch，生产不能借测试会话入口绕过。提交后加载失败可恢复未撤销的旧配对，但保持禁用并移除授权；没有安全版本则禁用并保留数据。手动回退同样不恢复 grant、会话或旧 epoch。
6. 卸载保留命名空间；独立删数据清除 namespace/回退引用，保留安全历史和撤销记录。GC 只删除未被当前、回退、事务日志或当前预览引用的文件；备份 API 不导出这些权威账本。

未签名包逐哈希重新确认；同版本不同内容不静默继承权限。发布者变更/未验证包重装需要显式数据接管确认，固定发布者的版本升级只继承当前仍有效且未变化的实际授权。新增权限、已撤权权限、历史等级变化均重新审查。秘密不交付。L2／联网组合要求声明私有数据出口能力并单独进行最高风险审批，不支持的声明在预览拒绝。

签名撤销清单由应用根验证，持久化单调 sequence/issuedAt/expiry 与命中记录的并集；关闭刷新/离线不能遗忘撤销。预置多根支持分发键轮换。生产尚未配置发布根/分发源，不从插件自带密钥建立撤销权威；分发刷新通过原生入口。原生应用先持久撤销，再取消相应网络任务。

## 预览与兼容

固定宿主 [PluginPackagePreview](../../../../packages/ui/src/components/plugins/PluginPackagePreview.vue) 展示身份／指纹、内容哈希、执行类型、权限差异及历史等级。选择和关闭只暂存／释放不可变快照，不授权；原生交付在明确审批后消费绑定预览，重检身份、撤销、epoch、期限与目标准入。执行器没有预览／安装 IPC，不接受渲染层授权声明。

原生预览只接受 .amplugin 包快照，来源 JSON 格式不受支持。Userscript 不提供外部安装入口；当前桌面安装/执行受 S15 精确目标准入约束。

## 验证边界

`pnpm check:plugin:package` 检查共用恶意包语料及原生包测试。覆盖双向签名、签名撤销／重放、目录／指针／SQLite 故障点、锁、取消、配额、重启、成对迁移／回退、逐次篡改、发布者连续性和垃圾回收。故障注入不证明物理断电、安装器注册或设备验收。
