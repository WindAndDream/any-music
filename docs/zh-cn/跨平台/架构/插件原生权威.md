# 插件原生权威

英文对应页：[Native Plugin Authority](../../../en/cross-platform/architecture/native-plugin-authority.md)。应用装配原生权威，[桌面交付](插件系统重构S15工具与桌面交付.md)决定实际准入的能力与目标。

## 持久化与身份

`am-plugin-runtime` 通过 `Store`、`Clock`、`Ids`、`InstallFiles` 管理安装／授权／上下文／来源和提交／撤权状态机，不拥有 SQLite、Tauri、HTTP、账号或具体文件 IO。应用注入独立的 `plugins.sqlite3` schema 3，与产品快照及凭据隔离。未知数据库版本或损坏权威拒绝插件操作并保留文件，核心产品继续可用；产品备份不导入权威账本。

原生调用方不能从客体消息反序列化。会话绑定真实通道／文档／账号范围、installId、pluginId、内容哈希、发布者、包／数据代次、permissionEpoch 和过期时间。生产权威只由原生验证安装与明确审批创建，不提供测试 seed、任意 grant／会话创建或通用数据中继 IPC。

每次读取／准备／提交重载身份与权威。`BEGIN IMMEDIATE`、`synchronous=FULL` 事务原子保存值、来源及幂等回执，COMMIT 后才确认。单并发 blocking 池中，等待 future 取消不会提前释放正在执行的任务配额。

## 上下文、提交与撤权

宿主发布选中字段副本，签发绑定任务、允许字段、对象版本和过期时间的上下文。Title、Artist、Note 不开放任意 ID、资料库或凭据。选择变化、完成和取消关闭上下文及预留；读写重检身份、epoch、账号、expectedVersion、operationId。相同重试返回回执，变化载荷或其他通道不能重放。

自身命名空间状态和非破坏性显示标题注解使用原生版本化提交，保留源标题、配方及产品快照。工作台消费已提交的原生结果，不在撤权后另写资料库。不提供通用收藏／歌单／删除写接口。

撤权在同一串行事务增加 epoch、移除 grant、关闭会话／上下文／待办；先持久化，再取消原生资源并确认。撤权先提交则旧预留与迟到回复不能写，写入先提交则保留已提交值。回退不恢复旧 epoch 或授权，已交付字节无法收回。重启增加 epoch、清理临时句柄及预留，保留数据、历史与已提交回执。

## 来源与预算

交付、命名空间、注解保留安装／上下文／数据等级／包代次来源。输出继承选中输入、保留命名空间和历史交付的最高等级，并沿发布者／插件继承。缺失历史按 L2，备注至少 L2，秘密不交付；私有备注转为显示标题不能为另一插件降级。这只追踪宿主 API 可观测流，不宣称任意 JavaScript 信息流分析。

上限：128 安装、16 原生会话、每上下文 100 对象、每会话 16 待写、16 KiB 文本值、1 MiB 命名空间、每账本表 4,096 行、16 MiB 逻辑 DB 载荷及 SQLite 页上限。会话／上下文最多 5 分钟且不超过 grant 有效期；耗尽时拒绝新工作，不删除用户数据。

固定宿主权威 UI 只显示原生快照并发出刷新／撤权意图，等待原生确认，不派生或持久化渲染层授权。测试猜测 ID、跨插件／账号／通道、过期、选择／版本竞态、重启、原子回滚、幂等和 A→宿主→B 来源。网络组合见[插件联网](插件联网.md)，安装见[插件包与恢复](插件包与恢复.md)。
