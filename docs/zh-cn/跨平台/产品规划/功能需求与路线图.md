# Any Music 功能需求与路线图

英文对应页：[Feature Requirements and Roadmap](../../../en/cross-platform/planning/feature-requirements-and-roadmap.md)。

## 1. 产品边界

Any Music 不是只聚合传统音乐平台。任何能够稳定定位并按需解析声音的内容都可成为“音乐”，包括视频、视频分 P、平台音频投稿和由用户片段组合出的虚拟歌曲。

前端是可替换的壳；搜索、导入、详情与媒体解析由音乐源插件提供。UI 只消费统一模型，不理解 B 站/抖音字段、WBI/`a_bogus` 签名或短时 CDN 地址。

后续账号系统、云同步、分享／社交与高级报告归可选插件及独立服务。宿主保留本地用户、隔离、经过验证的绑定、核心音乐数据和受控能力；一个本地用户可绑定多个提供方／实例的多个账号，本地音乐不要求云端登录。上述方向尚未实施，见[本地用户与服务规划](../架构/多用户与本地云端部署规划.md)。

## 4. 后续功能分层

### P0：剩余发布验收与性能

- 关闭[主题验收](../架构/独立主题UI迁移计划.md)中的运行端／输入／设备用例，包括宿主页、真实人工输入与原生对话框范围。
- 完成[虚拟列表实现及验收](../架构/虚拟列表与布局性能实施方案.md)，保留拖拽连续性和键盘／减少动态效果替代路径。
- 测量启动器／首次展开、正式 `.user.js` 体积及重型异步模块；移动裁剪使用真实入口和依赖图，不依赖 CSS 隐藏。
- 下载暂停／恢复已实现；优先级、更丰富的时间线编辑和插件批量检测仍属后续增强，先明确领域／持久化契约，再呈现为可用控件。

### P1：资料管理与设置

- 点击曲目后的行为可配置为“直接播放”“播放并跳原页”或“仅打开原页”。
- 提供有界资料库摘要；标签统计归标签插件，高级听歌报告归可选报告插件，通过同意范围内的播放事实生成。私密数据上传另行授权。
- 每个平台独立设置媒体预加载阈值、默认页大小、失败重试和跳转行为。
- 为资料库、工作区与下载历史补齐用户可触发的导出、导入和可恢复清理；基于当前版本数据与预检，不恢复旧架构自动迁移链。

### P1：统一插件体系与分端开放

当前能力及准入限制由[桌面交付](../架构/插件系统重构S15工具与桌面交付.md)和[移动交付](../架构/插件系统重构S16手机交付.md)维护。

- Profile／资源变化后重新完成桌面精确目标准入，并实测声明式网关。
- 完成 Android 剩余优化 Release、最低设备、音频／代理与渠道退出，以及 iOS 原生适配和设备验收。已有 Android 适配器及签名产物不准入移动外部执行。
- 新外置扩展点／媒体、市场／自动更新、分发根、SecretRef 与跨插件服务需要独立契约和验收；外置主题仍未开放。

恢复、更新、DEV 或降级不能绕过策略、原生审批与目标准入；数据 API 已实现不等于产品导入/导出界面已全部交付。

### 后续本地多用户、独立服务与 Web

- 宿主基础：稳定本地用户 ID／显示名、资料库隔离、显式切换／删除，以及旧来源／播放／下载／插件上下文的取消。当前单 profile 设置不等于已实现多用户。
- 账号提供方插件：一个用户绑定多系统、多实例、多账号；验证绑定、每次业务明确选择账号、安全凭据及独立读取／上传授权。注册／密码／邮箱／恢复归独立账号服务。
- 可选同步／分享／报告／远端备份插件：各自命名空间、服务、保留政策与禁用生命周期，禁用后本地音乐仍可用；同一同步范围初期只有一个协调者，防止多提供方冲突或回环。
- Web／后端：提取不依赖 Tauri 的宿主用例和 API 适配，再接独立浏览器入口。服务端验证外部主体并映射受信操作者／资料库权限，不信任客户端 profile ID；这与可选云业务独立推进。

[部署规划](../架构/多用户与本地云端部署规划.md)统一维护 A01–J04 及依赖。本地多用户不等待远端注册／邮件／云部署；秘密注入、私网连接、私密出站与跨插件服务仍待单独设计验收，不改变 Userscript／手机外置策略。

## 5. 非功能要求

- 函数按“解析、请求、校验、映射、分页、状态转换、播放”拆分，避免跨层万能函数。
- 热路径优先使用 `Map`/`Set` 做稳定 ID 查找和去重；顺序数据仍由数组表达。
- 大列表不全量排序、复制或预取；发现真实瓶颈后再引入虚拟列表或索引。
- 所有第三方封面从任意宿主页显示时默认不发送 Referer，并在失败时回退占位；平台 CDN 规则不得泄漏到 Track。
- Userscript 运行时依赖随脚本版本打包；首次只挂载无框架启动器，完整 Vue/Pinia、平台适配器和媒体模块按需执行。页面加载和跨站跳转不得重复请求浮动版本 CDN。
- 三端共享颜色、语义状态、导航 ID 和 headless 契约，但分别采用适合桌面与移动的壳层；响应式隐藏不等于移动端减包，端级入口必须用实际构建产物验证。
- 任何“黑魔法”必须注释不变量、复杂度、回退路径，并用测量证明收益。
- 短时 URL、Cookie、令牌和媒体字节不得进入持久化资料库或文档样例。

## 6. 完成定义

每个能力完成时至少满足：统一模型无平台字段泄漏；错误能进入明确状态；分页可终止；刷新后稳定数据仍可恢复；短时媒体重新解析；中英文文档状态一致；`pnpm test`、`pnpm typecheck`、`pnpm lint`、`pnpm format:check` 与 `pnpm build` 全部通过。UI 按目标运行端验收，Shadow DOM 只属于 Userscript，IPC/原生保存只属于桌面。UI 能力还需满足[跨端界面与交互规范](../功能设计/跨端界面与交互规范.md)中的键盘、触摸、主题、窄屏、动效降级和 Shadow DOM 验收。
