# 网易云音乐接口接入

英文对应页：[NetEase Cloud Music integration](../../../../en/cross-platform/platforms/netease/api-integration.md)。

`packages/plugin-source-netease` 维护内置来源 `netease`、模块 `source.netease`。根入口只导出描述符、贡献和链接本地校验，`/runtime` 负责官方接口、数据校验、映射、惰性分页和媒体解析。两个应用注入原有 HTTP 端口；同级 `WangYiMusicApi` Node SDK 是参考实现，正式产品不依赖它，也不需要启动本地 API 服务。

## 请求与参数

下列路径均以 `https://music.163.com/api/` 为根。内置请求显式包含凭证，超时 15 秒，响应上限 4 MiB；POST 使用 `application/x-www-form-urlencoded`，结构化参数使用 JSON 字符串。

| 操作         | 方法／路径                        | 参数／返回值                                                                                                                              |
| ------------ | --------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| 搜索歌曲     | POST `cloudsearch/pc`             | `s`、`type=1`、`limit`（1–100）、从零开始的 `offset`、`total=true`；读取 `result.songCount` / `result.songs`                              |
| 歌曲详情     | GET `v3/song/detail`              | `c=[{"id":33894312}]`；每次消费最多 100 个 ID，按输入顺序整理返回结果                                                                     |
| 歌单 ID      | GET `v6/playlist/detail`          | `id`、`n=0`、`s=0`；完整清单是 `playlist.trackIds`，不能把 `playlist.tracks` 当完整歌单                                                   |
| 专辑         | GET `v1/album/{id}`               | `album` 与 `songs`；一次有界请求后本地切页                                                                                                |
| 歌手热门歌曲 | GET `v1/artist/{id}`              | `artist` 与 `hotSongs`；仅代表上游热门歌曲子集                                                                                            |
| 登录状态     | GET `w/nuser/account/get`         | `profile.userId` / `nickname`；账号和资料明确为 null 才代表未登录                                                                         |
| 媒体描述     | POST `song/enhance/player/url/v1` | `ids=[id]`、默认 `level=jymaster`、`encodeType=flac`；以实际 `level`、`br`、`encodeType`、`time`、`url`、`code`、`freeTrialInfo` 决定结果 |

导入接受官方 HTTPS `music.163.com` 的歌曲、歌单、专辑和歌手链接，包含 `/#/` 与 `/m/` 路由；必须有唯一的正安全整数 `id`。其他域名、重复 ID 和冲突路由在请求前拒绝。稳定曲目 ID 为 `netease:audio:{songId}`，资料库仅保存稳定页面引用和元数据。上游歌手数字 ID 为零但有名称时，保留名称而不伪造稳定歌手 ID；歌曲 ID 仍要求正整数。

歌单迭代器先取一次 ID 清单，之后每次消费只取一批详情；提前停止不会继续预取。继续加载直接定位目标页；歌曲下架导致详情缺项时，仍能读取后续页面。所有操作透传取消并拒绝迟到结果，重试重新发起请求。

媒体解析只发起一次描述请求，不探测、下载媒体。音质只展示账号实际取得的表示，不声明未经验证的其他档位。显式切换音质时拒绝上游降级；无地址、无权限和仅试听片段均明确失败，不用 outer URL 伪造成功。媒体地址仅保留在会话中，沿用原生流式播放／Range／完整读取回退顺序。

## 运行端与证据

- 用户脚本使用含凭证的 `GM_xmlhttpRequest`；`@connect` 增加 `music.163.com` 和 `music.126.net` CDN 域名族。通过官方页面登录，目标 Cookie 由脚本管理器持有。
- 桌面端使用账号绑定的 IPC／Rust HTTP、原生 CookieStore／代理和原生二维码生成／轮询。二维码成功状态不能单独提交登录：Rust 同时要求 `MUSIC_U` 和匹配的正账号／资料 ID；凭证不进入渲染层。媒体继续绑定账号授权并幂等释放。用户反馈扫码确认后返回 8821；可能需要额外安全验证，目前尚未支持，登录仍未验收。
- 原生移动端不装配网易云，也不接纳网易云账号，原有能力／验收矩阵不变。
- 2026-10-26 匿名直连检查获得有效搜索、歌曲详情、`n=0` 返回 200 个 ID 的歌单、专辑、歌手热门歌曲和未登录响应。歌曲 `33894312` 申请 `standard`／`exhigh`／`hires`／`jymaster` 均有实际结果，申请高档时可能只返回 `exhigh` MP3；不可用歌曲返回 null URL 和 `code=-110`。共享适配器本身也正确映射了搜索、歌单、专辑和歌手首批结果；免费歌曲解析后的 CDN 对 64 字节 Range 请求返回 HTTP 206。这是匿名直接 HTTP 协议证据，不是网站／浏览器重采集，也不是 GM／Rust 验收。
- 2026-10-27 的 [GM-R3 安装版验收](../../../../baselines/theme-ui-migration/T13-gm-r3.json)记录真实 GM 未登录会话、无关宿主页与来源宿主页的公开导入／原生播放、取消／网络错误／明确重试及零歌手 ID 修复。最终安装版 `c944e1c9…907134` 在两类宿主页的“童声”搜索均返回 30 首，静态宿主页明确续页后保留 60 首／两页；该 GM 证据不证明 Rust 传输通过。
- 确定性测试覆盖惰性请求／顺序、取消／重试、会话故障、试听拒绝、实际音质、运行端组合及原生身份解析。网易云账号登录／付费音质、桌面真实二维码登录及原生账号／代理／媒体播放仍需各自现场验收；未声明 `captureDate`。
