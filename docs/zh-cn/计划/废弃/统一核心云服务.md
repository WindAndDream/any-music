# 单一核心账号与云服务

[English](../../../en/plans/discarded/unified-cloud-service.md)

**已搁置。** 早期设想把注册、密码／邮件、同步和分享交给同一个核心身份服务。选用的方向由宿主持有本地身份、验证绑定和正式写入，独立服务管理各自的账号与云端生命周期。离线和私有部署因此可减少依赖。[本地用户](../未来/本地多用户.md)、[可选服务](../未来/可选云服务.md)。

用户确实需要单体安装，且服务身份、授权、数据、离线使用和独立停用都能保留时，可以重新评估统一部署选项。
