# 创作与标签虚拟列表消费方

[English](../../../en/plans/future/virtual-specialist-consumers.md)

**提案。** 通过共享界面端口接入标签目录和关联列表。创作工作区恢复后再评估时间线与素材控件。

| 批次 | 消费方                                              | 验证要点                                                                               |
| ---- | --------------------------------------------------- | -------------------------------------------------------------------------------------- |
| C22  | 经典主题 `TagManagementResults` 标签目录            | 标签身份、维护选择、筛选与详情导航。                                                   |
| C24  | 插件中性 `TagDetailsPanel` 关联列表                 | 出现键、关联编辑与作用域检查，挂载不写命名空间。                                       |
| C27  | 插件中性 `PendingMaterialStorage`                   | 虚拟重建后保留待用顺序、编辑及复用，不触发发布／重放。                                 |
| C51  | 插件中性 `SegmentTimeline` 排列列表                 | 保留完整配方顺序、重复片段身份、编辑和删除；现有索引参与键的行为需要在接入前单独锁定。 |
| C52  | 插件中性 `SegmentTimeline` 剪辑轨道                 | 在现有横向滚动轴上适配缩放、选择与片段宽度，不能套用等高纵向列表。                     |
| C53  | 插件中性 `MaterialFilterBar` 平台原生选择器         | 调查完整音乐源目录和实际成本；保留原生选择器，不能为虚拟化擅自替换控件。               |
| C54  | 插件中性 `MaterialFilterBar` 标签原生选择器         | 保留完整标签查询结果及素材会话中的筛选草稿。                                           |
| C55  | 插件中性 `MaterialCollectionToolbar` 合集原生选择器 | 合集数量无小集合约束；保留完整合集选择及删除确认身份。                                 |
| C56  | 插件中性 `TagMaintenanceToolbar` 标签维护选项       | 保留查询、原始标签身份与重命名／删除会话。                                             |
| C57  | 插件中性 `TagFilterBar` 平台选项                    | 和主题专属筛选分开，保留中性控件的会话归属。                                           |
| C66  | 插件中性 `TagDetailsPanel` 覆盖平台统计             | 与三项固定导航、C24 的主题关联列表插槽分别处理。                                       |

使用[已有分支清单](../../../baselines/virtual-lists/2026-11-03-p00-p03/collection-surfaces.json)定位候选入口。修改前重新核对现行源码，再选一批可复用的接入工作。
