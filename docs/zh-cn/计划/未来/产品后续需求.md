# 产品后续需求

[English](../../../en/plans/future/product-improvements.md)

选定结果和受影响的[板块](../../板块/文档索引.md)后再安排开发。这里保留原路线图中的备选项。

- **资料库**。评估歌曲激活动作偏好、有界摘要、用户主动导入／导出和可恢复清理。标签统计留在标签插件，经同意的收听报告由[独立可选服务](可选云服务.md)提供。
- **下载与配方**。任务优先级和时间轴编辑增强，先明确顺序、草稿和持久化语义。[现行播放／下载](../../板块/资料库/历史与下载.md)。
- **来源偏好**。评估按来源设置预加载、分页和重试的需求，保持取消和请求预算。[分页契约](../../板块/音乐源/分页与会话.md)。
- **启动与包体**。先测入口与首次展开、生产用户脚本体积及重型惰性入口。移动端看实际入口和依赖产物。[运行端指南](../../板块/文档索引.md)。
- **网格性能后续**。O03–O05 取决于测出的侧栏布局、可见行投影或资源重复挂载成本。如有必要定向修改，保持卡片几何、媒体／任务生命周期和交互。[当前网格排查](../../变更/修改中/网格与侧栏性能.md)。
