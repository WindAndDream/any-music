# 非阻塞资料库持久化

[English](../../../en/plans/future/nonblocking-library-persistence.md)

**提案（S00）。** 完整产品代际提交仍做 O(N) 工作。compact 10k 测量中，即使渲染已限制挂载，仍观察到存储引起的停顿。[校验和分配实验](../废弃/同步校验和优化.md)已回退。

先定义工作台和两端适配器的异步准备与串行提交端口。分离候选数据，校验完整暂存与读回数据及预算，保留规范校验和与崩溃恢复，异步返回时复查修订和会话。明确顺序、取消、刷新、销毁与错误传播。让异步让出发生在现有同步锁外，存储格式变更独立决定。

验收包括完整提交与偏好写入回归、两端的崩溃／交错／过期写入测试，以及相同负载下的总耗时和主线程连续工作时长对照。持久化停顿计入端到端侧栏和列表结果。
