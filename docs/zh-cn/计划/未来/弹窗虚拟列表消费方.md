# 弹窗、选择器与筛选虚拟列表消费方

[English](../../../en/plans/future/virtual-dialog-consumers.md)

**提案。** 保留控件原有的编辑会话和焦点返回。按实际滚动根和数据选择窗口，复用 [UI 原语](../../板块/界面/虚拟列表.md)。

| 批次 | 消费方                                                  | 验证要点                                                                  |
| ---- | ------------------------------------------------------- | ------------------------------------------------------------------------- |
| C06  | 经典主题 `ReadonlyTrackCollection` 调用方               | 抽屉／编辑列表保留选择身份、完整数量和原本动作可用性。                    |
| C07  | Studio `StudioReadonlyTracks` 调用方                    | 原生表格与皮肤卡片两种展示，焦点回到原始对话框。                          |
| C16  | 经典主题 `PlaylistPickerPanel` 调用方                   | 查询、多选、数量、键盘焦点与对话框关闭草稿。                              |
| C17  | Studio `StudioPlaylistPicker` 调用方                    | 查询／选择在筛选及当前支持的表格／卡片布局中保持。                        |
| C18  | 经典主题 `ReadonlyPlaylistCollection` 调用方            | 相同校验／选择与受控导航，包含长对话框列表。                              |
| C19  | Studio `StudioReadonlyPlaylists` 调用方                 | 保留独立控件与焦点恢复，不引用经典主题。                                  |
| C35  | 经典主题 `CatalogFilterHistoryList`                     | 历史应用／移除、可变长范围摘要及嵌套滚动边界。                            |
| C36  | 经典主题 `CatalogTrackFilterEditor` 标签选项分支        | 完整标签筛选／数量和既有控件语义保持，滚动契约不同的独立调用方分配 C51+。 |
| C37  | 经典主题 `CatalogTrackFilterEditor` 音乐源选项分支      | 保留完整音乐源选择，固定日历／维度组单独分类。                            |
| C38  | Studio `StudioFilters` 标签选项分支                     | 虚拟卸载／重建后保持草稿选择，不提前写入偏好。                            |
| C39  | Studio `StudioFilters` 保留历史分支                     | 保留历史应用／移除及可变长筛选摘要，与固定设置维度表区分。                |
| C40  | Studio `StudioFilters` 音乐源选项分支                   | 保留全部可选源与完整选择语义。                                            |
| C49  | Studio `StudioFavoriteFilters` 音乐源选项分支           | 保留喜欢筛选的专属草稿与应用语义，静态文本字段不变。                      |
| C50  | 经典主题 `PlaylistOverviewFilterEditor` 标签选项分支    | 歌单专属标签统计、查询和草稿应用独立于歌曲筛选保持。                      |
| C59  | 经典主题 `CatalogTrackActionsDialog` 标签选项           | 独立弹层中的完整标签目录与原始歌曲确认，不能仅依靠 C36。                  |
| C60  | 经典主题 `PlaylistEditorDialog` 标签目录                | 草稿、组合输入及标签明细导航不因卸载丢失。                                |
| C61  | Studio `StudioPlaylistActions` 标签目录                 | 保留独立主题编辑流程与明确提交。                                          |
| C69  | 经典主题 `CollectionFilterChoices` 的标签管理平台调用方 | 仅 `TagManagementFilters` 的动态平台目录；其他调用方是固定枚举。          |

使用[已有分支清单](../../../baselines/virtual-lists/2026-11-03-p00-p03/collection-surfaces.json)定位候选入口。修改前重新核对现行源码，再选一批可复用的接入工作。
