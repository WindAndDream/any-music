# 外置插件扩展

[English](../../../en/plans/future/external-plugin-expansion.md)

**提案。** 已准入桌面目标的实际能力见[桌面交付](../../板块/插件/工具与桌面交付.md)。用户脚本和移动能力查[运行策略](../../板块/插件/运行策略.md)。

- **媒体与资源**。有实际来源需求时引入可信适配器。按需解析，有界资源句柄，保留描述 → 原生 → Range/MSE → 完整读取回退。字节、重定向、Range、封面与下载绑定安装／上下文、预算、epoch 和撤权。访客的任意 URL 不交给 WebView。
- **更多贡献**。按实际消费方定义版本、信任、基数、副作用、清理和回退。候选方向包括有限的声明式导航／视图、歌曲或列表操作及设置。受保护界面和构建期主题保留宿主的信任边界。
- **分发**。发行者信任根、注册表发布、市场与可选更新体验需要独立的交付和恢复契约，复用原生安装器和同意流程。
- **面向服务的权限**。SecretRef、私网目标、私有数据出站和跨插件服务需要独立带版本权限、明确用户决定和撤权检查。[可选服务提案](可选云服务.md)。

先选一项具体扩展和它的验收目标。同步公开契约与 SDK／原生的实际能力表。
