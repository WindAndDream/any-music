# 移动端外置插件准入

[English](../../../en/plans/future/mobile-external-plugins.md)

**提案。** 两个移动运行端当前都返回 `externalPlugins: none`。Android 可有界预览插件包，安装、回退、执行与 DEV 仍不可用。见[移动端能力](../../板块/桌面与移动端/移动端能力.md)。

- 声明式和代码型分别验收。在选定的精确系统、引擎、设备和渠道验证明确同意、安装／升级／回退／撤权／恢复和原生传输。
- 代码型还需要隔离主体和资源过滤、独立 Worker／WASM／CSP／relay 拒绝、预算终止与实际生命周期恢复。按原有目标范围参考[执行器隔离证据](../../../baselines/plugin-system-s03/live-2026-10-18/acceptance.json)及[桌面执行契约](../../板块/插件/无权限执行.md)。
- 在实体最低设备测量内存／CPU、挂起／被杀及存储网络恢复。原生目标和渠道条件满足前继续保持当前关闭策略。准备发布时重新查阅 [Google Play 设备与网络政策](https://support.google.com/googleplay/android-developer/answer/16559646?hl=en)及 [Apple 审核指南](https://developer.apple.com/app-store/review/guidelines/)。

下一项规划工作是选定最小声明式目标及验收需求。
