# 插件、来源与原生宿主虚拟列表消费方

[English](../../../en/plans/future/virtual-host-consumers.md)

**提案。** 保留受保护的账号／授权界面、原生选项语义和已安装身份。短小固定控件按实际容量分类，例如已选备用代理上限八项，可选代理目录则可增长。

| 批次 | 消费方                                         | 验证要点                                                                   |
| ---- | ---------------------------------------------- | -------------------------------------------------------------------------- |
| C30  | 经典主题 `ClassicPlugins` 插件目录             | 筛选、启用状态及配置打开，虚拟挂载不执行来宾代码。                         |
| C32  | 宿主 `NativePluginInstallList` 安装目录        | 精确安装身份与原生同意权威保持，有界预览保留既有限制；命令目录另见 C48。   |
| C33  | Tauri `AccountList` 账号目录                   | 不能因虚拟化关闭账号编辑或把秘密暴露给主题，嵌套选择器另行实施。           |
| C34  | 宿主 `ProxyManagementList`                     | 代理身份、校验和受保护状态保持，选择分支另行实施。                         |
| C41  | Tauri `AccountSwitchDialog` 账号选项           | 当前／禁用身份、键盘焦点及关闭／确认行为保持。                             |
| C42  | Tauri `AccountPolicyForm` 可选账号列表         | 完整备用／故障切换策略选择与显式保存语义保持。                             |
| C43  | Tauri `AccountConnectionForm` 主要代理目录     | 保留选中连接与草稿校验，重建不执行原生写入。                               |
| C44  | Tauri `AccountConnectionForm` 可选备用代理目录 | 已选备用最多八个不代表目录不会增长；保留数量限制与顺序。                   |
| C45  | 宿主 `ContributionInputDialog` 选项目录        | 搜索完整选项、保留选择与输入法输入，并保持绑定原始会话的确认。             |
| C46  | 宿主 `NativePluginCommandResult` 文本项目分支  | 保留完整有序且有界输出，短输出排除需有实际协议／运行端限制证据。           |
| C47  | 宿主 `NativePluginCommandResult` 建议分支      | 保留来源、项目身份和显式标注动作，不改变权威。                             |
| C48  | 宿主 `NativePluginInstallList` 嵌套命令目录    | 独立于父目录虚拟化保留命令／安装身份与同意门禁。                           |
| C62  | 经典主题 `MusicSourcePickerDialog` 源目录      | 分组标题固定为两个，但组内源目录会增长；重选当前源只关闭弹窗。             |
| C63  | 经典主题 `MusicSourceSettings` 源设置目录      | 保留外部源的状态与宿主动作，组数不代表项目数有界。                         |
| C67  | Tauri `AccountPlatformList` 账号平台目录       | 原生源身份可扩展，不能按两个内置源排除；保持宿主权威。                     |
| C70  | 经典主题 `PlayerSettingsDialog` 音质目录       | 源返回的候选没有代码数量上限，先调查真实成本；保留音质选择和播放生命周期。 |

使用[已有分支清单](../../../baselines/virtual-lists/2026-11-03-p00-p03/collection-surfaces.json)定位候选入口。修改前重新核对现行源码，再选一批可复用的接入工作。
