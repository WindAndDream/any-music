# 恢复分板块架构复查

[English](../../../en/plans/future/architecture-audit.md)

**后续提案。** 十月的 B00–B21 排查覆盖了部分仓库。[范围和发现](../../../baselines/refactoring-audit/2026-10-21-b00-e0884a5/summary.json)与[收尾报告](../../../baselines/refactoring-audit/2026-10-21-b00-e0884a5/B21-summary.zh-cn.md)保留当时覆盖、待查项和有日期的证据。未排查候选仍是开放问题。新增代码独立核查。历史证据保留记录时的路径，B19 的现行参考见[移动端能力](../../板块/桌面与移动端/移动端能力.md)。

恢复排查时可以先做 B06 用户脚本代际存储。读[运行端开发规范](../../板块/用户脚本/开发规范.md)和[数据归属](../../板块/插件/数据归属.md)，用定向夹具跟踪一条现行写入／恢复链。记实际归属和行为、最小合理修复和验证范围。其余板块可以按明细单独选中。选中的工作进入[变更流程](../../开发指南/文档变更流程.md)。
