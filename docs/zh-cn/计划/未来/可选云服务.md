# 可选账号、同步、分享与报告服务

[English](../../../en/plans/future/optional-services.md)

**提案。** 每个可选插件和服务持有自己的生命周期、命名空间、配置和用户同意。本地资料库遵循独立的[本地用户计划](本地多用户.md)。先为一项用例建立具名、带版本的端口，再扩展访问。

| 扩展                  | 归属与验收重点                                                                                                                                               |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 账号提供方（C02–C06） | 注册、密码／MFA／邮件／找回和远程会话归提供方。宿主验证绑定证明并授予操作权限，同一提供方不同服务实例保持独立。                                              |
| 收听报告（E01–E03）   | 宿主可在同意后记录最小收听事实，定义寻址、暂停、中断与去重。报告插件进行有界、限定范围的聚合读取，对外传输另行同意，并设保留与删除规则。                     |
| 分享（F04）           | 使用固定的可移植音乐文档，支持验证收件方、过期／撤权、限定预览和幂等导入。稳定作者标识只提供归属信息。                                                       |
| 同步（G01–G07）       | 宿主持有导出、完整性、导入和事务回执。每用户／范围选一个协调者，负责游标、离线意图、服务代际、删除标记、冲突恢复及无循环切换。保留未知命名空间及其权限边界。 |
| 备份和存储（H05–H06） | 宿主持有资产身份和本地恢复。可选服务负责配额、远程保留、受限传输及可验证恢复。                                                                               |

先选择一个提供方或用例。结合现有本地实现确定结构、预算、授权、撤销和失败行为。私网、外置 SecretRef、跨插件服务与远程出站需要独立契约和准入。
