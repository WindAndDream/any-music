# 移动端来源网页适配

[English](../../../en/plans/future/mobile-source-pages.md)

**提案。** Android 已有哔哩哔哩原生适配器。抖音当前的[账号网页端口](../../板块/桌面与移动端/来源网页会话.md)用于桌面。移动端口要有自己的验证和传输证据。

- 建立账号专属原生网页，保证 UA 与请求状态一致，在导航前按源域安装早期观察。确认实际 Android WebView 的 document-start 注入支持。过晚或不可用的观察返回不可用。[Android WebViewCompat](<https://developer.android.com/reference/androidx/webkit/WebViewCompat#addDocumentStartJavaScript(android.webkit.WebView,java.lang.String,java.util.Set)>)。
- 匹配主框架源域、具名操作、账号与列表代际，限制响应字节，导航、取消或挂起时释放读取器和网页。原生适配器提交经过验证的凭证。配置和代理隔离单独验证。
- 先选一个小的列表或登录场景，在真实引擎和目标验收。iOS 需要自己的[原生交付](iOS原生交付.md)。
