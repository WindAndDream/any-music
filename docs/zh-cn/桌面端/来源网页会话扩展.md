# 来源网页会话扩展

英文对应页：[Source Page Session Extension](../../en/desktop/source-page-sessions.md)。

## 当前实现

桌面抖音使用账号专属的内嵌页面（产品窗口内的子 WebView，见[运行端架构](运行端架构.md)），列表解析消费 `DouyinBrowserCatalog`，媒体字节仍通过原生 HTTP 与媒体授权读取。Android 当前提供 Bilibili 账号传输，尚未准入抖音网页验证与列表能力，详见[运行端架构](运行端架构.md)。

应用组合中的 `loadDouyinPlugin` 接受可选的可信 `createPageCatalog` 工厂，传入已选择的账号 ID 和取消信号，返回现有的可移植列表端口。未提供工厂时使用原生账号页面会话；提供的适配器失败时不会切换传输。共享来源解析无需访问网页。现有原生 `request_state` 链路仍然适用，单独注入工厂不会增加移动登录、验证界面、运行端能力或凭证桥接。

## 可行性与后续工作

- 桌面已采用 Tauri 2.12.1 的子 WebView（`unstable` 功能，[Tauri Window API](https://docs.rs/tauri/2.12.1/tauri/window/struct.Window.html#method.add_child)）。它是独立于此前 Chrome/Edge Profile 的浏览器上下文：已保存的原生凭证在新上下文首次创建时导入，旧 Chrome Profile 不再读取。子 WebView 在各平台使用不同引擎（WebView2、WKWebView、WebKitGTK），实站兼容性需要分别验收。
- Android 可在导航前用 `setUserAgentString` 设置电脑 UA；加载中修改可能重新加载页面。UA 应由账号所属原生适配器统一设置，并与请求状态保持一致。电脑 UA 本身不能证明来源兼容。[Android WebSettings](<https://developer.android.com/reference/android/webkit/WebSettings#setUserAgentString(java.lang.String)>)。
- Android 可在 UI 线程通过 `evaluateJavascript` 读取页面。若需提前观察响应，应先检测 `DOCUMENT_START_SCRIPT`，在导航前按来源域注入。Tauri 对 Android 远程页的回退方式不保证早于网站脚本执行；错过捕获时应明确返回不可用，不能静默返回残缺数据。[Android WebView](<https://developer.android.com/reference/android/webkit/WebView#evaluateJavascript(java.lang.String,android.webkit.ValueCallback)>)、[WebViewCompat](<https://developer.android.com/reference/androidx/webkit/WebViewCompat#addDocumentStartJavaScript(android.webkit.WebView,java.lang.String,java.util.Set)>)、[Tauri WebviewBuilder](https://docs.rs/tauri/2.12.1/tauri/webview/struct.WebviewBuilder.html#method.initialization_script)。

桌面实现中，远程页面只能调用 `account_page_report` 上报观察，无任何产品 IPC 权限；其余要求同样适用于移动实现：校验主框架来源和明确的业务操作，限制捕获字节数，将结果绑定账号和列表世代，并在取消、切换账号、导航及挂起时释放监听和页面。凭证提交与验证完成仍由原生代码确认，网页消息不能直接宣告成功或执行任意 HTTP/存储操作。Android 的账号隔离和代理一致性需要单独验证；iOS 需要独立实现和验收。

桌面内嵌页面目前只有自动化测试；移动抖音能力、实站捕获和设备验收均未交付。
