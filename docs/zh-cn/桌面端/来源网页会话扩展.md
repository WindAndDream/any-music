# 来源网页会话扩展

英文对应页：[Source Page Session Extension](../../en/desktop/source-page-sessions.md)。

## 当前实现

桌面抖音通过原生 CDP 使用账号专属系统浏览器，列表解析消费 `DouyinBrowserCatalog`，媒体字节仍通过原生 HTTP 与媒体授权读取。Android 当前提供 Bilibili 账号传输，尚未准入抖音网页验证与列表能力，详见[运行端架构](运行端架构.md)。

应用组合中的 `loadDouyinPlugin` 接受可选的可信 `createPageCatalog` 工厂，传入已选择的账号 ID 和取消信号，返回现有的可移植列表端口。未提供工厂时继续使用原生 CDP；提供的适配器失败时不会切换传输。这为后续内嵌原生网页读取器预留替换位置，共享来源解析无需访问网页。现有原生 `request_state` 链路仍然适用，单独注入工厂不会增加移动登录、验证界面、运行端能力或凭证桥接。

## 可行性与后续工作

- 桌面可考虑独立管理的原生网页视图。Tauri 2.12.1 的子 WebView 依赖仅桌面提供的 `unstable` 功能；它是另一份浏览器上下文，不能直接视作当前 Chrome/Edge CDP 页面的内嵌显示。账号 Cookie、代理、用户目录及现有页面如何衔接，需要另行设计。[Tauri Window API](https://docs.rs/tauri/2.12.1/tauri/window/struct.Window.html#method.add_child)。
- Android 可在导航前用 `setUserAgentString` 设置电脑 UA；加载中修改可能重新加载页面。UA 应由账号所属原生适配器统一设置，并与请求状态保持一致。电脑 UA 本身不能证明来源兼容。[Android WebSettings](<https://developer.android.com/reference/android/webkit/WebSettings#setUserAgentString(java.lang.String)>)。
- Android 可在 UI 线程通过 `evaluateJavascript` 读取页面。若需提前观察响应，应先检测 `DOCUMENT_START_SCRIPT`，在导航前按来源域注入。Tauri 对 Android 远程页的回退方式不保证早于网站脚本执行；错过捕获时应明确返回不可用，不能静默返回残缺数据。[Android WebView](<https://developer.android.com/reference/android/webkit/WebView#evaluateJavascript(java.lang.String,android.webkit.ValueCallback)>)、[WebViewCompat](<https://developer.android.com/reference/androidx/webkit/WebViewCompat#addDocumentStartJavaScript(android.webkit.WebView,java.lang.String,java.util.Set)>)、[Tauri WebviewBuilder](https://docs.rs/tauri/2.12.1/tauri/webview/struct.WebviewBuilder.html#method.initialization_script)。

后续实现须让远程页面保持无产品 IPC 权限，校验主框架来源和明确的业务操作，限制捕获字节数，将结果绑定账号和列表世代，并在取消、切换账号、导航及挂起时释放监听和页面。凭证提交与验证完成仍由原生代码确认，网页消息不能直接宣告成功或执行任意 HTTP/存储操作。Android 的账号隔离和代理一致性需要单独验证；iOS 需要独立实现和验收。

本次仅交付扩展接缝与基于官方文档的可行性评估，未交付内嵌网页、移动抖音能力、实站捕获或设备验收。
