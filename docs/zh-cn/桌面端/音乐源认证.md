# 音乐源认证

英文对应：[Music Source Authentication](../../en/desktop/source-authentication.md)。

登录方式、来源是否允许免登录、账号当前的登录状态是三个独立契约。桌面端哔哩哔哩、抖音、网易云账号必须经过原生验证后才能进入账号列表。哔哩哔哩和抖音在运行端支持时提供原生二维码和系统浏览器验证，网易云只提供二维码登录。抖音原有的短信二次验证仍属于官方登录挑战，不虚构独立的手机号登录接口。

外置声明式接口来源可声明二维码、输入凭证和短信手机号登录。系统浏览器只供内置来源使用，外置包声明此方式会被拒绝。`allowUnauthenticated` 决定是否出现明确的“无需登录”选项，登录失败不会自动变成免登录。静态目录和普通沙箱目录维持既有的无账号使用行为。

## 包配置

CLI 的 `source-gateway` 模板创建声明式接口来源。编辑公开的 `plugin.json` 后正常打包，最终 `.amplugin` 中的 `manifest.json` 会保留 `sourceAuthentication`。真实 Token、密码、手机号不得写进插件包。

```json
{
  "sourceAuthentication": {
    "protocolVersion": 1,
    "apiBaseUrl": "https://api.example.com/music/",
    "allowUnauthenticated": false,
    "methods": ["qr", "credentials", "phone"],
    "credentialFields": [
      {
        "id": "token",
        "label": { "en": "API token", "zh-CN": "API Token" },
        "secret": true
      }
    ]
  }
}
```

完整清单还必须声明 `execution: declarative`、属于本来源的 `music.sources` 贡献、`search` 命令，以及版本为 1 的必需能力 `source.authentication` 和 `network.publicHttps`。凭证字段有数量和大小限制，名称唯一，提交时必须完整填写；只有提供 `credentials` 方式时才声明字段。仅支持免登录的来源可使用 `allowUnauthenticated: true`、`methods: []`、`credentialFields: []`。

协议 1 只接受 443 端口 HTTPS、小写主机名和以斜线结尾的普通路径段；路径段仅含字母、数字、下划线或连字符。不支持 URL 凭证、查询串、片段、重定向、私网目标或代理。宿主会在用户输入前显示认证服务地址。Schema 与原生包校验共同拒绝无效或未知声明。

## 网关协议 1

接口开发者在下列固定端点后适配自己的实际接口，地址均相对于 `apiBaseUrl`。这是带版本的适配协议，不授予插件任意认证脚本、地址或浏览器操作。使用 POST 收发 JSON。认证失效返回 HTTP 401；其他错误不应携带可显示给用户的秘密诊断。

| 端点                | 请求                                             | 成功响应                                                                                      |
| ------------------- | ------------------------------------------------ | --------------------------------------------------------------------------------------------- |
| `auth/qr/start`     | `{}`                                             | `{"status":"waiting","challengeId":"opaque","qrContent":"待编码文本","expiresInSeconds":120}` |
| `auth/qr/poll`      | `{"challengeId":"opaque"}`                       | `waiting`、`scanned`、`expired`，或下述登录成功响应                                           |
| `auth/credentials`  | `{"fields":{"token":"用户输入"}}`                | 登录成功响应                                                                                  |
| `auth/phone/send`   | `{"phone":"+8613800000000"}`                     | `{"status":"code-sent","challengeId":"opaque","retryAfterSeconds":60}`                        |
| `auth/phone/verify` | `{"challengeId":"opaque","code":"123456"}`       | 登录成功响应                                                                                  |
| `auth/session`      | `{}`，附原生管理的 Bearer 认证                   | `{"status":"signed-in","userId":"stable-service-identity"}`                                   |
| `search`            | `{"query":"music","pageNumber":1,"pageSize":20}` | SDK `WireTrackPage`，其中 `source.pluginId` 为当前清单 ID                                     |

例如等待状态为 `{"status":"waiting"}`。登录成功响应为 `{"status":"signed-in","userId":"stable-service-identity","token":"opaque-session-token"}`。身份是非空、稳定且不超过 128 字节的字符串；Token 不超过 8192 个可打印 ASCII 字节。二维码文本在本地编码，不加载远程二维码图片。二维码有效期为 5–600 秒，串行查询间隔至少两秒。短信验证码为 4–10 位 ASCII 数字；原生端按账号限制 60–300 秒的重发冷却，发送失败、取消或重选登录也不会绕过冷却。输入凭证与验证码只作临时输入，仅保存验证后的会话 Token。

搜索按消费者翻页逐次发起，每页一个有界请求，最多 50 页，响应上限 64 KiB，传输截止时间 15 秒。列表始终绑定同一个账号，包括明确选择不登录的情况。删除或停用该账号会取消请求，后续页面不能悄悄换用其他身份。HTTP 401 标记账号失效，连接错误不推断退出登录。主动账号检测使用 `auth/session`。

## 原生归属与生命周期

`apps/tauri/src-tauri/src/plugins/source_auth` 管理已验证配置、登录挑战、Token 和宿主专用网关传输；SDK Schema 管理声明形状。通用插件 VM 网络仍然匿名，内置账号的 CookieStore、代理和系统浏览器进程不会借给此通道。`am-plugin-net` 仍是匿名传输 crate；宿主网关复用其公网目标和 DNS 规则，以及原生 Gate 的身份、epoch、预算和交付屏障。

Token 在原生保险库中加密，并绑定安装身份、发布者和认证配置，不进入公开快照、产品备份或插件状态。表单固定用户看到的配置指纹，原生端在发送前再次核对，防止插件更新把已经输入的凭证转发到新地址。认证配置改变后需要重新登录。公开来源查询经过 L1 同意边界，宿主私人备注仍为 L2，Secret 宿主数据仍不可外传。安装仍需原生确认，包括关联用户数据的联网同意。

新账号首先是隐藏的登录草稿；只有身份与 Token 验证提交成功，或明确选择来源允许的免登录，才发布为账号。关闭未完成的表单会取消对应登录代次并回收草稿，延迟关闭不能删除已经完成的账号。重启时会清理文件可回收的遗留草稿。同一来源的重复身份会在写凭证前被拒绝。

删除先撤销工作、停用账号，再等待所属浏览器进程树退出。被取消的抖音会话直接结束所属进程树，省去优雅关闭的等待。保险库清理和 Profile 脱离放到阻塞线程；通过校验后的同卷重命名，将 Profile 移到不再属于账号的待清理目录。账号事务无需遍历缓存文件即可完成；后台单线程回收，并在重启后重试。目录脱离失败时账号保持停用，并显示可重试错误。已有音乐和账号名称历史保留。

## 交付与验证边界

实现包含离线 Schema/打包、原生授权/保险库和界面生命周期测试，不代表更新了 [S15 目标准入](../跨平台/架构/插件系统重构S15工具与桌面交付.md)，也不代表真实接口或登录已验收，更没有新增外置媒体解析。精确目标、资源和 Profile 校验继续生效。隔离 DEV 会话不提供网关认证；应在已准入的桌面目标上使用经过验证并明确安装的插件包。移动端外置策略仍为 `none`，Userscript 不安装外置包。
