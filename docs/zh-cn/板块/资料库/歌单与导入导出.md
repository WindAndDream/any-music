# 歌单与可移植导入导出

[English](../../../en/modules/library/playlists.md)

宿主持有稳定歌单成员关系、顺序和可移植编解码。经典主题使用只读投影和具名操作。

歌单统一使用封面卡片，不提供风格选择；歌曲网格密度与受控卡片保持共用，宽列表中上方为横向封面，下方为较大的名称及一行截断标签。曲数在悬停或键盘聚焦时显示于封面右下角的阴影角标中，触屏持续显示。封面不显示序号，菜单保留独立悬停背景，继续支持预览、选择与排序。Node 测试覆盖设置隔离、宿主投影、进度归零和操作意图，不能证明浏览器、GM、WebView 的布局、焦点或真实输入验收。

- 默认主题“我的歌单”复用待听/我的喜欢的集合表面、数量徽标与响应式卡片网格。导入歌单使用中性描边，紧邻主题色实底创建按钮的左侧，两者统一右对齐；各宽度下歌单歌曲页底栏依次为歌单信息、展示方式、筛选器与操作器。筛选、操作器选择、长按封面排序、方向键替代、独立展示偏好和概览导航保留集合契约。歌单歌曲页顶部仅保留返回与同一分组内的“全部歌曲 / 按平台”，不重复标题/数量，也不再提供上下滑动收起及手柄。详情顶部对齐歌曲操作弹窗的柔和摘要底色，展示可点击预览的封面、名称、歌曲数和创建时间，其后直接复用歌曲操作的三列主操作按钮组：喜欢（将未喜欢歌曲加入我的喜欢）、下载、导出，图标在上、文字在下，沿用动作按钮动效。已有标签从摘要中移出，单独使用柔和背景区域，单行溢出隐藏；点击打开可换行的完整标签列表，关闭后焦点回到预览入口。歌单项统一复用音乐卡片的网格密度与受控封面卡片：宽屏上方为 8:5 横向封面，下方使用更大的歌单标题；600px 以内的单列容器与音乐卡片一致，采用 72px 封面在左、信息在右的横向布局，双列紧凑单元保留方形封面。名称，标题下面以主题色标签块展示标签，最多一行，溢出隐藏，外部不显示简介和序号。歌曲数量在卡片悬停或键盘聚焦时，显示于封面右下角的阴影背景角标中，触屏上持续显示；详情操作始终位于标题行右上方，存在标签时也不下移；勾选框不额外占用底部行或固定正文高度。图片保持原比例，留白使用主题背景补齐。封面与名称直接进入歌单，仅详情内提供图片预览。悬停放大使用与歌曲卡片一致的 1.055 比例和动效变量，减少动态效果时停用缩放。歌单名称、歌单简介、歌单封面及可用时的管理标签均以向右箭头进入横向滑动详情页，底部先放返回、再放保存；名称与标签入口显示用途说明，不重复当前值。歌单与歌曲操作项共用一份样式，统一 28px 图标列、12px 间隔、字体、内边距、分组线及动效。管理标签对齐歌曲操作的主题色可移除标签、同行输入与添加、底部返回。操作主页底部只保留右对齐的删除歌单，创建页保留取消与创建；仅有上传封面时按钮水平居中；出现移除封面后，移除在左，上传或更换在右。导出按钮按内容宽度水平居中。管理标签输入沿用发现平台选择器的单下划线及入场、聚焦延伸动画；进入简介时焦点落到返回按钮。创建提交期间及成功关闭过程中不显示刚写入歌单引起的重名提示。关闭时保留弹窗直至退场动画完成。歌单标签由标签插件命名空间和生命周期管理，使用独立歌单关联，歌曲标签目录的维护操作仍只作用于歌曲，次要按钮使用暖灰表面色；创建时直接显示相同字段。歌单筛选提供匹配名称或简介的“文本搜索”、仅接受正整数的歌曲数量区间、歌单用户标签及封面状态。具体封面状态可多选并取并集，“全部封面”清除具体条件。文本输入、可搜索的标签复选项和数量区间控件共用歌曲筛选器样式，挂载时即聚焦输入，下划线随入场开始延伸；区间支持添加、编辑和删除，合法的待输入区间参与实时预览并可直接确定。区间包含两端，留空的一端不限；同维度的多个区间或标签取并集，不同维度取交集。标签功能停用时保留休眠条件，恢复后需明确确定才重新参与筛选。歌单筛选器复用音乐筛选面板的布局、类型栏、概览与选项控件：桌面左侧放类型栏，手机移至底部，每个维度有独立草稿、实时数量预览和返回/确定操作。确定才合并本维度，应用才更新列表，取消放弃面板草稿。歌单和歌曲操作器共用全选行与横向操作栏。草稿跨主题替换保留，保存保留稳定 ID、成员、顺序与播放上下文，名称按 NFKC、空白及大小写归一化判重。封面接受最大 5 MB 的 JPG/PNG/WebP，选择后打开本地取景弹窗，支持横向 8:5、方形 1:1、拖动/方向键定位与 1–3 倍缩放。确认后只将选中的原图像素范围编码为最长边不超过 1024px 的 JPEG，小图不放大，存入独立且有上限的本地缓存。取消保留原封面；替换、取消、卸载均释放解码像素，迟到的解码结果不得覆盖较新选择。两套完整主题使用同一个中性裁剪弹窗。卡片比例变化时仍完整展示保存范围，多余空间由主题底色补齐。旧低分辨率封面需要重新上传才能恢复细节。预览使用带进出动画的无边框图片灯箱，图片放大时向整个可用屏幕区域扩展，仅在屏幕边缘滚动，缩放控件悬浮显示，提供居中缩放动画、双击缩放、Ctrl+滚轮、原生滚动、Escape/系统返回与焦点恢复；关闭时保留当前图片与倍率直至退场结束，减少动态效果时禁用缩放及入场位移，继续复用模态语义及不发送 Referer 的图片边界。概览操作区与歌曲工具栏通过细分隔线区分顶部和内容；歌曲页返回按钮自带跨插槽样式，返回概览恢复焦点但不把鼠标焦点呈现为歌单选中。Node 测试不证明浏览器、WebView 或触屏验收。

- 用户歌单目前通过 JSON 文件导入导出（`any-music-playlist`、`schemaVersion: 1`），限制 5 MB、含配方依赖最多 5,000 首。文件保存顺序、元数据、自定义名称和已发布自定义歌曲配方及稳定创作者署名，不包含音频、本地封面缓存、来源账号、喜欢状态或插件命名空间。导入仅在本地校验必要基本字段、ID、引用与配方，再一次性追加保存，不请求音乐源或检查歌曲真实性；必要歌曲字段缺失时指出字段路径。打开歌单后才启动可取消的媒体描述检查，自定义歌曲叶子依赖去重，最多并发三个请求。重新排列原有歌曲时继续当前校验，进度合并更新。离开页面、更换歌单或卸载宿主时取消旧任务并忽略迟到结果，主题替换保留同一次检查。检查后释放临时媒体描述和授权，不播放或持久化媒体。顶部横向提示展示失败歌曲数与 AM 错误码，详情保留各歌曲、网络/不存在或已下架/无权访问/账号/音乐源等原因及上游消息，并提供重新检查；临时失败不删除歌曲或将其标记为永久失效。导入生成新的歌单 ID，同名自动加后缀，保留已有歌曲资料和喜欢状态，不修改当前用户身份。稳定来源或已发布配方版本冲突时拒绝整次导入，保存失败不修改内存状态。文档编解码独立于文件保存，后续服务端鉴权接口可以复用；导入的创作者 ID 仅为署名，不授予身份或所有权权限。两种主题复用宿主传输动作，各运行端沿用现有保存适配器。
