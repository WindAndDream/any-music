# 资料库、播放与下载

[English](../../../en/modules/library/README.md)

工作台持有正式歌曲、喜欢、本地歌单和受管任务。运行端注入稳定值存储与保存能力。用户脚本以 `any-music:userscript:*` 隔离产品数据，Tauri 使用原生代际快照与产品镜像。当前资料库 schema 为 6，下载 schema 为 2。宿主产品数据和插件命名空间通过各自端口提交。见[数据归属](../插件/数据归属.md)。

## 资料库与标签

- 歌单用 `playlist:<uuid>`，保存有序的稳定歌曲 ID。平台合集仍由来源提供 `TrackListing`。批量操作面向完整的筛选结果。
- `plugin-tag-management` 在 `feature.tags` 持有用户标签。写入按 NFKC、空白、长度和大小写无关规则校验及去重。启用时向资料库投影编辑、筛选和排序。停用保留关联并撤回投影。来源标签仍归核心元数据。

## 创作与已发布歌曲

两端的创作工作区暂停开放。既有列表仍可访问已发布作品，素材和配方归属见[创作工作区](创作工作区.md)。
