# 创作工作区与素材归属

[English](../../../en/modules/library/creation-workspace.md)

用户脚本和 Tauri 暂停开放创作工作区。保留的 `feature.composer` 模块持有「自定义音乐」和「片段创作」贡献及素材与草稿逻辑。已发布作品在宿主的已有引用处仍可播放和下载。

## 素材、草稿与已发布作品

- `plugin-music-creation` 在自己的命名空间持有草稿、待整理区和素材合集状态。宿主持有正式来源歌曲和已发布歌曲。插件通过具名端口读写。
- 截取先把歌曲放入持久化待整理区。选择 `material-collection:<uuid>` 时按稳定 ID 加入合集，同次状态更新从待整理区移除。歌曲可以在多个合集。新配方的直接素材均须属于当前所选合集。
- 保存时创建归宿主的已发布歌曲，加入创作时的合集。[配方编译](片段配方与播放.md)把嵌套引用解析成叶片。素材仍被该合集作品使用时，移除会报冲突。
- 删除有作品的合集需要明确选择级联。若其他配方仍引用其中作品，宿主拒绝删除。保留仍被喜欢、歌单、其他合集、配方、当前草稿和待整理区引用的来源歌曲。

通过歌单导入的已发布作品也服从[片段配方与播放契约](片段配方与播放.md)。
