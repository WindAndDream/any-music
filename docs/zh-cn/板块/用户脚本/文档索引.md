# 用户脚本运行端

[English](../../../en/modules/userscript/README.md)

`apps/userscript` 将工作台组装进 Tampermonkey，持有 document-start 入口、Vue 延迟启动、宿主页集成、GM 请求和单宿主账号／代理。隐藏保留控制器，销毁应用时结束会话。

- [开发规范与运行端端口](开发规范.md)涵盖 GM HTTP、存储、网页桥接及按请求使用的真实 GM 流程。
- [宿主页隔离](宿主隔离.md)涵盖挂载、Shadow DOM、样式、输入、CSP 和脚本权限。
- [已安装 GM 的验收](../../变更/验收/用户脚本主题.md)记录主题与输入场景。[音乐源板块](../音乐源/文档索引.md)负责可移植协议。
