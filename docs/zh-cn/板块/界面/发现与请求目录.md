# 发现与请求目录

[English](../../../en/modules/ui/catalog-directory.md)

经典和工作台接收受控请求／列表元数据，工作台持有请求身份和保留页。展开后的列表见[歌曲结果页](歌曲结果页.md)。

发现中的搜索／导入卡片直接显示常用操作。PC 保留搜索／导入时间，视口宽度不超过 600 CSS 像素时隐藏时间行，缩短移动端条目高度。状态预览保持有界，完整错误沿用宿主错误详情弹窗。批量选择、操作菜单、长按和方向键排序继续可用。

- 发现及其歌曲页沿用待听的内嵌灰色表面：灰色仅覆盖内容区域，高度随内容变化，四周保留页面底色与留白；歌曲卡片与表面边缘保持上下 16px、左右 12px 间距，网格不再叠加内边距。页面吸顶返回栏保留原有布局。

- 音乐列表卡片标题区的中间仅展示搜索/链接导入与等待查看/已加载歌曲概况两个标签；按完整文本宽度自然换到上下排列，不挤压或省略标签文本。置顶、加载、来源不可用和简短错误原因与加载统计共用一行，状态分组排在统计分组前；两组保留各自 DOM 语义，在共同视口内横向滚动，不显示滚动条，不压缩或换行标签，保留原生触摸、触控板与键盘滚动。完整错误仍通过“处理错误”查看。

- 音乐列表顶部在桌面端没有任何列表时，将搜索与导入上移到标题与介绍右侧，纵向居中对齐，不保留空的状态工具栏；存在列表时，把四个状态筛选放在吸顶工具栏左侧，搜索与导入放在右侧，同一行排列，筛选无匹配时仍保留该布局。手机端隐藏介绍文案，并将账号/标题、发现入口和状态栏整体吸顶。桌面和手机的初始顶部留白均与「我的喜欢」对齐。留白随列表滚出，吸顶区随后贴合滚动视口上缘并覆盖经过的卡片。键盘排序或返回列表时，将聚焦卡片带到吸顶控件下方。状态按钮保持单行，放不下时复用操作器的原生横向视口与右侧箭头，支持触摸和鼠标按住拖动；纵向手势仍滚动列表，横拖结束不触发状态切换。

- 音乐列表操作弹窗提供一键复制完整公开信息，按点击时的列表投影生成缩进 JSON，包括请求、账号公开身份、状态和已加载歌曲；不补发歌曲/会话请求，不解析临时媒体地址。复制进行中复用本次操作，失败允许重试，关闭或切换列表后忽略迟到反馈。详情各分组共享等宽列，长请求、时间和加载概况跨整行，窄弹窗统一收为单列。完整信息的复制入口是详情卡片右上角的图标按钮；原始搜索词框最右侧另设居中图标按钮，仅复制原始文本。

- Classic 的外层搜索／导入请求卡片及抖音以外来源的歌曲结果也使用虚拟网格。请求卡片的筛选、选择和排序使用完整匹配结果。从歌曲结果返回时恢复目录滚动位置，并聚焦对应请求卡片。这些歌曲结果沿用常规滚动阈值，按需翻页。

- 平台选择保存在所属运行端的工作区快照中，重新进入或重启后恢复上次主动选择的平台。已停用或卸载的平台暂时回退到可用来源，自动回退不覆盖原偏好；旧 v1 快照没有该字段时沿用默认平台，恢复选择不自动加载历史列表。

- 音乐列表详情采用单一低对比曲面，按标题与来源、账号、原始请求和加载概况分组；宽容器使用两列，窄容器改为单列，全文保留换行与复制。账号名称和自定义命名来自实际列表身份；桌面显示实际胜出或要求验证的账号，篡改猴复用该请求所属平台的已知宿主用户名。未读取用户名、未设置命名与尚未加载分别明确提示，展示详情不额外发起会话请求。

- 搜索与导入都可用时，表单非控件区域悬停显示抓取光标，按住时显示抓取中光标；输入框与按钮保留文字输入和点击光标。带有操作器的集合默认不处于选择模式：隐藏各项复选框与选中样式，点击项不会选择或打开操作器。卡片标题、底部操作区和紧凑平台行在两种模式下均预留相同的 44px 选择区域，Studio 播放历史保留空的选择列，避免显示勾选框时重新换行或改变项高度。点击工具栏“操作器”后才进入选择模式并显示复选框。发现、待听和我的喜欢卡片与我的歌单一致，除三个点菜单外，点击卡片任意区域均切换勾选；移动端单列、双列的复选框均位于卡片右下角，与菜单保留独立触控区域。逐项选择、取消最后一项或取消全选均保持操作器展开。明确关闭操作器时退出选择模式并清空勾选，切换列表上下文也退出选择模式；仅隐藏页面的导航或切换主题保留当前模式。打开操作器仍聚焦关闭入口。发现、资料库集合、播放历史与下载共用此行为，长按与方向键排序始终独立于选择模式。

音乐列表卡片的“操作”弹窗提供“刷新”，使用原始搜索词或导入链接，保留列表名称、置顶、创建时间及已收藏歌曲。已有歌曲时，确认按钮显示“刷新”，取消会保留操作弹窗与当前结果。所有来源的歌曲列表右上角始终显示“刷新”。正在加载、验证或来源停用、卸载、不可用时禁用该按钮。再次进入歌曲列表时恢复已加载的结果和 Any Music 列表滚动位置，滚动到底也保持只读。确认刷新后清空结果、回到列表顶部，并请求第一页。首次进入或刷新后的这次浏览可向下滚动加载，加载期间显示转圈图标。空列表提示区分尚未加载到歌曲、当前页没有可用歌曲但可继续加载、已有歌曲被筛选排除，以及当前结果无可用歌曲。

- 音乐列表卡片在正文与加载概况之间保留主题色细分隔线，加载概况只展示已加载的歌曲数和页数，与底部操作之间仅用留白分区。窄卡片沿用相同层次。请求摘要的来源行和原始输入按文本宽度收缩，文字可复制，右侧空白仅在操作器模式下可点击勾选并显示手形光标。切换其他板块再返回时，保留音乐列表的状态分组、已应用筛选、勾选、当前歌曲页及滚动位置；只收起临时浮层，隐藏歌曲页暂停自动翻页，隐藏列表取消拖拽。状态仅保留于本次工作台会话，不新增持久化结果或自动重新请求。顶部标签区仅用留白建立层次。手机视口或列表可用宽度不超过 600px 时隐藏来源与原始请求摘要，缩减卡片高度；宽屏多列中的窄卡片仍保留摘要。点击“操作”直接展示完整列表名称、音乐源、请求方式、原始搜索词/导入链接、创建时间、当前状态、加载概况与置顶状态，再提供列表操作；全文可换行和复制，搜索词与导入链接各提供复制图标、44px 触摸区域及对应成功或失败反馈，复制保持原文且不关闭弹窗或重新请求。内容超过弹窗可用高度时滚动查看。底部筛选器/操作器入口控件在可用区域内垂直居中；手机将条带收紧至 70px，其中上方约 48px 放置 36px 高按钮，下方 22px 为顶边进度条伸出的热区留空。进度条继续保留完整的 44px 触摸高度，按钮与热区之间留出约 6px 间距，兼顾列表可用高度、拖拽与防误触。

- 操作器打开时，音乐列表卡片的空白区域可切换选择，桌面鼠标显示可点击手势；默认关闭选择模式时仍可长按空白排序；文本区域保留复制能力，按钮和复选框点击不重复触发选择。全选与删除已选列表使用带背景的按钮曲面，删除保持危险语义和确认流程。卡片的“操作”弹窗统一提供全部喜欢、重命名、置顶或取消置顶；置顶以主题色实底、加粗文字和向上图标标注；置顶偏好跨刷新保存，置顶列表始终先于新建或重复搜索的普通列表，同组保留原有顺序。取消置顶恢复普通列表顺序，不重放来源请求。桌面与手机顶栏右侧共用带“切换”文字的紧凑平台选择按钮，不显示下箭头。点击打开紧凑弹窗，按内置/自定义音乐源分组并标记当前平台；选择后关闭，沿用当前音乐源切换与外部插件检测流程，重选当前平台不重复探测。手机顶栏限制平台入口宽度，长平台名仅在入口省略，弹窗中显示完整名称。桌面和手机都把“搜索与导入”放在列表标题右侧，并与卡片网格的最右边缘对齐；操作器保留恢复原名、全选与删除，空列表提示同步指向标题入口。桌面和手机都移除左上角“你的发现”。灰色列表容器默认上下各留 16px 内边距，介绍区不再叠加留白，避免顶部间距大于底部；手机保留末项后的额外滚动空间。手机移除“音乐列表”标题，通过受控会话插槽把用户名作为标题，与紧邻的刷新图标同排。账号行不使用外框和背景块，左侧保留与桌面一致的会话状态灯，窄容器规则不能隐藏用户名。账号名称直接展示，不加“用户名 ·”前缀，为长名称留出更多空间。下方说明与标题/按钮行保留 12px 间距，换行时使用 1.6 行高。用户名使用 16px 加粗文字，随剩余宽度缩短并以省略号隐藏，辅助技术保留完整名称及登录状态；刷新时保留已知账号名称，刷新图标在请求期间旋转，并禁用重复点击、提供忙碌状态；减少动态效果时停止旋转。未登录或失效时保留登录入口，刷新图标保持 44px 触摸区域。平台弹窗提供自动聚焦的底线搜索输入，按名称或标识即时本地匹配，不触发来源探测；无匹配时显示明确提示，重新打开清空搜索。输入焦点与筛选器保持同样的主题色底线动画，并尊重减少动态效果。

- “发现”进入后以音乐列表为主。所有宽度都在播放控制栏上方提供“筛选器 / 操作器”，左侧显示已选、匹配和全部列表数量，手机保留返回列表顶部按钮与列表末尾间距。外层筛选器复用歌曲筛选器的概览、独立草稿、历史、日历和实时预览，提供文本、平台、命名与搜索时间四个维度：文本匹配列表名称、原始搜索词/链接或音乐源名称，搜索时间按原始搜索或导入的创建日期筛选，多段日期取并集，与文本取交集，结束日期包含当天。卡片显示搜索时间或导入时间，沿用配方已有的 `createdAtMs`，刷新、重试和恢复不改写；无时间的端级投影显示“时间未知”，有日期条件时不匹配。取消丢弃草稿，应用才改变可见列表，不发起新来源请求；状态分组为“全部 / 可用 / 不可用 / 错误”，三个具体分组互斥且数量之和等于全部列表；来源停用或卸载归入不可用，并优先于旧请求错误和单曲失效，重新启用后自动更新分组。底部非模态操作器在所有宽度都提供恢复原名、全选与删除已选列表，窄容器分为固定高度的两行，关闭按钮只占上排，下排使用完整宽度。发现入口保留在桌面音乐列表标题或手机账号标题右侧；音乐列表操作器上排右侧放全选，下排放删除已选列表及有已选命名项时才显示的恢复原名。全选只作用于当前匹配结果，删除保留确认，空列表仍可搜索或导入。弹框内通过分段控件和水平手势切换；提交后回到列表查看加载状态，不改变主导航位置。查看歌曲时，列表与歌曲页在内容区横向交替推入/退出，歌曲页使用完整可用宽度，返回时恢复列表筛选、选择、滚动位置与触发卡片的键盘焦点。
