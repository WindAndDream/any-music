# 虚拟列表、网格与表格

[English](../../../en/modules/ui/virtual-lists.md)

`packages/ui` 持有仅用于渲染的 `ui/virtual-scroll` 入口。通过固定版本的 TanStack 适配器提供共享滚动上下文、定高／实测列表、响应式网格和合法的 HTML 表格单元。主题注入实际滚动根、受控身份和现有皮肤，宿主对完整集合执行筛选、排序、选择、分页、媒体和写入。

## 几何与生命周期

- 使用稳定的出现项键、不可变完整几何，以及有界的可见行与缓冲。逻辑卡片行采用最高单元的自然高度。保持扁平的 keyed 父元素，变更列数时保留可见卡片作用域。CSS 决定尺寸、列数和间距。`VirtualTrackCardGrid` 用 `0px` 隐式列与压缩轨道表示离屏区间。`VirtualTable` 将歌曲和详情行作为 keyed `tbody` 测量，保留合法表格结构与整表 ARIA 位置。
- 共享观察器测量挂载节点的自然边框盒。只保留当前测量代际，默认缓存 512 项。宽度、内容及样式代际使旧高度失效。行成员变化仅使受影响的拉伸行失效，同一行内重排和行高最大值不变时可复用几何。真正的空间变化仍重建 O(N) 行。挂载、淘汰及宽度批次保持独立的动效基线，见[动效契约](动画与手势.md)。
- 经典主题的虚拟网格在操作器显示或隐藏勾选控件时保留已测高度。歌曲卡片、平台卡片和发现列表卡片在两种模式下均为勾选控件预留空间。
- `useVirtualItemRetention` 默认保留 8 个活动项，上限 32，只保留实际拖拽、落地、编辑、焦点和菜单目标。跨不可变快照保持适配器注册，滚动根或会话替换时清理。`useVirtualScrollAnchor` 为滚动补偿租用权限，在用户滚动、重置或替换时取消过期工作。
- 中立 `ui/theme` 连续性契约保存临时出现项、偏移和控件身份。`ui/library` 解析完整几何或原生元素位置。主题事务等待当前惰性适配器、先挂载离屏目标再聚焦，并在恢复时独占滚动。上述值不进入产品快照。
- 已虚拟化的界面在结果少或为空时仍使用窗口。筛选和全选作用于完整数据，原生 Ctrl+F／Cmd+F 只查已挂载 DOM。保留减少动态效果、键盘替代操作和[按视口推导的挂载预算](动画与手势.md#72-随视口变化的挂载预算)。
