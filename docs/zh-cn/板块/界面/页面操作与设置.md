# 共享页面操作与无障碍

[English](../../../en/modules/ui/page-actions.md)

主题渲染受控的页面操作，共享键盘、触摸和减少动态效果规则。见[产品壳布局](布局与导航.md)。

## 共享操作与集合控件

集合展示设置分为“风格选择”和“排列方式”（卡片密度／手机列数）。点击分类横向滑入对应选项，返回后重新显示可扩展的分类列表。发现中的搜索／导入项统一使用默认卡片，不提供风格选择或独立风格偏好；音乐卡片初始风格为“留白”；“直显”（存储值为 `default`）将常用按钮直接显示在卡片中。每个板块通过运行端命名空间下的 `collection-display:*:v1` 独立保存卡牌风格，与各区域的排列偏好分开；歌单概览统一使用封面卡片，只提供排列方式，全局默认设置保持一致。切换密度、平台分组、下载状态或完整主题不覆盖卡牌风格。插件中心保持现状。

`packages/card-styles` 持有可复用的受控卡牌和轻量风格元数据；`packages/ui` 单独持有分类与选项弹窗。完整主题适配只读播放位置并转发操作意图，工作台持有保存、播放和下载业务。“留白”音乐风格覆盖发现、待听、我的喜欢、歌单歌曲、下载和历史：封面提供播放入口，悬停／键盘焦点显示带动画的黑色遮罩，操作收进三点菜单，批量模式显示选择框。主题主色边框展示当前歌曲真实播放位置，不创建逐卡计时器；跳转、循环和密度切换复用同一时钟，播完回到起点。触屏始终可见播放入口，减少动态效果时关闭过渡。歌曲已有标签使用共享标签块展示在时长／任务状态右侧，最多单行，溢出隐藏。音乐卡牌省略日期／上下文文本，下载保留任务状态，历史记录身份与详情保留在选择／操作中。支持排序的集合继续提供封面长按与方向键操作。

“留白”音乐风格在宽列表中使用横向封面与下方文字，封面高度最多 200 CSS 像素，宽松排列提高至 240 像素，让卡牌稍微高一些。列表宽度不超过 600 CSS 像素时改为横向条目，使用 72 像素方形封面；单卡宽度不超过 260 CSS 像素时保留小卡片，为手机双列中的文字留出足够宽度。悬停时仅在封面裁剪框内放大图片，减少动态效果时关闭缩放。实际正在播放的歌曲在悬停／键盘焦点时显示波形标识并提示“正在播放，点击暂停”，点击通过宿主播放器暂停；暂停后显示播放图标，再次点击从原位置继续，不重新解析媒体。批量选择框覆盖在封面上，显示或隐藏时不改变卡牌高度与文字排版，沿用直显风格的原生勾选框与透明的 44 像素点击区域。选择模式下点击封面仅切换勾选，正在播放或已失效的歌曲也遵循同一规则，鼠标悬停、键盘焦点和触屏均不显示播放遮罩；关闭操作器后恢复封面播放。支持排序的集合在两种模式下均保留长按和方向键排序。

- 主导航切换保留各板块在当前工作台会话内的勾选、筛选条件与未应用草稿、操作器/筛选器开关。离开板块时隐藏其浮层并暂停快捷键与焦点交互，返回时恢复离开前的状态；明确关闭操作器会清空勾选，返回时仍保持关闭。待听、我的喜欢和发现分别持有这些状态及展示密度、手机列数，其他板块的操作与迟到摘要不得覆盖它们。

- 发现、待听在空列表或筛选无匹配时共用白色空状态表面（深色主题跟随表面 token），灰色内容区伸展至壳层剩余可用高度，保留页面四周及底部留白；待听、我的喜欢、我的歌单和播放历史在条目未占满页面时也默认铺满该高度，条目保持顶部排列，底部留白与内容占满时一致。集合排列及详情切换从入场开始即采用新视图高度。详情导航的离场内容裁切在新视图区域内。空状态的图标、标题和说明作为一组在白色区域内水平、垂直居中，窄屏自然换行。图标与当前板块一致：发现使用放大镜，待听使用队列图标；图标悬停有轻微位移、旋转与缩放，减少动态效果时停用。待听提示覆盖发现、我的喜欢、我的歌单和自定义音乐等添加入口，不限定只能来自发现。

- 手机迷你播放器第二页的返回箭头位于右侧；完整播放器展开只暂停迷你栏交互，收起后保留之前的页并恢复当前可见页的焦点，退出手机布局才重置分页。

- 单曲操作弹窗提供“自定义名称”子视图，最多 80 个字符。底部按“返回 / 保存名称”排列，返回不提交草稿，清空输入后保存可恢复来源原名。经典主题的标签摘要与已有标签使用独立浅色背景分区，标签使用主题色浅底；标签管理的“返回”位于添加表单下方，顶部不再放返回按钮。名称作为本地资料库记录的可选 `customName`，按跨来源稳定且唯一的 `Track.id` 关联；分 P/子资源采用自身歌曲 ID，不用标题、列表位置或短时媒体 URL 作为键。来源原名保持在 `Track.title`，重新搜索、刷新、喜欢、加入歌单与编辑标签不会覆盖自定义名称；未自定义名称时使用来源原名。所有共享卡牌与播放器从同一名称映射即时派生展示，后续编辑入口复用资料库 `renameTrack`。卡牌将自定义名称作为主标题，并以带“原名”提示的独立次要行展示来源标题，紧凑及手机双列也保留该行；长文在卡牌省略，操作详情与名称编辑页完整换行。本地歌曲筛选同时匹配两种名称，名称排序采用当前显示名；命名不改变歌曲 ID、来源解析或正在播放的会话。

- 默认主题各板块（含发现）的筛选概览统一展示草稿条件。已设置条件的维度标题旁紧跟小号主题蓝底数量徽标，条件分组上下边缘无分隔线。匹配数量统一在概览底部显示，数字和单位加粗。宽屏将匹配数量放在左侧、取消和应用筛选放在右侧。窄屏将匹配数量放到按钮上方，取消和应用筛选在底部一行左右等宽。标签管理的添加输入框使用内侧焦点环，避免被横向切页容器裁切。

- 歌曲卡片按当前响应式 Grid 行等高，卡片底部操作对齐；手机双列的作者与操作入口同样靠底排列，未命名歌曲保留自然留白，不增加逐卡片尺寸监听。歌曲与音乐列表的命名筛选使用“全部 / 自定义名称 / 来源原名”原生单选，与自定义拼接来源类型无关；平台筛选多选同维度取并集，跨维度取交集，未选平台表示全部。没有可选平台时，平台筛选项内容区显示“当前无任何平台”。新维度沿用隔离草稿、实时预览、概览删除和独立历史设置。恢复原名只处理已选命名项，原名项不改记录；批量操作一次发布快照、一次保存，并保留喜欢、标签、歌单、请求输入与创建时间。列表配方保存默认标题 `originalTitle`，旧 v1 配方按原有默认命名算法兼容恢复。

- 歌曲操作器保持非模态，默认按加入歌单、下载已选、添加待听、添加喜欢的顺序展示四个动作，以及有已选命名项时才显示的恢复原名。添加标签等扩展动作共用操作器按钮的尺寸、边框、背景、悬停、焦点、禁用及响应式样式。待听和我的喜欢共用这些歌曲动作，并在加入歌单之后、下载已选之前的第二位展示各自的红色移出按钮，与删除音乐列表使用相同的危险色、悬停和禁用反馈；选中歌曲全部已待听或已喜欢时隐藏对应添加按钮，混合选择只补充缺少的歌曲。已下载或已加入歌单不隐藏按钮：下载包含全部已选歌曲，已下载歌曲也交给运行端校验或重新保存；加入歌单按所选目标检查，全部已存在时提示无需重复添加，混合选择只提交新增数量。下载状态来自实际保存成功的下载历史，生成完成、保存取消或失败不算已下载。我的喜欢不在操作器中显示歌单下拉框，与其他歌曲列表共用目标歌单弹窗。宽屏与手机均从底部滑入横向操作条，覆盖底部播放器；手机还覆盖底部导航，操作条上缘到播放器顶部，保留上方启动按钮。系统侧边栏及其遮罩位于操作条之上。启动按钮和面板关闭按钮都可收回操作器。添加待听、下载与添加喜欢在提交前确认；加入歌单直接打开支持多选的歌单选择弹窗，没有歌单时在弹窗中提示前往“我的歌单”创建；勾选目标后提交即执行添加，不再二次确认。搜索或导入的歌曲列表本身只读，不提供删除已选歌曲。添加待听按勾选顺序一次去重并保存，已有歌曲保持原位；取消后重选排到末尾，全选仅追加尚未选择的歌曲。若当前按平台排列，批量添加切回全部歌曲以保持真实播放顺序，超过待听容量时整批拒绝。

- 歌曲卡片将作者、时长、发布时间合并为可省略的一行；播放和弹幕统计显示在封面上的半透明字幕底色上。歌曲卡片的一级操作为播放、喜欢、下载和“操作”，待听收进操作弹窗；手机单列使用紧凑横向摘要，封面固定在右侧，统计固定在封面左下角、选择控件固定在卡片右下角，双列卡片的统计与选择控件同样保持这些位置，并保留顶部封面与紧凑操作。操作弹窗提供所有一级操作、待听和标签管理、截取片段、来源原页。单曲喜欢和待听显示“已喜欢 / 已待听”，再次点击取消；已失效歌曲仍可取消已有喜欢或待听。添加操作使用绿色成功提示，取消使用蓝色信息提示，实际保存失败使用红色错误提示。播放、待听、喜欢和下载的键盘焦点环画在按钮内侧，避免被横向切页容器裁切。标签管理在弹窗内横向切换子视图，支持查看、添加和移除。操作器打开时，外部音乐列表和歌曲卡片才显示选择控件，并提供至少 44px 的点击区域，歌曲封面也仅在此模式下属于选择热区；以复选框状态和主题蓝色歌曲卡片描边反馈选择结果，歌曲选中描边优先于播放强调，音乐列表卡片沿用原有选择描边，不在每项旁重复显示“选择”，鼠标勾选后不保留键盘焦点环，选中时不填充整张卡片背景。

- 筛选器共用草稿事务、预览、取消/应用、日期编辑与历史机制；各板块保留自己的状态结构、匹配规则、维度和文案。业务容器必须提供稳定的历史归属标识：外层音乐列表独立保存，每个歌曲列表按配方 ID 独立保存，各维度的去重、保留数量、恢复与删除只作用于当前归属。历史保留数量与折叠偏好按板块和筛选区域分别配置；“发现”区分外层音乐列表与列表内歌曲，歌曲列表共用区域偏好但各自独立保存记录，最多保留最近使用的 100 个筛选器。正式脚本使用 v2 历史存储；旧 v1 共用记录没有可靠归属，保留旧存储但不自动混入新筛选器。

- 列表与歌曲操作器在桌面两侧各保留 20px 留白，关闭按钮旁不显示分隔线；关闭按钮与全选同处上排，下排使用完整可用宽度。所有按钮在放得下时整组靠右，间隔 12px；只有实际宽度不足才切换为从左开始的滚动布局，判断可用宽度时不扣除箭头占位，以免按钮减少或面板变宽后仍停留在滚动状态。恢复原名只在已选项包含自定义命名时显示；混合选择仅恢复实际命名项。手机下排按钮保持单行、统一高度和至少 44px 的触摸区域，不压缩或折行；溢出时右侧提供渐隐磨砂箭头，点击推进到下一组操作，到末尾后可返回开头，同时支持触摸滑动和鼠标横拖。纵向输入不接管，横拖后的落点点击被抑制；窗口尺寸或按钮数量变化会更新箭头，减少动态效果时直接滚动。展开/收回时，底部区域用与面板滑入相同的时长和缓动协调空间变化。按播放器实际高度和已占位的移动导航计算不足空间，并补在播放器上方，控制栏始终贴住底边；内容视口通过壳层 Grid 同步让出高度，列表尾部保留留白与滚动对齐空间，使最后一项可以完整滚入。减少动态效果时关闭这类空间过渡。三种歌曲集合共用四个动作的确认和去重流程，业务写入仍由各自容器处理；外层音乐列表保留自己的操作。我的喜欢、待听与发现页共用外层零内边距规则，灰色内容曲面由内部统一控制四周留白，避免喜欢页叠加内边距。

- 发现、歌曲列表及待听操作器中的可用按钮、全选、关闭与溢出箭头在悬停和键盘焦点时提供轻微背景变化。普通操作使用表面悬停色，删除列表保留危险色提示，蓝色主按钮使用随浅色/深色主题调整的 `--am-color-primary-hover` 轻微提亮。搜索与导入入口的左侧图标轻微缩放和转动，表单提交按钮也反馈到对应输入行的左侧图标；导入链接图标轻微上移。禁用操作不响应悬停，减少动态效果时停用图标运动和颜色过渡，保留静态背景反馈。

- 需要批量选择、下载或加入集合的页面使用一致的操作器语义，筛选器与会改变数据的操作明确分离；只有拥有可编辑集合的数据页才提供删除。播放、暂停和切歌仍属于播放器，不塞入批量操作器。

所有带操作入口的音乐项均在“自定义名称”下方提供“添加歌单”。其子视图与操作器中的加入歌单弹窗复用“我的歌单”的封面、信息、卡片尺寸和勾选框位置，歌单项只允许勾选。可滚动列表提供展示方式和筛选器；控件行左侧仅显示“已选 N 个”，右侧依次为展示方式、筛选器和全选。三个按钮在桌面与手机均采用外部操作器入口的 12px 字号和 36px 高度，全选勾选框为 16px；窄布局中展示方式使用 36px 图标按钮。容器宽度不超过 320px 时，第一行将已选数量和展示方式分列左右，下方筛选器和全选各占一半宽度。全选只切换当前匹配歌单；全部匹配项勾选时背景变蓝，否则恢复默认，单项变化立即更新按钮状态。筛选保留其他已勾选目标，计数和最终提交包含全部已勾选歌单；各目标只追加缺少的歌曲，已有歌曲保持原位。明确返回或关闭重置草稿，主题切换保留进行中的编辑。经典主题使用共享的无界面选择逻辑。Node 测试覆盖选择和事件传递，真实布局与焦点验收单独执行。

## 无障碍

交互控件使用原生元素，所有无文字图标按钮有 `aria-label`；弹层管理焦点、Escape、关闭后焦点恢复与背景遮罩；选择和错误不能只靠颜色。远程图片有替代文本，触摸目标保持足够尺寸，文本在 200% 缩放下仍可操作。

虚拟列表沿用现有筛选器，在归属方提供的完整集合中匹配，包含当前窗口之外的项目；匹配结果继续通过同一个有界虚拟窗口渲染，应用或清除筛选均不切换为全量 DOM，也不遍历远程分页。浏览器 Ctrl+F／Cmd+F 保持原生行为，只搜索当前已挂载内容。不新增独立的查找／查看按钮、不拦截快捷键，也不挂载隐藏或离屏副本来扩大原生搜索或文本选择范围。

UI 变更至少验证：浅/深/系统主题、侧栏两侧与收起状态、窄容器、键盘顺序、触摸等价路径、reduced motion、加载/空/错误/部分成功、宿主页样式隔离、隐藏再显示、播放栏与移动底栏叠加。最后运行目标包测试和类型检查，再执行根级 `pnpm lint`、`pnpm format:check` 与 `pnpm build`；涉及移动端时额外比较各端产物依赖图和体积。
