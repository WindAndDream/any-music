# 目录错误与恢复

[English](../../../en/modules/ui/catalog-errors.md)

工作台保留列表和请求身份以重试或验证。[来源适配器](../音乐源/分页与会话.md)负责分页与取消。

- 音乐列表保留请求配方、稳定结果元数据和可续载位置，不持久化迭代器或临时媒体。重复进入复用已保留结果；没有结果缓存的配方首次查看时加载第一页，后续页面按需加载。启动恢复、搜索、链接导入、已保存列表首次恢复和后续翻页的错误统一留在对应列表中，不局限于空列表或网络错误。只有用户点击“处理错误”或歌曲页错误摘要时，才打开“音乐列表错误处理”详情；后台状态更新、滚动、收藏、重新查看及主动重试失败均不自动弹出或重新打开详情。首屏断网不要求重输搜索词；后续页失败时保留已加载歌曲并停止自动翻页，用户可继续浏览或收藏，联网后主动重试，不要因滚动重复发出失败请求。歌曲页的错误摘要与返回栏共同固定在内容区顶部，点击可重新打开详情。有效/无效状态与重试入口必须保持可见，不用动画掩盖网络状态。

- 列表级错误及内容失效时，卡片用简短状态和区别于“查看歌曲”的“处理错误”主按钮提示；完整错误、已加载进度与分步骤处理指引放在错误弹窗。卡片不单列重试；弹窗可重试、前往插件中心或查看已加载歌曲。重试从第一页重新加载，已有歌曲时应先提示已保留结果会替换，并引导用户先收藏需要保留的歌曲。错误弹窗移除来源网页验证/搜索跳转，账号验证由所属运行端动作完成。宿主和主题共用一个错误弹窗目标；验证期间保留进度，验证或重试成功后重载第一页、关闭弹窗并进入歌曲列表；查看已加载歌曲先关闭弹窗再导航。恢复失败时保留实际原因与可重试入口。后续页不可用不等同于已确认需要人机验证。只要已有歌曲且尚未全部喜欢，列表卡片和歌曲页的批量喜欢都可操作，即使后续分页失败。音乐列表与歌曲列表使用相同内容宽度，外框不设 1600px 上限；网格以 300px 的舒适最小卡片宽度自动填充列数，卡片最小宽度不超过容器，单张卡片仍保留空列。侧栏开合与窄容器自然重排，不由宿主视口强制列数。音乐列表卡片移除独立拖拽按钮，长按空白区域 500ms 后进入二维排序预览，拖动时显示四向移动光标，覆盖卡片、子控件与网格间隙，松手后保存请求配方顺序。操作器模式下，点击音乐列表卡片中除三个点菜单外的任意区域均切换选择，包括文字与主要操作；原生复选框只切换一次。按钮、复选框与文字区域不触发长按排序。等待期间不捕获指针或阻止触屏滚动，移动超过 8px、滚动、提前松手或取消都会撤销等待；长按激活后才接管触屏移动。卡片自身可聚焦，回车/空格切换选择，方向键提供同组排序。卡片的隐式指针捕获移交网格时不取消排序，仅网格自身失去捕获才取消。加载数、账号或错误等公开投影刷新但 ID/顺序和分组不变时保留拖拽；真正的顺序、分组或布局尺寸变化才撤销旧槽位预览。方向键提供同组微调，Escape、指针取消、失焦、切页、筛选变化与网格尺寸变化中止拖动，不改变选择；拖动落点的原生点击不重复选中卡片。置顶与普通列表各自在组内排序，隐藏项保留原位，持久化只保存配方。拖到另一置顶分组时清除排序预览并阻止跨组排序，顶部显示琥珀色警告“置顶列表无法与未置顶列表交换位置，请先取消置顶。”；每次拖拽只提示一次，3 秒后消失，不抢焦点，拖回同组后可继续排序。

- 来源在设置中停用时使用 `disconnected`，卸载使用 `missing`，已有歌曲、筛选和收藏保留，暂不加载新歌曲。空闲列表使用中性静态提示，不因旧错误自动弹窗；正在加载或验证的列表取消旧任务、忽略晚到结果，并保留“加载已中止”状态供用户主动点击查看。重新启用不会重复提示或自动请求，用户重试时从第一页重建。空闲列表停用时保留现有游标，启用后继续按需消费。无歌曲时查看按钮禁用；来源仍启用但有效性检查失败继续使用实际错误处理。受影响的播放恢复空闲，相关下载和导出中止，保存的列表、歌曲和待听保留。

- 歌曲列表中的平台和实际请求账号只读，发现页的账号偏好只影响新操作；桌面按平台恢复上次选择的账号并显示名称，没有有效选择时按固定账号列表顺序保存默认账号，优先选择已启用、非待保存且就绪的账号。已保存的选择不因需要登录或验证而改变。账号删除或停用后，空闲列表下一次加载自动选择可用账号并重建第一页；正在加载时在列表中保留中止错误供主动查看，重试时重新选择，无可用账号则提示到设置中添加。列表标题全文按钮保留左右内边距，测量宽度扣除同样的留白。音乐列表操作详情的加载概况与置顶状态并排展示，窄屏允许概况文字换行。经典主题的列表重命名在同一操作弹窗内横向滑入，复用歌曲名称表单：上方为自定义名称，下方按类型显示“搜索原名”及完整搜索内容，或“导入来源”及完整导入链接。返回放弃草稿；保存修改后的非空名称（最多 80 字）后返回列表操作，不改变原始请求。置顶与取消置顶按稳定列表 ID 读取当前状态，操作弹窗关闭后也能正确切换。

- 顶部错误栏只显示可点击的错误提示，不额外放置“错误处理”“查看详情”或来源跳转按钮；点击整条提示打开“音乐列表错误处理”。账号验证和重试操作统一留在弹窗内。移动端的错误弹窗操作按钮按文案和舒适的最小宽度排列，空间不足时换行，不拉伸铺满每一行。

- 错误弹窗在等待账号验证和重新加载第一页时使用中性进度摘要，隐藏旧错误代码；重新加载期间不显示旧处理指引或“当前列表暂时无法继续加载”的兜底警告，只有重新加载失败才重新显示实际错误。已恢复的验证错误在运行端提供恢复能力时首次打开就显示“验证”，无需先点重试。桌面的“验证”按钮与篡改猴来源验证入口使用相同的表面色和描边样式，保留“重试”为实心主按钮。“重试”表示再次尝试加载；需要登录或安全验证时先完成对应操作，再重试。桌面验证指引中，关于验证完成前重试仍可能出现相同错误的提示加粗显示。验证通过后的自动加载使用“重新加载”提示。“恢复原名”和“恢复筛选历史”继续表示还原已有内容。
