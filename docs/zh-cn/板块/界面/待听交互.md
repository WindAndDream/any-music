# 待听界面与操作

[English](../../../en/modules/ui/listen-later.md)

顺序与存储归[宿主队列](../资料库/历史与下载.md)。这里记录布局、分组、选择和重排。

待听复用发现的歌曲卡片、展示密度、移动列数、背景区域色和克制圆角，顶部标题采用与 catalog-page__context 相同的字号和 44px 标题行，标题与歌曲网格共用横向留白，默认按真实播放顺序展示。待听内容和上方区域使用内嵌灰色表面，外框及歌曲项横向留白与发现中的歌曲页一致，不设额外宽度上限，表面默认占满页面可用高度，内容较多时自然增高，四周及底部沿用现有页面背景与留白。桌面歌曲总数使用主题色数量徽标和加粗数字；手机移除内容区介绍标题，在最顶部右侧显示完整待听歌曲总数。平台和账号上下文仅在发现展示，其他功能页不沿用该上下文。“全部歌曲 / 按平台”继续作为左侧直接可达的集合分组控件。各宽度均在底部筛选器左侧保留唯一“展示方式”入口；窄容器可只显示图标，并保留相同的无障碍名称与触摸热区。入口采用与搜索/导入相同的 12px 字体与至少 44px 高度，发现中音乐列表的状态按钮与歌曲页顶部按钮统一使用待听展示方式入口的 650 字重；工具栏滚出原位后吸顶，排列控件始终留在左侧。复用歌曲列表的密度与手机列数设置；歌曲展示密度使用同一网格位移动画，全部歌曲与按平台之间仅列表内容双向滑入滑出，介绍、工具栏和背景表面保持原位，减少动态效果模式停用位移。播放顺序继续从播放器设置。平台入口使用共享集合卡片和 Grid，理想列宽为 320px（CSS 像素，避免宿主页根字号改变列宽），列间距 16px，按内容区实际宽度自动增加列数；不足理想列宽时单列，长名称和数量摘要单行省略并保留完整提示。卡片使用 10px 圆角、主题图标、歌曲数、类型和播放标记，勾选控件独立于查看歌曲按钮。平台概览不显示路径文本。窄于 600px 的待听容器使用紧凑横向平台卡片，类型放在歌曲数量前方并共用摘要行；按实际文字宽度优先移除放不下的“音乐源 / 本地拼接”前缀，仍超宽时单行裁切数量并保留完整提示，播放标记随可用宽度换行，独立的 44px 勾选热区保留在右侧；查看按钮保留横向内边距及完整的箭头动画空间，减少页脚和卡片间的纵向留白。点击平台时，整页连同介绍、工具栏和内容一起双向水平推进；平台歌曲页复用发现中的歌曲页的吸顶返回栏、标题与摘要字号、44px 上下文标题行和文字横向内边距、可收起信息区和加粗展示方式按钮，只显示平台名称、待听数量与播放状态，不重复概览介绍或排列控件。返回按平台恢复概览滚动位置和原卡片焦点。离场视图立即停止交互，减少动态效果时关闭位移动画。平台概览、全部歌曲和平台歌曲详情均保留操作器入口、面板及已选数量。平台卡片的勾选框选择当前筛选匹配的该平台歌曲，部分选中显示混合状态，全选后再次勾选取消该平台匹配歌曲；选择与歌曲视图共用同一状态，批量下载和移出待听沿用歌曲数量与确认规则。详情页的选择、全选、下载、移出及数量摘要只作用于该平台的匹配歌曲；筛选后没有匹配歌曲仍保留平台信息和返回入口，平台最后一首歌移出后自动返回概览。平台概览使用二维卡片拖动和方向键排序；组内歌曲仍在当前平台内排序。CollectionCard、CollectionGrid、CollectionBreadcrumbs 与 useCollectionNavigation 为后续我的歌单提供相同的入口与导航基础。切换为平台排列时，保留各平台歌曲原有的相对顺序，并将实际队列整理为连续平台区块；排列偏好与队列顺序一同持久化。歌曲卡片与发现中的歌曲列表共用播放、喜欢、下载与操作，操作弹窗复用自定义名称、标签和来源原页，上方四列紧凑按钮与发现中的歌曲操作一致，为播放、待听、喜欢、下载；待听显示为已选状态，点击取消待听沿用移出确认，不再单列移出待听按钮；中间一组为后移、前移、置顶，底部为名称、标签和原页，各组之间增加留白与分隔线；发现中的歌曲操作同样使用四列按钮与分组分隔。所有可用按钮及详情项在悬停/键盘焦点时改变背景，并在允许动态效果时提供轻微图标位移或缩放；第一首的置顶和前移禁用，最后一首的后移禁用。全部歌曲和平台详情的歌曲卡片均移除独立拖拽按钮，仅在操作器打开时短按封面选择，长按封面 500ms 后进入拖拽状态并显示浮起描边，顶部同步显示带排序图标的青蓝色信息提示“已进入拖拽排序，移动调整顺序，松手完成。”；每次成功进入只提示一次，3 秒后自动消失，不抢焦点或拦截拖动；长按激活后的歌曲、平台卡片、子控件与内容间隙统一显示四向移动光标，松手或取消后恢复原有光标；等待期间移动超过 8px 或开始滚动即取消长按，长按成功后才接管触屏拖动，松手后的合成点击不改变选择。封面保留方向键微调和 Escape 取消，操作弹窗保留前移、后移、置顶，移动端卡片右下角的选择控件仅在操作器打开时显示，且独立于排序；平台概览移除独立排序手柄，短按勾选框选择歌曲，长按平台卡片或勾选区 500ms 才进入整组拖拽，成功进入后复用同一顶部信息提示和取消规则，松手后的合成点击既不改变选择也不打开平台详情；网格不额外叠加内边距，标题和两侧控件与歌曲项边缘对齐，容器约束横向排序位移溢出；平台排列下歌曲在组内排序，平台区块也可整体排序。手机端保留相同操作，不叠加第二层侧抽屉。
