# 目录歌曲结果与操作

[English](../../../en/modules/ui/catalog-track-view.md)

请求和会话逻辑见[来源分页](../音乐源/分页与会话.md)，错误交互见[异常恢复](目录错误与恢复.md)。

- 查看歌曲直接展示已保留的元数据，慢请求期间退出再进入复用同一次请求。首次打开或刷新抖音列表时，未启用筛选的歌曲视图显示加载指示，按歌曲行的实际尺寸逐页补齐首屏。铺满首屏、分页停止，或首个分页后达到额外三页或四秒的上限时，从顶部展示已加载的歌曲。后续随向下滚动加载。列表太短而无法滚动时，向下滚轮、向上滑动或聚焦列表后使用翻页键仍可请求下一页。加载期间到底的需求在请求完成后重新检查。每页只准入一次，向上滚动撤销待续载需求，筛选不会触发连续后台翻页。未提供可靠续载位置的来源保留结果并提示手动刷新。刷新与错误重试保留各自显式入口。

- 桌面端抖音歌曲结果在应用内列表和 Windows 结果 WebView 中都采用实测虚拟列表。Classic 使用歌曲卡片，Studio 支持原生表格和皮肤网格。挂载范围跟随主题视口，筛选、选中、播放顺序和分页仍依据完整的已加载集合。渲染端之间恢复滚动位置时不会触发翻页。见[桌面运行端架构](../桌面与移动端/运行端架构.md)。

- PC 歌曲页上下文区域展示列表标题、平台与歌曲总数/已加载数量，不展示账号名称。移动端进入发现的歌曲页后，右上角显示该列表的实际请求账号名称，账号右侧补充留白，与左侧导航按钮中的图标保持协调的边缘间距。歌曲页上下文左侧只显示平台，点击平台可查看完整列表信息；右侧只显示歌曲总数与已加载数量，不重复显示账号或平台。音乐列表页仍保留平台选择入口。

- 桌面端发现页的账号入口只显示所选账号的自定义名称。切换账号弹窗统一显示“平台用户名（自定义名称）”。平台用户名不可用时，括号前使用平台显示名称。平台用户名按账号隔离。抖音保留上次验证的昵称，重启后可直接显示。打开切换弹窗时，后台补读已登录的其他抖音账号缺少的昵称，默认账号由发现页检查。关闭弹窗取消其补读请求。命名变化即时跟随公开账号快照，不覆盖平台原名或更改列表身份。

歌曲页不再显示“发现”按钮，需要返回音乐列表搜索或导入；顶部固定来源只显示平台名称，不显示“固定”后缀。进入歌曲页和返回列表沿导航方向整宽滑动，与“我的喜欢”的平台导航一致。经典主题的音乐列表在切换“全部 / 可用 / 不可用 / 错误”时采用集合工具栏的结果转场。页面通过横向裁切避免底部滚动条，同时不创建影响吸顶的嵌套滚动容器。离场内容停止交互，减少动态效果时关闭转场。已确认失效的歌曲标记跨列表和重启保留；网络、登录、验证和媒体传输等临时故障保留重试机会，不永久禁用歌曲。缓存与平台续载边界见[音乐源架构](../音乐源/分页与会话.md#4-惰性列表)。

- 歌曲页在播放控制栏上方把筛选器与操作器拆为两个入口，数量摘要与音乐列表统一为“已选 · 匹配 / 共”，采用略加粗字重；歌曲数量只统计当前已加载范围，草稿预览不改变入口摘要，应用筛选后才更新匹配数量。音乐列表空状态说明使用完整内容宽度，空间不足时自然换行。歌曲操作器上排左侧放关闭、右侧放全选，下排依次放加入歌单、下载已选、添加待听、添加喜欢，以及有已选命名项时才显示的恢复原名。按钮固定为 44px 高，整行宽度足够时整组靠右，按钮间保留 12px 间距；只有实际溢出时从左开始排列，通过单行滚动和右侧箭头浏览，不挤压或折行；手机入口保持紧凑，并保留仅图标的返回列表顶部按钮。回顶入口逐帧改变产品内容区滚动位置，先慢后快，抵达后只对列表内容执行 4px 轻回拉；不移动宿主网页、导航或播放器。触摸、滚轮、滚动键盘操作、切页、隐藏或卸载会取消旧动画；减少动态效果时直接回顶。筛选器从底部滑入，初始概览不默认选中维度，空维度不重复显示“未筛选”状态：宽屏左侧提供搜索、标签、命名、发布时间、歌曲时长五个入口，右侧纵向展示对应维度的草稿条件。每条具体条件本身就是编辑按钮，悬停时使用直角矩形背景，点击后进入对应维度并载入该条内容；修改区间时替换原条目，保留其他区间。概览删除单项条件立即更新草稿。无筛选条件时，无边框的集合空状态铺满概览区域，居中显示图标和“还没有筛选条件”。筛选维度入口以数字徽标显示已选数量。每个维度名称旁都有问号按钮，点击打开对应说明弹窗。弹窗打开期间暂停底层筛选面板交互，关闭后焦点回到问号按钮。搜索提示字号随输入框宽度调整，底部按钮的键盘焦点环绘制在按钮内侧。具体筛选项中的关键词、标签与合法的待加入或待更新日期/时长区间实时参与预览，并与其他维度条件组合；不完整或非法输入沿用已选条件，不提前写入概览或历史，返回丢弃修改并恢复原预览。关闭按钮旁仅保留音乐列表名称，去除重复匹配数量。搜索只有一个关键词，始终同时匹配歌曲名称、作者名称和用户 ID；进入即显示自动聚焦的主题色底线输入框，点击或键盘聚焦时主题色底线从左向右延伸，失焦向左回收，不显示四边焦点框；反复聚焦从当前长度平滑反向，减少动态效果时立即切换，下方展示搜索历史，历史按钮中的文本垂直居中，不提供范围选择或多条件添加。发布时间左侧使用紧凑、偏方的自绘日历，日期点击区域至少 44px 高，顶部使用项目统一字体，将年月日数字文字作为三个原生模式入口，保持居中的日期阅读顺序与细底线，当前维度以主题色背景和按下语义高亮；两侧提供翻页箭头，宽屏布局放大箭头及按钮，下方显示模式提示和当前选值，不再另占一行重复的视图按钮。标题与选中日期格复用 `--am-color-primary` / `--am-color-on-primary`，日期格以主题色描边强调选中；今天保留 `aria-current="date"` 语义，不给日期数字添加下划线。日期数字跟随活动端点或当前月份的键盘落点。支持年、月、日期定位及方向键、Home/End、PageUp/Down；年月日视图和翻页使用有方向的滑动/淡入，日期范围色块独立缩放/淡入，离场网格立即停止接受点击和焦点，减少动态效果时关闭这些动画，日期操作栏的“起始时间”和“结束时间”复用我的喜欢“全部歌曲 / 按平台”的分段样式。组内按钮等宽并留有间距，选中滑块随端点切换而滑动。减少动态效果时，滑块立即切换。按钮组默认占满整行。加入或更新时间段按钮出现时，左侧按钮组平滑收至可用宽度的三分之二，右侧操作占三分之一，两组之间留有间距。减少动态效果时立即切换宽度；PC 放在右栏顶部并独立于历史滚动，手机放在日历上方。加入按钮初始隐藏，点击“结束时间”或载入含结束日期的已有区间后出现，切回起始仍保留；加入后重新隐藏并将焦点交回起始入口。PC 操作栏与下方内容区保留相同的滚动条槽，使加入按钮对齐右栏内容边缘。日历只修改当前端点：结束阶段同时标记起止日期格与中间范围，切回起始时只标记起始格并保留结束值；起始不能晚于已选结束，结束不能早于起始，允许同一天。当前起止日期摘要使用上下两条端点行，起始/结束标签与对应日期对齐；两条端点行均为原生按钮，点击或键盘激活与顶部“起始时间”“结束时间”共享阶段切换，按下语义和活动提示同步，悬停提供主题背景与手形光标，键盘焦点环保留在按钮内侧；日期使用 20px 加粗文字，窄容器允许标签与日期自然换行，保留完整日期。活动端点使用主题色细边框、浅主题色背景和“正在设置”文字，不仅依赖颜色区分阶段；摘要不再嵌套外层卡片，也不显示箭头。历史日期保留紧凑的横向箭头摘要。PC 时间编辑区使用完整可用宽度，日历与右栏按约 1.6:1 分配并为右栏保留必要的操作宽度；左侧日历和六周网格铺满可用高度，年月日标题、日期字号与格子随可用空间调整；日期及年月选项始终至少 44px 高。左侧日历保持在原位，右侧当前范围、已选范围与历史共用独立滚动区；左侧日历优先铺满可用高度；桌面高度不足时通过明确的尺寸容器收紧留白和辅助提示，达到最小点击尺寸后允许左栏滚动，避免裁掉日期或继续缩小点击区域。窄屏仍上下排列并由详情区整体滚动。日历、日期格与时间内容块使用较小圆角；切回起始端点仍可提交已完成的范围。歌曲时长左侧提供最短和最长分钟数的底线输入框，支持单边不限，拒绝负数、非法数值及最长小于最短；右侧展示已选时长区间与历史；加入或更新时长按钮按内容紧凑排列，最小宽度为 8rem（受可用宽度限制），两端均保留至少 44px 高度。时间与时长仍可添加多个区间，编辑页内删除只影响隔离草稿。搜索、标签、时间、时长每次“确定”直接使用本次提交快照保存该维度整组历史，不读取尚未回流的旧 v-model 值，首次确认即记录，去重后最近优先；设置中可分别指定各维度保留 0–100 组，默认 12 组，0 表示不保存，调小立即裁去最旧记录。每项历史默认显示最近 3 组，显示阈值可在设置中调整为 1–100，超过阈值提供带剩余数量的展开/收起按钮，展开列表使用有界滚动；一组历史中的每个日期/时长区间分别占一行，组内通过细分割线区分各段。时间与时长历史统一采用中性背景块及较小圆角，日期历史省略重复的起始/结束标签，仅用箭头连接日期，不增加渐变、阴影或最近使用徽标；整块仍一次恢复整组条件。桌面时间历史展开后共用右列滚动，窄屏保留有界历史窗口。正式脚本通过运行端存储跨宿主页和刷新恢复历史。所有筛选历史的文字均采用与搜索时间一致的 650 字重。每组历史旁均提供始终可见的删除按钮；删除整组快照并立即持久化，不改变当前筛选草稿。删除后焦点转至相邻组，最后一组删除后回到当前输入。恢复历史会替换当前维度草稿并载入可编辑控件。平台历史将各平台名称分块放在同一行，超出的部分裁切隐藏。点击该行会打开弹窗，展示这组历史中的所有平台名称和“恢复筛选”按钮。标签编辑页的本地搜索只收窄可选标签，无标签或无匹配结果时提示水平居中；标签整块及复选框显示可点击光标，悬停时切换背景，键盘聚焦保留主题反馈。历史删除和已选条件删除的悬停、键盘聚焦或按下反馈复用项目的 `--am-color-danger-container` 柔和背景与 `--am-color-danger` 红色前景。标签历史每次选择形成一个组框，外框使用主题表面色（浅色为白色），框内标签使用 `--am-color-surface-subtle` 浅底与细边界分区；组框按内容宽度自然排满一行后换行，长标签在框内换行，保持最近优先与键盘阅读顺序，点击整框恢复整组标签。标签组在悬停时使用常态背景，删除按钮悬停时使用危险操作背景。编辑页底部把状态靠左并将“返回”“确定”靠右；返回丢弃本维度修改，所有维度共用先慢后快的返回转场，概览抵达时越过终点 3px 再轻轻回拉；离场视图立即停止接受点击和键盘焦点，入场结束恢复原入口焦点，减少动态效果时关闭动画。确定会提交尚未加入的合法输入，非法或不完整区间保持编辑页并显示错误。手机将左右布局改为上下排列，概览入口移至可横向触摸滚动且隐藏滚动条的底栏。入口角标记录独立条件数量，面板使用与正式列表相同的规则预览匹配数；关闭或取消丢弃整个面板草稿，只有“应用筛选”更新歌曲页。同一维度的区间/标签取并集，不同维度取交集。

- 歌曲页的返回栏吸附在内容区顶部，并直接显示列表名称、来源、总歌曲数、已加载数、“喜欢已加载”和“刷新”。展示方式只保留底部筛选器左侧的入口；刷新在各宽度均显示“刷新”两字。展开时所有宽度（含超宽屏）均保持两排布局：上排左侧为列表名称、右侧为来源与数量，下排左侧返回、右侧为喜欢与刷新，桌面将单条短横线手柄贴在返回栏底边中央，以绝对定位复用既有留白，不占据按钮行的列宽或增加高度；移动端隐藏图形提示，顶部栏全部非交互控件区域与底边均支持按住后上下拖动，普通标题、来源、数量文字都可作为起点；轻触、点击及拖动后合成的点击均不切换收缩状态。仅按钮（含省略标题的全文入口）、链接、输入及可编辑控件独占各自输入。各宽度下，鼠标进入顶部栏非控件区域时显示抓取光标，按住时显示抓取中光标；按钮保留原有光标。保留原生文字选择与复制菜单，仅在开始纵向移动后接管默认输入。切换布局或卸载时释放手势监听器。桌面点击手柄或两端向上拖动至少 24px 后松手，隐藏名称、来源与数量，只保留三个操作按钮及手柄；桌面再次点击或两端向下拖动展开。底边入口保留键盘语义：桌面支持回车/空格切换，两端保留上下方向键收起/展开；短拖、反向拖回、横向手势与取消均不切换，拖动后的原生点击不重复触发。收缩状态在当前工作台会话内保留，错误与来源不可用提示始终保持可见。返回栏自身宽度超过 600px 时保留完整返回文字，窄容器使用图标入口。列表名称按实际文字宽度自适应：完整名称（平台、搜索方式与原始搜索词）放得下时全部显示；放不下时显示“平台 · 原始搜索词或导入链接”，省去搜索方式，若仍超宽则单行省略。只有实际省略的文字提供可访问的全文按钮和悬停背景，完整显示时使用不可点击的普通文本。全文弹窗保留完整名称及原始请求内容，长文本自然换行且可复制，重命名不影响原始请求；调整宽度、文字或字体时重新测量，并在卸载时释放观察器。来源未提供总数时明确显示未知，不把已加载数量当作总数。“喜欢已加载”在手机上保留文字，并在提交前确认当前已加载的歌曲数量；尚未加载的分页不在本次操作中。宽屏展示方式弹窗提供宽松、标准、紧凑三种卡片密度；手机提供一行一个或一行两个。卡片内容按各自网格单元宽度调整，切换不改变当前选择、筛选或播放。网格保留空列，筛选后只剩一首也遵守当前展示方式的列宽；列宽只随可用空间和展示方式改变，手机仍遵守一列或两列的偏好。后续页面通过滚动加载，不再显示手动“加载更多”按钮。
