# 音乐源板块

[English](../../../en/modules/sources/README.md)

来源包持有上游地址识别、签名、DTO、分页以及到 `Track` 和 `TrackListing` 的映射。工作台通过可移植端口组合注册表、列表会话和播放。界面发出搜索、导入、播放、下载意图。[GM](../用户脚本/开发规范.md) 与 [Rust／IPC](../桌面与移动端/开发规范.md) 各自持有传输、账号上下文和媒体访问。

| 运行端       | 内置来源目录                                                                                    |
| ------------ | ----------------------------------------------------------------------------------------------- |
| 用户脚本     | 哔哩哔哩、抖音、网易云音乐                                                                      |
| Tauri 桌面   | 哔哩哔哩、抖音、网易云音乐                                                                      |
| Tauri 移动端 | 哔哩哔哩。Android 有原生账号和前台媒体端口，范围见[移动端能力](../桌面与移动端/移动端能力.md)。 |

应用按运行端形态选择 `*_BUILT_IN_TARGETS`，构造前拒绝重复来源 ID。根入口提供轻量描述、能力、地址范围和贡献元数据。不支持的地址在请求前拒绝。实现首次使用时惰性加载，成功复用，失败可重试。区分 `bilibili` 等来源 ID、`source.bilibili` 等模块 ID、`source.bilibili/provider` 等贡献 ID 和已保存的歌曲 ID。

注册表持有操作代际。停用、失败、策略或账号改变会撤销旧列表、解析和媒体。重新启用会保留记录，等待用户发起新操作。故障导致没有可用来源时核心页面仍可用。用户无法手动停用最后一个已配置来源。用户脚本固定 `externalPlugins: none`，Tauri 只接收原生验证的投影，并检查[运行策略](../插件/运行策略.md)。

来源协议与播放修改使用 `$music-source-adapter`。验证请求数量、顺序、并发、取消、重试以及来源特定的空页、错误和终止条件。明确要求重抓时用对应采集技能。网页、实际安装的 GM 和 Rust 证据按各自范围记录。
