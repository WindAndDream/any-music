# 插件生命周期、贡献与分配

[English](../../../en/modules/plugins/extensions.md)

`plugin-center` 持有数据描述、注册、依赖与生命周期协调及分配。一个分发包可以包含模块。模块持有有版本的贡献，宿主分配器按信任、作用域和基数匹配到类型化扩展点。每个挂载的视图或歌曲行使用一份定义，并持有自身清理作用域。歌曲和歌单仍归领域模型。

## 组装与故障恢复

1. 应用根据轻量元数据组装必需宿主模块与构建期已知的标签、创作和来源可选模块。内置身份来自构建目录。插件中心是运行中的系统的控制界面。
2. 注册校验所有者、贡献／扩展点 ID、契约版本、实现种类和作用域。必需依赖不兼容时阻止受影响模块激活。惰性激活合并并发工作，允许失败后重试，只发布当前代际。
3. 分配器输出确定的分配和拒绝原因。交互通过受控输入与具名宿主命令。撤权或停用清理注册、副作用、数据投影和旧异步工作，已存数据保留在原归属。最小恢复区域可以恢复默认而无需挂载故障板块。
4. 稳定工作台持有资料库、播放、下载和编辑生命周期。`plugin-ui-vue` 绑定分配的视图及可信主题渲染。主题共享公开 UI 契约和稳定视图 ID。登录、授权、安装／回退、原生保存和恢复归宿主。

## 协议与原生边界

SDK 持有有版本的 Schema 与生成的 TypeScript／Rust 验证。Wire、Profile、包、数据、预算和贡献分别协商版本。执行前检查已知扩展点和能力。未知必需项失败，未知可选项不分配。渲染器偏好和签名元数据不能授予原生权威。

外置包使用[桌面交付](工具与桌面交付.md)已经准入的目录和具名命令。经过验证的目录与内置来源共用选择器。外置包当前不能解析媒体、组装主题、替换任意 Vue 组件或占用受保护界面。分别参见[独立主题](../界面/独立主题开发.md)、[原生权威](原生权威.md)和[外置扩展提案](../../计划/未来/外置插件扩展.md)。
