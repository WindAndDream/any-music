## 共用产品功能与边界

`music-workbench` 拥有共享工作台、资料库、收藏、歌单、播放器、播放队列、下载、历史、宿主持有的已发布配方及快照编排，测试随实现所有者维护。应用注入 HTTP、稳定值存储、来源实例、登录入口、媒体适配和保存文件等能力。`plugin-tag-management` 持有标签规则/关联及专属界面，`plugin-music-creation` 持有草稿/材料/编辑状态及专属界面，工作台消费其具名端口和投影。`ui` 保持受控展示，`plugin-source-bilibili` 与 `plugin-source-douyin` 持有来源协议，`core` 持有领域与 ports。见[包边界](../../系统架构/可复用包边界.md)。

Userscript 保留 `any-music:userscript:*` 存储键、Shadow DOM、轻量启动器、GM HTTP、宿主单账号和单代理配置；桌面不会读写该命名空间。桌面取消隐藏悬浮产品入口，使用 embedded 布局和原生文件保存。

Tauri 渲染端快照与原生 `product.json` 镜像保存当前完整代次映射和提交指针。启动先选择最高的完整代次，再比较 revision；两份镜像一致后才暴露资料仓库或工作台。不受支持的镜像版本或无法恢复的快照损坏会停止初始化并保留恢复数据，可读取的另一份镜像可用于恢复损坏副本。渲染端在内存中暂存并校验每一代数据，发布指针时同步写入一次完整的本机镜像，再将完整镜像排队持久化到原生。原生镜像失败有可见反馈，并阻止后续写入直到重启。稳定快照不保存 Cookie、媒体 URL、字节、Blob URL 或最终磁盘路径。账号策略只含公开 ID 与操作元数据。桌面不自动导入篡改猴资料库。见[数据归属](../插件/数据归属.md)。

桌面与 Android 通过注入的 `DownloadScheduler` 申请原生下载准入。Rust 持有有界 FIFO 信号量（1–5 首整曲任务）并处理等待任务取消；渲染层拿到原生许可后才开始任务。许可覆盖解析、读取、编码和重试，任务资源清理后才释放；共享层保留重试策略和浏览器编码。主 WebView 关闭/重载、应用退出及移动挂起清理临时准入。篡改猴保留前端调度；iOS 媒体与保存仍不可用。自动化测试不代表设备验收。

下载目录选择位于“设置 → 网络与下载 → 歌曲下载”。桌面通过原生文件夹选择器选目录，仅在原生 `download-directory.json` 中保存目录偏好，不写入产品快照或下载历史；原生保存回执仅包含文件名、字节数与完整 SHA-256，不包含最终磁盘路径。重新下载只打开当前目录内的精确同名文件，以 64 KiB 缓冲区流式校验全部内容；仅文件名、大小或内容相同均不足以跳过。保存时请求名称和内容均一致则跳过重复写入，其余冲突通过独占新建自动编号，保留已有内容。Android 使用 `ACTION_OPEN_DOCUMENT_TREE` 和原生偏好中的持久读写授权，渲染层仅接收文件夹显示名称；下载在授权目录中新建文档，继续经过原有受限保存令牌适配器（32 MiB、前台/生命周期/时限检查）。恢复“每次询问”后使用逐文件系统保存窗口，取消目录选择保留原设置。目录消失、授权撤销或写入失败会明确报错，允许重试或重新选择。Android 11+ 限制存储根目录及 Download 目录本身，可选择允许的子文件夹，见 [Android SAF](https://developer.android.com/training/data-storage/shared/documents-files)。iOS 继续声明原生保存不可用。Rust、渲染层测试和 Android 编译检查不代表真实选择器或设备验收。

## 操作、分页与媒体

新的搜索、导入、会话检查和媒体解析使用已保存的默认账号，每次操作只尝试该账号，失败不会切换账号。已有列表和歌曲绑定的账号仍启用时优先沿用该身份。账号切换弹窗不提供自动选择入口，也不提供账号竞争策略配置。普通操作的单次尝试预算为 25 秒，总预算为 60 秒。

抖音搜索保留 105/115 秒的单次尝试与总预算，为官方页面加载和清理留出时间；媒体解析预算为 50/70 秒。遇到风控时等待用户验证同一账号。

搜索/导入首屏绑定所选账号，后续惰性分页保持该身份和游标；停止消费、账号停用、删除或环境更改会释放请求。播放和下载的媒体 URL 转换为 Rust 提供的随机本机媒体 grant，原生 audio、Range 与完整读取均使用该 grant 的账号 Cookie 和代理；只有随机 grant ID 进入本机 URL。服务绑定 127.0.0.1、流式传递 Range，不缓存完整文件。grant 仅在内存、有数量/有效期预算；账号环境变更立即撤销。媒体策略继续保持描述解析、原生流式、有界 Range/MSE、完整读取兜底的顺序。

抖音搜索由官方搜索页面生成请求，Rust 捕获限定的 general/search/stream 与 general/search/single 响应，保留原始字节交给共享 DTO/映射。每个列表独立 target、关键词和游标；首屏按消费创建，后续页按需滚动，停止消费关闭页面。官方页面可能提前加载下一游标，因此在等待消费或检查账号状态期间保留匹配的响应；每列表至多三个待消费响应、全账号缓存上限 24 MiB，最多八个列表且响应/时长有界。会话检查同样来自官方页面。

作品播放、下载和单作品导入的详情解析也使用所属账号的内嵌页面：原生端校验数字作品标识和 video/note 类型，收到作品详情请求时按需打开隐藏页面。返回匹配 API 响应的页面最多空闲保留 90 秒。页面控件就绪后，固定脚本推入 `/video/<id>` 或 `/note/<id>` 路由，由官方客户端自己请求详情（登录状态下客户端使用官方 `www-hj.douyin.com` 接口域名，与 `www.douyin.com` 一并接受）。路由不可用、重访同一路由，或路由后 8 秒内没有匹配 API 时，先关闭该页，再在同一预算内打开替代页面。新导航页面仅读取匹配的 aweme/detail 响应或主框架作品文档，正文最多 12 MiB、页面读取最多 40 秒（原生操作 45 秒，界面端播放尝试 50 秒）。客户端详情请求要等官方页面加载完脚本后才发出，因此优先等待匹配 API，只有读取预算耗尽且没有 API 响应时才使用文档回退。2026-11-16 观察到视频作品的主框架文档不含媒体地址字段，慢网络下文档回退无法得到可播放媒体，延长 API 等待才是有效手段；网络、验证或登录失败保持原错误。共享包解析 API/React Flight，并校验作品身份与媒体结构；搜索结果的短时媒体地址不复用、不持久化。CDP 详情读取拦截媒体和图片请求，内嵌页面桥接禁用媒体播放。仅返回文档回退结果、失败或取消时均关闭详情页。实际媒体仍经相同账号的 Rust HTTP 与本机回环 grant 流式读取。官方详情失败不再退回缺少网页安全签名的本地详情请求。观看历史、个人喜欢、收藏视频/合集及合集作品已走所属账号的内嵌页面导入端口；未接入该端口的列表与收藏音乐详情仍走 Rust HTTP/共享签名，具体实站覆盖见契约记录。

本次原生账号复测确认两条真实作品的 API 详情可以通过共享解析器解析，其中一条使用所属账号的 Rust HTTP 返回 HTTP 206 和 1024 字节 video/mp4；响应和媒体地址仅在内存流转。自动化回归覆盖文档/load 先于详情 API、无 API 时的有界回退、网络失败不被文档掩盖、超时、取消、响应大小和目标清理。该证据不包含产品 audio 的 playing 事件或完整本机回环 grant 播放验收，也不更新网页契约 captureDate。
