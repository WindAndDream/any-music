# Tauri 移动端能力

[English](../../../en/modules/tauri/mobile.md)

| 能力       | Android                                                                                                                                                | iOS                                                                                     |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------- |
| 工程与启动 | `apps/tauri/src-tauri/gen/android` 有维护中的 Gradle／Kotlin 工程。最低 API 26 和 Chromium WebView 111。提供方缺失或过旧时原生引导显示本地化更新提示。 | 已有配置与受限 IPC 面。原生工程和设备交付仍在[计划中](../../计划/未来/iOS原生交付.md)。 |
| 来源目录   | 哔哩哔哩原生扫码跳转、CookieStore、账号／代理请求，以及绑定账号的环回／Range 前台媒体能力。                                                            | 哔哩哔哩元数据，运行端端口不可用。                                                      |
| 文件与凭证 | 原生选择器或单个获授权的 Android 内容流、不可变预览暂存、文档提供方保存、Keystore 保护的凭证。                                                         | 原生账号、安全凭证和保存适配器不可用。                                                  |
| 外置插件   | `externalPlugins: none`。提供有界包预览、脱敏诊断、快照／撤权。安装、DEV 和访客执行不可用。                                                            | `externalPlugins: none`。仅本地数据、能力和取消命令。                                   |
| 构建与分发 | arm64／x86_64 本地调试与优化 APK／AAB，显式签名。渠道和最低设备检查见 [Android 发布验收](../../变更/验收/Android发布.md)。                             | 尚无设备或渠道验收。                                                                    |

Android `main-android` 和 iOS `main-mobile` ACL 只匹配主 WebView。Kotlin `mobile-platform` 仅 Rust 可调用。Android 在同应用 UID 内转发合法 intent 及授权。原生预览最多在五秒内复制 16 MiB 到私有不可变快照，使用取消与有界打开器防止提供方卡死。脱敏诊断和文档保存归原生端。移动端没有系统浏览器／CDP、安装／回退、访客命令和执行器 relay。

构建与仪器测试见 [Android 验证](../../开发指南/Android验证.md)，音频焦点和取消见 [Android 播放](Android播放.md)，可能的未来准入见[移动端外置插件](../../计划/未来/移动端外置插件.md)。

## Android 来源与媒体生命周期

进入后台取消临时任务。只有已经明确打开的哔哩哔哩客户端授权跳转可在原 180 秒有效期内保留。返回应用不会再次跳转，取消、替换、过期均使旧会话失效。两条官方扫码路径校验后才进入跳转。

代理设置由 accountProxy 能力决定。环回监听在发现能力前绑定，WebView 仅对环回放行明文。主宿主为内置 MP3 编码允许所需 Blob Worker／WASM，与执行器 CSP 分开。账号、传输和设备的证据见 [Android 设备验收](../../变更/验收/Android发布.md)。
