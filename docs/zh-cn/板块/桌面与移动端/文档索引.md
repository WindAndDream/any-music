# Tauri 桌面与移动运行端

[English](../../../en/modules/tauri/README.md)

`apps/tauri` 通过渲染器 IPC 给工作台绑定 Rust 服务。Rust 持有原生凭证、数据、HTTP、账号页面、媒体、安装及授权。运行端能力决定桌面或移动组合。
